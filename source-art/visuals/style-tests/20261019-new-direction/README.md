# 正片画风新版候选

本轮以用户新增的燕云十六声截图为气氛参考，使用内置 image_gen 重新制作三张静帧。吸收灰青空气、逆光、前后景剪影与选择性湿面高光，保留三国军营设定。没有替换正式图片、视频或绑定。

| 候选 | 原图 | 特点 |
| --- | --- | --- |
| D 精致写实 | [D-refined-realism.png](D-refined-realism.png) | 沿用魏延身份图，面部明暗更柔和，保留较强的原衣甲结构 |
| E 青灰诗意 | [E-poetic-atmosphere.png](E-poetic-atmosphere.png) | 双人中远景、帐篷框景、层叠山雾与逆光，环境更重要 |
| F 写实与诗意融合 | [F-refined-hybrid.png](F-refined-hybrid.png) | 人物中近景、较细腻的脸部过渡，帐外冷色与帐内暖色联系空间 |

本轮是方向探索，景别和光照并非严格受控比较。E、F 仅采用文字身份锚点，摆脱旧渲染的同时产生了脸型、年龄感、胡须和头盔变化；不能直接作为已锁定魏延身份的正式资产。选定方向后需用同一套人物与服装设定复核身份，并在同一机位和光照下验证。E 的湿地高光仍偏多，F 的部分甲片仍偏亮，应作为下一轮局部校正项。

建议供用户选择：F 的人物与面部处理，E 的环境空间。该建议不代表用户已确定画风。

[用户气氛参考](user-atmosphere-reference.png) 为用户提供截图，作为研究附件保留，不作为发布资产。未核验原始出处，不用于推断相关游戏的制作技术。

[完整实际提交提示词](prompts.json) 记录三个版本的原始英文提示词与参考职责。D 使用当前魏延镜头及新增截图；E、F 只使用新增截图，人物由文字重新构建。全部为内置工具生成，未调用 CLI。
