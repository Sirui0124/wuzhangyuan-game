# 第一视角水墨电影画风候选

用户偏好 E 的画风，并明确纠正：不要求把人物退到景色中；游戏很多时候需要玩家第一视角。应迁移原始截图的提示词、精细度与影调到近距离人物，而不是照搬远景和小人物构图。

| 图片 | 用途 |
| --- | --- |
| [P1 青灰柔光](P1-grey-daylight.png) | NPC 直接面对玩家，灰青环境与近距离面部细节 |
| [P2 墨色冷暖](P2-ink-warmth.png) | 保持 P1 身份与交谈距离，尝试墨色暗部与局部暖光 |
| [P3 原始关键词](P3-original-keywords.png) | 在 P1 的身份和尺度基础上，直接复用雨帘与百官截图提示词，收敛环境暖色和强反光 |

P3 是用户最新“更多复用原先截图提示词关键词”指示下生成的版本，P1、P2 是此前的第一视角试验。三图为内置 image_gen 生成静帧，尚未确定最终画风、校准为正式魏延身份或接入游戏。当前头盔和扣件出现装饰性变化；P1、P3 顶部盔饰留白不足，最终资产需修正。不能将表面细节清晰等同于已完成角色连续性验收。

[E1 营门](../../archive/20261022/style-branches/branch-E1-gate.png) 和 [E2 候报](../../archive/20261022/style-branches/branch-E2-waiting.png) 是纠正前已启动的景色旁支，归档供环境研究，不代表用户要求主体缩小，不作为第一视角候选。2026-10-22 已移入归档区；原始 Prompt 仍保留在本目录，原路径、归档路径与 SHA-256 见[可逆归档清单](../../archive/20261022/manifest.json)。
