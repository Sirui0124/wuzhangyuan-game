# 现用美术

`runtime/` 保留当前构建使用的美术原件；游戏实际绑定唯一依据是 `GameStarter/web-demo/visual-assets.json`，`runtime-map.json` 从它自动导出，不另行手改。`design-tokens.json` 为旧版样式记录。历史图片 Prompt 和过程稿清理记录保留，本轮新增的生成记录、版本图与复核证据按分类存放。

普通人物按[跨章节人物形象规范](../../docs/art/CHARACTER-IDENTITY.md)维护：同一身份保持一致，不同关卡的不同军士分别设计，不以同一立绘换称呼。对话与人物志使用同一角色 ID；资源检查拒绝不同身份绑定相同图片。

后续场景与视频制作参考 [制片风格规范](../../docs/visual-direction/制片风格规范.md) 与 [视觉对照板](../../docs/visual-direction/style-board.html)：融合现有军营灯火与用户新增的水墨电影构图参考，保留自然肤色、暗朱与局部暖色。新增参考归档在该规范的 `references/`，未改现行素材绑定或公共调色。
