# SC02｜手机观看与愤怒许愿

## 视频参数与本轮节奏

**16:9／有声音／独立生成9秒／建议交付1920×1080。** 每个独立段最多25秒。

先让观众看懂手机，再让愤怒压成愿望；说完才进入黑场。

本轮调整：9秒不变；增加开口前0.7秒反应和说完后0.6秒停顿，黑场从8.2秒开始。

| 段内时间 | 节拍 |
|---|---|
| 0—2.5秒 | 拉出手机屏幕 |
| 2.5—3.2秒 | 先有反应 |
| 3.2—7.6秒 | 愤怒变成愿望 |
| 7.6—8.2秒 | 愿望落定 |
| 8.2—9秒 | 黑场与声音转场 |

秒数表达剪辑和表演意图，不保证生成模型严格锁帧。分辨率、时长和参考图数量最终按实际生成端支持项设置；如需拆段，在明确切镜处拆，每个子段重新从0计时。此处不指定新模型。
