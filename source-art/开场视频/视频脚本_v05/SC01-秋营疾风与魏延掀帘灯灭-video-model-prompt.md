# SC01｜秋营疾风与魏延掀帘灯灭

## 视频参数与本轮节奏

**16:9／有声音／独立生成20秒／建议交付1920×1080。** 每个独立段最多25秒。

远景与守灯先沉住气；风、骑兵和急步逐渐提速；掀帘到灯灭按因果拍清楚；最后把时间还给失落。

本轮调整：18秒→20秒；人物失落由约1秒增至2秒，另给熄灭后的灯芯1秒停留；减少无叙事作用的横移与弧线。

| 段内时间 | 节拍 |
|---|---|
| 0—3秒 | 秋营远景 |
| 3—6秒 | 帐内守灯 |
| 6—7.5秒 | 风势突变 |
| 7.5—10秒 | 营外骑队 |
| 10—12秒 | 魏延抵达 |
| 12—15秒 | 掀帘，风抵灯阵 |

秒数表达剪辑和表演意图，不保证生成模型严格锁帧。分辨率、时长和参考图数量最终按实际生成端支持项设置；如需拆段，在明确切镜处拆，每个子段重新从0计时。此处不指定新模型。
