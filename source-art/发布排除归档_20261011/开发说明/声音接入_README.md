# 五丈原声音资源

当前 HTML 试玩接入 12 个经过裁切、滤波、压低峰值和边缘淡入淡出的触点音效。原始设计与素材保留在 `source-art/五丈原_声音设计_v01/`。素材来自 Kenney Interface Sounds 与 RPG Audio，采用 CC0；许可证保留在 `licenses/`。

默认音乐 35%、音效 45%。音效总线额外乘 0.65，使默认音量更轻。设置范围 0–100%，0 精确静音；偏好独立保存在 `wuzhang-audio-v1`，不随剧情存档或重玩清空。文字输入、拖动、空白区域、禁用按钮和视频进度拖动保持安静；实际对白推进有短轻音。单次同步操作只保留优先级最高的一声，85 ms 内不重复触发，最多两声同时播放。切到后台立即静音、取消触点音效；返回不会补播旧声音。

获得证据使用 0.70 秒的古琴感三音阶拨弦（D4–F4–A4），逐音柔和衰减，峰值 -13 dBFS，比旧单音提高 3 dB。音体由项目脚本合成，叠加很轻的 Kenney CC0 拨弦触感，仍走同一音效总线及静音设置。

四首用户提供的 BGM 已接入：首页《五声余韵》（首次 394.2 秒，随后循环 4–394.2 秒）、第一轮《七星灯未灭》（108 秒循环）、第二轮《再查此夜》（188 秒循环）、魏延交涉《帐前未决》（96.4 秒循环）。原始 MP3、可复现处理脚本、处理记录与循环接缝试听保存在 `source-art/五丈原_BGM接入_v01/`，音乐不适用触点素材的 Kenney CC0 许可证。

循环版使用 44.1 kHz 双声道无损 WAV。去掉近静音的头尾后，把最后 4 秒与最初 4 秒做等功率交叉淡化，再连接中段形成连续周期。首页曲额外保留完整开头，首次从 0 秒开始，后续循环从 4 秒开始。循环处不额外淡到静音。四首以恒定增益匹配至约 -20 LUFS，保留原曲动态；处理文件和运行清单的循环终点精确到样本。

场景自动选择：首页用 home，第一轮用 round1，第二轮用 round2，魏延交谈（包括填写对白）用 weiyan。开始播放用 2.5 秒渐入，停止用 2.5 秒渐出，换曲时两首交叉淡化；快速切换从正在播放的实际增益继续衰减。同一曲不因打开设置或继续对白重新开始。地图、结局及剧情视频关闭独立 BGM。视频挂载前立即静音音乐总线，包括正在渐出的旧曲；手动暂停视频也不恢复 BGM。影片结束或跳过后恢复当前场景音乐，返回开始页恢复首页曲目。音乐暂停不覆盖玩家音量偏好，也不影响音效总线与视频自身对白。

修改后运行 `npm run build:demo`。验证脚本为 `web-demo/verification/verify-audio.mjs`、`verify-bgm.mjs` 和 `verify-home-bgm.mjs`，需要 Playwright；前两者可通过 `PLAYWRIGHT_MODULE` 指定模块位置。`audio-flow.json` 覆盖触点、静音与偏好；`bgm-flow.json` 覆盖四首实际文件解码、浏览器渲染循环接缝、渐入渐出、中途切换和停止，以及独立静音；`home-bgm-flow.json` 覆盖实际首页/视频/场景切换，包含视频暂停、跳过、自然结束、刷新续播和连续结局影片。未进行人工听音。
