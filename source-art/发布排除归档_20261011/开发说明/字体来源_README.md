# Ending title font

`ending-brush.woff2` is a locally served subset of Ma Shan Zheng Regular,
covering the ending names: 牺牲、遗憾、生还、殒命.

Source: https://github.com/google/fonts/tree/main/ofl/mashanzheng
License: SIL Open Font License 1.1, included in `MaShanZheng-OFL.txt`.
Generated with fontTools subset and WOFF2 compression. Add newly introduced
ending-name characters to the subset when extending the catalog.
