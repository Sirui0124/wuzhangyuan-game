# 夷陵大本营与御营附近空间研究

2026-11-06，独立 Blender 美术版本，等待用户审阅。用户本轮确认“大本营”应为刘备御营附近的集结营。本版按这个身份安排空间，保留原 `yiling-expert-20261106` 场景和 8942 剧情试玩。

## 场景布局

大本营位于江南台地，御营在附近较高的后方，两营之间有短路。集结营的北门通向岸边渡口，东门通向陆路；陆路出营后才分成傅肜方向与沙摩柯方向。黄权方向需要到南岸渡口、渡江、再走北岸道路。程畿方向与黄权共用出营至渡口的路，登船后沿江寻找后船。

台地、河道、渡口、御营位置以及四路距离都为游戏空间设计。模型按米统一物体尺度，让帐篷、木栅、船和地形具有合理的相对大小；这个单位不能用于推导史实行军距离或改写剧情计时。

场景里的一艘近岸船表示当前已有接应船队的视觉占位，远处一艘船表示程畿军情中的后船位置。它们不增加游戏可用船队，也不表示已完成接应。远处人物的标记是军情方位，不是玩家从营内肉眼看到了本人。

## 视角

| 机位 | 玩家看到的内容 | 用途 |
| --- | --- | --- |
| 大本营 | 发令帐附近的军帐、物资车、出营道路和营门。 | 以人的位置进入地图。 |

| 东侧陆路 | 营门、沿谷地延伸的路和远处山势。 | 认清陆路出营方向。 |
| 山路岔口 | 站在营外岔口，沿小路看向林缘与两侧山坡。 | 认清从主路转入山路的关系。 |
| 高处望御营 | 从大本营后侧瞭望台看两营之间的路、御营帐群和旗杆。 | 交代集结营与刘备御营相邻但分开。 |
| 调度总览 | 两岸、渡口、两营以及四路报告位置。 | 选路与比较去向。 |

采用六个固定机位预渲染。所有镜头使用同一 `.blend` 内的模型和光照，营地起始镜头使用40mm容纳身边物件，方向镜头使用50mm，总览使用48mm高机位。切换时只切换画面与对应投影，减少实时渲染负担。当前不生成假行军动画，不用镜头切换推进剧情。

地面道路和岸边砂砾直接混合在同一地形材质中，取消会相互遮挡的道路薄片。水面向岸坡下延伸；路口共用同一条地面，不叠放重复路段。御营前的地形、望江路线和视线走廊均已根据试渲染调整，不沿用旧沙盘坐标。

## 文件与重建

本机审阅入口为 [http://127.0.0.1:8943/review.html](http://127.0.0.1:8943/review.html)。也可直接用浏览器打开 `review.html`，它不依赖8942服务。需要重新启动本机预览时，在本目录运行 `python -m http.server 8943 --bind 127.0.0.1`。

- `build_scene.py`：完整几何、材质、灯光、机位与投影导出。
- `yiling-camp-v2.blend`：独立 Blender 源场景。
- `render_scene.py`：按机位渲染 1920×1080 PNG，Cycles、48采样；自动检测 Intel oneAPI，本机实际设备以 `render-log.json` 为准。
- `camera-layout.json`：各机位参数、地标世界坐标、投影与路线。
- `review.html`：独立机位审阅页，使用本目录图片与投影。
- `legacy-map-layout.json`：供现有调度页参考的兼容投影格式。
- `verification.json`：实际文件和审阅页检查结果。

在项目根目录执行：

```powershell
blender -b --python source-art/maps/yiling-camp-v2-20261106/build_scene.py -- --preview
blender -b --python source-art/maps/yiling-camp-v2-20261106/render_scene.py
python source-art/maps/yiling-camp-v2-20261106/build_review.py
```

建模和渲染调用 Blender 5.2.2；合成器按 [Blender 5迁移文档](https://developer.blender.org/docs/release_notes/5.0/migration/compositor_migration/)使用独立合成节点组。未使用 AI 生成图片或把参考营地图铺作背景。表面材质与天空光照采用 [Poly Haven 的 CC0 资产](https://polyhaven.com/license)，13个资源的来源与校验和见 `material-provenance.json`；图片已打包进 `.blend`。天空 HDRI 只用于天空与环境光，不提供夷陵地形。瞭望台、营地道具与本地地貌为游戏布景设计。

## 接入边界

本轮文件全部在新目录。没有改 `story-content.json`、`story-engine.ts`、`src/app.ts`、服务端、存档和当前发布的 `public/art/map.png`。

现有地图读取 `Layout={points,routes}`，坐标为左上角起算的0—1比例。`legacy-map-layout.json`使用同一格式和 `fu/huang/cheng/sha` 路线编号，大本营仍用 `camp`，文字改为“大本营”；新增 `imperial` 仅作非互动地点。未来接入需同时更换地图图片与该图的投影，不能把新图片配上旧坐标。

若接入多机位，所需文件为六张PNG、`camera-layout.json`、新增视角显示模块，以及调用该模块的页面与样式。模块只接收当前路线、军情位置与实际行动状态；请求查看军情时再交回已有回调。它不负责AI问答、队伍分配、船队占用或时间推进。各机位的 `inFrame` 只表示投影落在画框内，不能当成无遮挡的可视性判定；审阅页只使用逐图确认的地标。`routeLegs`列明陆路、水路和共用渡口，供接入时区分步行与行船段。
