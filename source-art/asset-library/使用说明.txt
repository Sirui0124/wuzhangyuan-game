逆转五丈原 · 图片与视频素材资产清单

双击同目录“素材资产清单.html”，即可离线查看人物对照、场景参考和全部素材。图片、视频从原路径读取，不要求启动游戏或联网。视频能否在浏览器播放取决于其编码；无法预览时可用“打开原文件”交给本机播放器。

用途
这份清单用于生成图片、视频之前选择参考，统一人物身份。清单、报告和脚本均存放在 source-art/asset-library，不在 public、Cocos assets 或游戏发布清单中，不随当前游戏构建与 Windows 安装载荷复制。

人物资料
诸葛亮、魏延、姜维优先显示身份图与现用立绘。其余人物按游戏角色 ID 单列，姜维亲兵不并入姜维，第一章与第三章的斥候、军吏、传令军士也不合并。核心参考沿用 source-art/core/assets.json；游戏实际绑定以 visual-assets.json 为准。

上方谷的诸葛亮各版本 作为场景候选保留。已有披发、戴巾和雨景分别管理服装与状态，不能自动将其中一张提升为全项目唯一已通过身份图。缺少正面、侧面或细节图的项目已写在人物卡里；这是待补项，本轮没有新生成人物图。

清单字段
每个文件保留稳定的路径编号、相对路径、完整绝对路径、类型、用途、文件大小、修改时间、SHA-256、图片尺寸、发布绑定、原清单状态、来源路径与可追溯截帧时间。现用视频的尺寸和时长引用发布清单；历史视频未重新探测，不虚填时长。
人物关联分为“角色 ID 绑定”和“文件名/影片标题关联线索”。后者不是画面出镜识别。历史候选、制作参考、检查帧的类别依目录初分，尚未逐张人工确认。
同内容副本仅通过完整文件 SHA-256 认定，不通过文件名或视觉相似度认定；2026-11-04 按用户要求将未采用的历史图片、视频及同名过程提示词移入回收站；保留文件不覆盖、不搬迁。

审核与核验
已看三位核心人物的身份图/中性立绘及上方谷 v3 缩览；未逐镜观看全部影片，也未逐人完成其余立绘的视觉审核。发布选中、文件存在和哈希一致均不代表用户审核通过。原审核说明原样保留；在线飞书状态不在本次本地盘点范围。
validation.json 记录扫描数量、缺失的发布源文件、读取错误和清单哈希差异。browser-validation.json 记录本次离线页面检查。打包边界以当前构建源码检查为依据，本次不重新制作游戏安装包。

更新
由执行者运行以下命令刷新清单：
python source-art/asset-library/build_inventory.py
脚本位置决定工作区根目录，所以也可从其他目录使用脚本的绝对路径运行。脚本只写本目录，依赖 Python 和 Pillow。
inventory.json 与 HTML 是生成文件，不直接手改。人物说明维护在 build_inventory.py；确认人物基准或具体版本时，记录确认依据和版本再更新资料，不覆盖历史原件。没有后台监控；新增素材后需要重新运行。

盘点范围
扫描 source-art、video、GameStarter/web-demo/public、GameStarter/assets、docs/visual-direction 和 demos 中的图片与视频，排除依赖、缓存和构建目录。outputs/output 中的导出副本、测试截图、安装包载荷及外部磁盘、未下载附件不计入本清单；不盘点音频。发布主清单引用的原图、现片及视频制作参考均在扫描范围内。

本清单仍为生成准备资料。正式游戏所绑定的图片、视频、存档及素材映射保持原状。删除记录位于 outputs/media-cleanup-20261104；回收站未清空。
