# 五丈原 BGM 接入

用户 2026-10-11 提供的三首 MP3 按顺序对应第一轮、第二轮、魏延交涉。`originals/` 保留完整原片及原文件名，Downloads 中的原文件未改动。

首页已接入用户另提供的《五声余韵》（`用户5806 - 五声余韵.mp3`），对应 `home`。原片同样保留在 `originals/`。此前首页古风设计 Prompt《灯前初候》保留在 `prompts/04_首页_灯前初候.txt` 供参考，实际播放以用户成片为准。

`prepare-bgm.py` 生成 `prepared/` 的无损循环版，并复制到 HTML 试玩 `GameStarter/web-demo/public/audio/bgm/`。以 100 ms 能量窗识别近静音的头尾，保留原曲内部的安静段落。最初和最后 4 秒按等功率曲线叠合，把循环重新排成「中段 → 尾部与头部的混合 → 中段」。跨周期连续播放，避免整首淡出后重新响起造成停顿。

首页曲保留从第一个音开始的原曲开头，末尾 4 秒与开头 4 秒交叉淡化；首次从 0 秒播放，后续从 4 秒循环至 394.2 秒，周期 390.2 秒。这样保留开场旋律，也避免重播已叠合的开头。其他三首保持既有处理及资源内容，循环长度是 108 秒、188 秒和 96.4 秒。

恒定增益将四曲匹配至约 -20 LUFS，不压缩原曲动态。音乐文件循环自身不淡到零；游戏播放器在开始、停止、换曲时施加 2.5 秒渐入渐出。进入任何剧情视频页，播放器先立即静音整个音乐总线，连正在渐出的曲目也不与影片叠响；影片手动暂停仍保持背景音乐暂停，离开影片后由当前场景重新选择音乐。设置、读取存档弹窗和首页成就卡册不会重启首页曲目。浏览器限制首次有声播放时，第一次点击或按键启动音乐。

`processing.json` 记录原片与循环版 SHA256、裁切位置、循环起终点、交叉淡化曲线、样本数、响度、峰值和循环接缝波形检查。`previews/` 提供每首「循环前 4 秒 + 循环后 4 秒」的接缝试听。浏览器验证记录在 `GameStarter/web-demo/verification/bgm-flow.json`，包含真实 WAV 解码及跨周期离线渲染；首页、开场视频、视频暂停/续播/自然结束/跳过及结局连续视频见 `home-bgm-flow.json`。没有人工听音验收。

重新处理：在工作区运行 `python3 source-art/五丈原_BGM接入_v01/prepare-bgm.py`，确保音乐清单 loopEnd 对应处理报告，然后在 GameStarter 运行 `npm run build:demo`。音乐版权随用户提供的来源；不沿用触点素材的 Kenney CC0 许可证。
