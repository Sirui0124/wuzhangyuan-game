# UI与人物整套 v04：设计来源

本目录保留23张生成原图和提示词。正式接入请使用相邻的 `五丈原_游戏资产库_v01`，那里有稳定英文资产ID、运行/参考用途、校验清单、布局参数和图鉴。

主界面以 `UI/01_剧情对话.png` 为基准；证据浮层已由 `UI/13_右上证据弹窗_定稿.png` 替代原03全高抽屉。01和13构成当前核心UI基准。其他参考界面的剧情状态由引擎决定。

人物为带背景单人镜头；场景为无UI底图。早期 `生成清单与提示词.json` 仅包含初始任务，完整22任务见 `全部生成提示词.json`，最终追加的右上证据任务记录于正式库 `prompts.json`。
