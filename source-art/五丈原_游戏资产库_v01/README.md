# 五丈原 · 游戏资产库 v1.2

本版锁定电影写实人物、冷夜暖火军营、纸色地点导航、墨色半透明对话层和朱红选中态。用户已确认主界面与证据视觉方向；右上证据浮窗按用户最新布局要求完成。人物与场景可直接用于当前 HTML/TypeScript 试玩版，核心界面由程序绘制。

## 入口和资产范围

打开 [资产图鉴](index.html) 可按场景、人物和核心 UI 筛选。机器可读清单为 [manifest.json](manifest.json)，包含尺寸、用途、源路径与 SHA-256。构建映射为 [runtime-map.json](runtime-map.json)，其 sourceRoot 相对 GameStarter/web-demo。

|---|---|---|
|运行场景 4 张|中军帐门、营前传报处、传令侧帐、帐外候报处|runtime/scenes；无UI、无前景人物的16:9底图|
|人物镜头 6 张|魏延、斥候、守帐卒甲、传令卒乙、姜维、诸葛亮|runtime/characters；带背景人物镜头，可用作人物卡与交谈镜头|
|核心界面参考 12 张|对话、找人、关键交涉、告示、军情交接、两种结算、回溯、设置、存档、帮助、右上证据浮窗|ui-reference；用于布局与视觉参考|

人物镜头为带背景 PNG；当前未制作透明立绘、表情序列、口型、视频、配音或音效。姜维仅有剧情回应，诸葛亮仅有剧情展示，不能把这两人加入自由交谈列表。整屏UI参考图不应作为运行时交互背景，否则会重复显示文字和按钮。

## 已确认的界面参数

[01_剧情对话.png](ui-reference/01_剧情对话.png) 是主界面基准；[13_右上证据弹窗_定稿.png](ui-reference/13_右上证据弹窗_定稿.png) 是出示证据展开状态。旧版全高证据抽屉已被替代，仍保留在上一级 v04 探索目录供追溯。

对话框比最初方案高30%，采用30%透明度（70%不透明度），去掉金黄色装饰边框。对白、主要选项与场景导航文字同级，并在较大字号版本基础上缩小约15%。左侧场景按钮比最初版本加长20%。具体参考坐标与颜色见 [design-tokens.json](design-tokens.json)。

证据浮窗位于右上角，人物脸和底部对白保持可见；在1672×941参考图中，浮窗底边约549，对话框顶边573，留24像素间隔。浮窗采用左列表、右详情，确认操作固定在内部底部。实际实现根据对话区域位置动态限制高度，长内容内部滚动。

界面只在新场景和新人物旁显示小型灰色 New 标。场景第一次进入后清除，人物第一次开始交谈后清除；回溯保留已读记录。未解锁场景不显示名称或New，不能提前暴露侧帐。

## 核心模块与玩法约束

|模块|可用行为|
|---|---|
|场景与人物选择|先选择地点，再点击场景中的人物或姓名，或选择调查热点|
|剧情对话|对白确认、话题选择、结束交谈返回场景|
|证据与记忆|保留右上纸色横向入口和数量，可浏览已取得证据与回溯记忆|
|出示证据|仅对可接收证据的人物持续显示竖签；点击列表选中，明确确认后出示，条件不符时给出人物回应|
|回溯记忆|可查看旧轮信息；旧凭条不能成为本轮许可|
|关键交涉|魏延有效出示后直接开放输入；查看提示可填入沟通方向，编辑后由玩家提交；服务失败保留草稿|
|行动交接|递报、请乙到场、军情交接、收取回话、转达原话均须实际执行|
|结算和回溯|区分普通灯灭、保灯处斩、保灯生还；回溯清空本轮道具和许可|
|设置、存档、帮助|当前提供稳定自动档和恢复；手动槽位尚未实现；帮助说明核心流程|
|重玩本关|设置左侧的朱红强调入口；确认后清空本关进度、证据、回溯记忆和已读记录，从开头重玩；取消保留进度|

剧情唯一来源为 content/chapters/wuzhang/chapter.json，配合 docs/五丈原_教学关卡剧情本_v02.md。不得根据概念图擅自增加角色、地点解锁或许可。图中的证据名、台词和条件是设计时的排版样例，正式界面以当前章节数据为准；三线索判断在收齐相关信息后由正常对白流程呈现，不设「整理线索」入口。UI08回溯图的高亮为示意，实际落点中军帐门应高亮；UI11存档示意中的手动槽位为设计预留，当前试玩只有稳定自动档。
