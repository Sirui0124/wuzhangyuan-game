# G5 共同补救与归途｜分镜脚本

7个逻辑段，27次请求，预计275秒。每请求4–15秒；所有文书/演出不自动朗读。

情绪推进：接受留下并如实署名 → 信件实际寄出 → 远方撤回并署名 → 真实回营核阅 → 正式收件与担责 → 扶空车南撤 → 旧卷引向更早时点。

V34仅信使目击；V35才回到玩家。V32A后、V35后分别保留确认UI。V42仅E1/E3共用一次，不为其他结局自动播放。
