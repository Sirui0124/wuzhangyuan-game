# 撤离PV续段｜认印、托付、进入地图

2026-11-17。设计提交稿，待review。用户要求设计转场与后续剧情，本轮仅完成设计及史料核对，没有提交图片/视频生成，没有修改游戏或地图任务。

## 用户原意

“下一个段应该衔接一下，设计一个转场，能够出现这个印从黑中展开在绢帕上能出现红印显示庞统【注意这里要符合历史】然后下一幕就是刘备看到之后非常难过。面对主角。

主角说：我受凤雏先生所托...
刘备：士元.....
然后传令，你可以整顿我军残部，。。。大概意思是救出我的将士。。。然后这一幕结束进入地图。”

以下对白为对上述意思的拟稿，不记作用户逐字批准台词。玩家在对白中标为“我”，画面保持第一视角，不新增玩家露脸。

2026-11-17用户本轮确认：采用铜印、红褐绦带与火光，不采用绢上红印；展示顺序调整为“先展示火光照出印底的‘龐統’，再全景展示出这是来自于这个印”。本次按此修订开场0—7秒；此确认绑定道具处理与揭示顺序，不代表印面字形、生成素材或成片已通过。

## 史实与剧情设定的边界

1. 项目既定信物是25×25毫米褐灰铜私印，低矮穿孔鼻钮，总高约15毫米，短红褐绦带。印面拟为汉篆阴文反刻“龐統”。尺寸组合、识别磕痕、庞统拥有此印与刘备认印均为本作虚构道具设定，不是出土庞统实物复原。现有文档明确篆字尚未考订，不能把AI生成的两个伪篆字当正式印面。
2. 秦汉印信用于封泥有可靠实物与馆方说明；现有核对资料不足以确认本场“庞统私印在绢帕上钤出鲜红姓名印”这一具体用法。不把后世常见的红印泥钤盖效果直接写成汉末考据事实，也不据此断言汉代绝无着色用印。
3. 用户已确认铜印方案，并将揭示顺序改为：先在暗处看见火光照亮印底刻痕，再拉开呈现完整铜印、红褐绦带与托印绢帕。印底字须反刻，印出的字才正向；不能为观众易读而把刻面写成正字。观众通过“凤雏先生”和刘备“士元……”识别故人，不依赖看懂两枚汉篆。
4. 如果坚持“绢上鲜红字显影”，只能作为明确的非写实片头图形设计备选，不能声称符合汉末日常用印。本稿不默认采用该备选。更考据的实体印迹可另用封泥，但需增加有合理来由的封缄文书，不凭空在旧交印道具中多出一块封泥。
5. 《三国志·庞统传》载其战死后“先主痛惜，言则流涕”，支持刘备提及庞统时的悲痛人物依据；不证明刘备在夷陵收到此印、说过本稿台词或下过本稿军令。庞统在夷陵前已亡故，本段承接本作既有梦中托印设定，不能把托付解释为他此时仍在人世。
6. 私印只能作为身份凭信，不能自动赋予玩家调兵权。刘备明确下令后，玩家才获得本场指定的接应人马与收拢任务。设计稿不替程序提前授予权限或判定救援成功。

## 场景与核心动作

接v2.14末尾的夜间撤离。地点拟为撤退线外侧临时驻脚的帐棚/避风处，不突然进入明亮、整洁的大殿。矮案上放军图，帐外仍有人撤离，但不加可辨喊词。刘备仍穿撤退中的旧衣甲，脸上有疲惫和少量灰尘，年龄与面貌需另从当前角色素材确认，不从研究截图擅自指定演员。

唯一主动作：我递出故人信物，刘备认印后把接应任务交给我。

## 转场：从暗处印文，拉开揭示铜印与绢帕

上一镜结束时，选拉车士卒握紧车柄的动作，不再使用完整结尾淡黑。最后约0.3秒让暗色衣袖/车旁遮挡掠过画面的一侧，作为剪辑接点；如果原片没有足够遮挡，不硬造人物或用突兀黑色矩形遮盖，改为8—10帧的短暗场。

黑中先听见绢帕轻微摩擦。下一镜从印底极近特写开始：帕角移出光路，来自右前侧的火光擦过铜面，依次照出阴刻“龐統”的边缘；起初不让整个印体、印钮和双手进入画面。不用光束扫描或文字显影，亮暗变化由帕角移开、固定位置火源的自然跳动产生。

随后镜头沿原视线平稳拉开，从印底特写退到完整道具近景，才揭示这是一枚由我的手托在旧绢中的铜印。左掌隔绢承重，右手两指扶住印体侧缘；印体略侧卧，刻面朝上并倾向我的视线，鼻钮由绢褶垫住，红褐绦带自然垂在旁边。拉开期间不翻转铜印，手指不挡刻面，防止印底与印钮互换或道具变形。这里的“全景”指完整展示铜印及托持关系，不骤然切到整个营帐远景。

待铜印全貌建立后，我的手才轻微调整角度将其递向刘备，接第一视角抬镜。通过一次拉开完成“刻痕—物件—持物者”的信息揭示；不绕印旋转，不让印悬浮、发光或变大。微距到手部近景可分两段拍摄，以同一刻痕位置、角度和光向匹配接合，不强求模型完成大跨度变焦。

火场轰鸣在转场前衰减，跨过黑场留下低而远的火声；布料和呼吸成为近处声源。无音乐、无钟声或史诗音效。

## 建议时长与分镜（约39秒续段）

| 相对时间 | 画面与动作 | 摄影与声音 |
|---|---|---|
| 0—3秒 | 暗处印底极近特写。帕角移开光路，火光照出阴刻“龐統”，先只见刻痕和旧铜表面，尚不展示完整物件。 | 机位先稳住，让刻面有短暂可辨时间。布料轻响，无显字音效；字形须考订并按反刻制作。 |
| 3—7秒 | 镜头平稳拉开，依次露出印体边缘、侧面的鼻钮、红褐绦带、展开的旧绢与承托双手，揭示完整铜印。末尾手将印略递向刘备。 | 保持刻面朝向和光向，完成一次由细节到整体的揭示；不靠旋转印章展示全貌。绢、手与铜印接触清楚，重量始终有支撑。 |
| 7—12秒 | 第一视角抬起，刘备在案后面对我。视线先落在我手中的铜印，再看向我。 | 从手抬到刘备中近景，单一抬镜；我画外说第一句，刘备闭口听。 |
| 12—18秒 | 刘备的手伸到印前，指尖停一下，再托住印身。他低头，拇指轻触旧绦，唇动后只说出“士元……”。呼气停顿，眼眶发红。 | 中近景慢推很短距离；不仰头号哭，不切幻影回忆，不做长篇解释。 |
| 18—23秒 | 刘备把印连绢轻放在案上，向身侧传令军士转头，下令。 | 轻微扩展构图露出旁侧军士的肩部；只让刘备发声，不新增军士回复。 |
| 23—31秒 | 刘备重新面对我，明确交代收拢与接应任务。说完后看住我，留半拍。 | 回第一视角中近景，眼线接近镜头，不与画外无关方向对话。 |
| 31—35秒 | 刘备补上最后一句，声音比军令低。手离开铜印，转向案上军图。 | 不再强推人脸；让手的方向带领下一镜。 |
| 35—39秒 | 我的视线顺着他的手落到军图，镜头俯下，图上山川填满画幅。图面与地图界面在河道/山脊轮廓上对齐切换。 | 实拍图只画地形，不生成现代UI和随机地名；地图界面由游戏渲染，不交给视频模型生成。 |

具体秒数待自然语速与表演预演校准，不用加速台词强塞时长。接在39.42秒PV后，总长约78秒；这是新增剧情段，不为保持原40秒删掉已确认内容。

## 对白拟稿（按说话人分段）

我：
“我受凤雏先生所托，持此印来见陛下。”

刘备：
“士元……”

刘备向身侧传令：
“传令，拨一队人马，听他调遣。”

刘备重新面对我：
“你去收拢残部，接应尚未撤出的将士。”

刘备：
“把他们带回来。”

这些说话人标签和动作说明绝不能读出。第一句仅我画外发声，刘备听时不做口型；其余仅刘备画内发声。无新增答话、旁白和BGM。最后一句保留为对眼前人的具体请求，不另加主题口号。

## 进入地图

视觉交接点为军图地形填满画面，随后接当前游戏地图的同方向构图。先以现有地图的河道和营区布局反向制作实拍军图，避免视频拍完才发现地形接不上。军图可用绢帛材质表达，不凭空增加准确历史坐标或现代网格。

进入地图后，由既有章节运行器记录“刘备已授权接应”这一事实，再按原有救援条件开放相应选择；不因播放视频直接宣布残部已收拢、人物获救或全部区域解锁。此为衔接意图，本轮不修改程序和既有机制。不要恢复已取消的线索列表、收集提示和思绪推理界面，也不要再用旁白把同一军令重复念一遍。
