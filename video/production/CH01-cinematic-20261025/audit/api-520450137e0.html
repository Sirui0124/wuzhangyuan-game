查询单个任务状态和结果

Draw
https://draw.openai-next.com
Draw
https://draw.openai-next.com
GET
/hailuo/v2/query/video_generation/{task_id}
查询单个视频生成任务的状态和结果。查询已失败任务仍返回 HTTP 200，以 task.status=failed 和 task.error.code 表达结果。
成功任务的结果位于 task.content.url，该字段是完整的公开 HTTPS 直链：
服务在视频发布成功后的 24 小时内不主动删除该业务结果；实际删除可能更晚
再次查询不会刷新或重新计算最早删除时间
下载 task.content.url 时不要携带 Authorization
公开对象支持普通 GET 和 Range GET（有效 Range 请求返回 HTTP 206）
对象被清理后存储层可能返回 404、403 或其他响应，任务状态仍保持 succeeded
如需长期保存，应在任务成功后尽快把视频下载到自己的存储

usage 口径#

input_seconds：参考视频时长与独立参考音频时长之和；视频内嵌音轨不重复计算
input_image_count：全部输入图片数，包括首帧、尾帧和参考图片
output_seconds：客户请求的名义输出秒数
total_seconds：为兼容现有计费，当前与 output_seconds 相同

Authorization
Bearer Token

Authorization
