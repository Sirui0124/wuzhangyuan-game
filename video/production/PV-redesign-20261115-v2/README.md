制作源文件为`prepare.py`、`build_review.py`、`separate_background.py`、`write_production_docs.py`及`make_review_page.py`。`storyboard.json`逐镜记录采用来源与source in；`work`为可再生成的中间文件。原生声音拼接采用PCM，整片只编码一次AAC，避免多段AAC编码延迟累计；画面为24fps、1280×720的工作预演，不称原生1080p或4K。

验证记录见`final-verification.json`与`browser-verification.json`。解码、计时、图片查看、抽帧、浏览器技术播放和用户通过分别记录。没有完成新视频动作、正确台词与口型、全片人工逐字听审、终混、用户通过或游戏接入。
