# 字幕集中维护

当前游戏字幕只维护 `GameStarter/web-demo/public/video/subtitles/*.vtt`。`chapter-one/*.draft.json` 是历史策划候选，不是成片转录，不导入游戏。

- `GameStarter/web-demo/public/cinematics.json` 是播放器唯一的影片—字幕引用入口，两章与视频审阅页共用。
- 本目录 `catalog.json` 集中记录每段影片的版本 SHA-256、字幕 SHA-256、时间范围与条数。视频实际文件哈希由 `npm run check:assets` 验证；正常构建会检查字幕清单，发现更换视频或字幕后未核对的版本变化便报错。
- `GameStarter/web-demo/public/subtitles.css` 统一透明底白字。原字号、位置与第二章既有字体规则保留。
- 每条字幕只删除最后的逗号或句号（中英文）；中间标点、问号、叹号、省略号保留。跨行字幕仅处理整条的末尾。

修改字幕时，以实际采用影片的对白和时间轴为依据。策划台词和 ASR 仅用于比对定位，不能把未在影片发声的台词补进字幕；不修改原始对白、配音或生产审核记录。核对实际影片后运行 `npm run subtitles:sync`，再运行 `npm run build` 和 `npm run check:assets`。只检查、不写入用 `npm run subtitles:check`。

2026-10-26 本次对已有字幕只做句末标点清理，程序逐条验证对白其余文字与时间轴未改变。117 段影片、359 条现有字幕均通过时间范围与版本绑定检查。原有制作记录的人工听审状态继续保留，不因本次样式和文件校验变成已通过。已知第二章 V11T、V11D 原字幕为空，历史定位报告存在未能完整定位对白的问题，仍须逐句听审，不用策划文字猜填。
