# 五丈原：守住这一盏灯

版本：v02，2026-10-11。用途：剧情、玩法与 UI 共用的教学关卡底稿。

本版落实两条核心路线：**直接阻止魏延 → 灯保住、玩家被斩首 → 复活；向另一名小卒举证 → 提前联系姜维 → 执行获准的传报安排 → 灯保住、玩家生还。** 场景切换、选择人物、举证、提出方案、兑现方案均为玩家操作。

此前《时间倒流_互动叙事引擎_核心架构与流程_v01》与《时间倒流_人物与UI元素拆解_v01》中，如有“第一轮即可按原流程安全通关”“说服即成功”“失败只回当前节点”的描述，以本版为准。既有的证据系统、有限 AI 判定、事件推进时间等架构继续使用。

## 一、史料边界与人物动机

本关以《三国演义》的祈禳情节为故事舞台，以正史资料补充北伐背景；教学中明确区分三类内容：正史记载、演义情节、游戏补写。

| 内容 | 依据与使用方式 |
| --- | --- |
| 诸葛亮在五丈原与司马懿对峙，最终病逝 | 《三国志·诸葛亮传》记载建兴十二年出兵、屯田、相持百余日及秋八月病卒。作为时代背景。 |
| 祈禳、主灯、魏延闯帐导致灯灭 | 《三国演义》第 103 回的情节，不能作为正史讲解。祈禳已经进行至第六夜，本关倒退至这一夜之前的傍晚。 |
| 魏延为何进帐 | 演义中魏军前来试探，魏延急报“魏兵至矣”。他急于报告真实军情，不能写成蓄意害诸葛亮。 |
| 姜维的位置 | 演义该时刻姜维就在帐内。第二路线的“提前联系姜维”应通过传令卒从帐外通报，不能把姜维写成原本远在别营。 |
| 原作对魏延的处置 | 第 104 回诸葛亮制止姜维杀魏延，认为不是魏延之过，并让魏延出迎敌军。游戏不能借此声称诸葛亮会杀救灯之人。 |
| 玩家越职截报被处斩、传令侧帐、凭条、回执 | 全部为游戏补写。处斩是架空分支的戏剧设计，不能展示为真实军法条文或史书记载。 |

史料链接：[《三国志·诸葛亮传》](https://m.gushiwen.cn/guwen/bookv.aspx?id=46653FD803893E4F775CCC007CA82E1C3EBFA45D531B8D0F)、[《三国演义》第 103 回](https://zh.wikisource.org/zh-hans/三國演義/第103回)、[《三国演义》第 104 回](https://zh.wikisource.org/zh-hans/三國演義/第104回)。

**魏延的核心动机：军情必须抵达能处置的人，不能因为帐门禁入而耽误。** 他不知道玩家掌握未来，也不会因为玩家说“你会害死丞相”就相信。说服他的有效理由，是提供可靠、及时、有人负责的替代通报途径。

玩家穿越后处于一名普通值守小卒的位置。能询问、取证、递话，但没有调兵或改变紧急军情传报的权限。此身份与权限为游戏设定。

## 二、关卡目标与最小范围

首轮显性目标：阻止魏延闯帐，守住主灯。

复活后新增目标：守住主灯，并让军情及时送达、让自己活下来。

通关条件同时检查：主灯未灭、军情已送达姜维、获准的处置已执行、玩家存活。**对方答应方案只打开后续行动，不能直接结算成功。**

建议完整体验 12—18 分钟。仅做三个主流程环节：帐门调查、魏延交涉、传报执行；复活后帐门调查多出一个侧帐场景。四张场景底图、四名可对话角色、四类证据、两次关键举证；不做移动战斗、复杂地图或实时倒计时。

## 三、场景与人物选择

| 场景 | 可选择的人物 / 热点 | 主要操作 |
| --- | --- | --- |
| 中军帐门 | 守帐卒甲、禁入告示、帐帘 | 问值守规则；查看告示；听见帐内咳嗽；首轮与复活落点。 |
| 营前传报处 | 斥候、魏延 | 听军情，取得证词；选择魏延开始交涉。这里只表示营内传报位置，避免营外自由探索。 |
| 传令侧帐 | 传令卒乙、递话窗口 | 首轮死亡后出现新的场景引导；向乙举证、通过他与帐内姜维取得联系。 |
| 中军帐外候报处 | 魏延、传令卒乙、军情交接点 | 出示获准凭条、交接军情、等回执、落实魏延的行动安排。与帐门可复用底图。 |

场景切换采用画面边缘或底部的地点按钮。进入场景后，点击人物或人物名选择交谈对象；“出示证据”针对当前人物，不自动默认魏延。不能用连续自动对话代替全部选择。

第一轮不显示“传令侧帐”的导航入口。侧帐本来就在军营中；玩家在临死前得到线索，复活后才知道如何寻找。第二轮新入口显示一次“你记起了另一条传报途径”，随后恢复普通地点样式。

## 四、开场影片：先看见失败

电视光照在主角脸上。画面里，魏延急步掀帘，主灯熄灭。主角低声说：“要是有人拦住他……”画面倒转：帐帘落回、灯火重燃、天色退到傍晚。主角低头看见自己穿着小卒衣服。

不解释完整穿越规则，只显示：**第六夜·傍晚。你记得灯会灭。**

此段可以用 15—20 秒影片；后续线索与选择使用静帧、对白与局部动效。

## 五、第一轮：救下灯，却没有救下自己

### 环节 1：帐门调查

玩家选择守帐卒甲。

甲：“今夜帐内有要事，闲人不得入。”

选项：

1. “若有军情呢？”——甲：“急报不能扣。你我只管守门，不能替将军改传报的规矩。”获得【守帐卒证词】。
2. “谁在帐里？”——甲：“姜将军在。”获得【姜维在帐内】这一事实，记入笔记。
3. 查看禁入告示——获得【禁入告示摘录】；证据说明明确：禁止闲人入帐，未授予玩家截留紧急军报的权限。

玩家可以切换至营前传报处，不强制点完全部对话。缺少证据时，关键交涉会提示可继续调查。

### 环节 2：识别魏延的目的

玩家选择斥候。

斥候：“魏军向我营逼近，前头已见兵影。魏将军要亲报中军。”

追问“已经攻破营门了？”——斥候：“尚未。我奉命回来报信，敌军到底何意，还不能断言。”获得【斥候军情证词】。

本关只要求识别“真实急报”和“已经失守”不同，不要求玩家证明敌军一定只是试探。玩家知道原作也不能把敌军试探当成当前已经证实的事实。

选择魏延后，他说：“军情紧急，我须入帐面禀！”

可选回应：

- “你会把灯弄灭！”——魏延：“你如何得知？军情岂能凭怪话耽误！”反馈缺少可验证依据，可再举证。
- 出示禁入告示，只说“任何人都不能进”——魏延指出急报例外，反馈告示不能支持该结论。
- 出示禁入告示与军情证词，输入理由，建议“请姜维接报，魏延先留在帐外”——进入直接干预路线。

开放输入提示：**你为什么认为不必闯帐？军情由谁接，怎样送达？**

示例表达：“帐内今夜禁止外人进入，姜将军就在里面。军情不能耽误，请先在帐外递报，叫姜将军出来接应。”

AI 可认可这是一项合理的替代建议，同时指出玩家尚未取得姜维同意。魏延的回应固定到已编写分支，不由 AI 自行承诺权力或剧情结果。

魏延：“好，你去叫姜维。我就在这里等你的回话。若军报误了，你担得起吗？”

状态变成【魏延暂缓入帐】，尚未保灯成功。画面给出两项行动：**去帐门叫姜维 / 返回解释办不到**。

### 环节 3A：兑现直接路线

选择“去帐门叫姜维”。玩家向守帐卒甲提出改变传报安排。

甲：“你未受命，不能擅改急报。要这么做，我会照实报上去。”

选择：

- **“先把军情递进去，责任由我承担。”**——执行越职转报；这是明确标识风险的行动选择。
- “收回安排，告诉魏延照原途径报告。”——魏延闯帐，灯灭，进入普通失败回溯。

选择承担后，玩家必须点击【交付军情】。守帐卒将急报送入，姜维得报后出帐处置，魏延跟随接令，主灯持续燃烧。若玩家离开去做无关行动，到下一次剧情推进时魏延不再等待，原失败发生。

保灯影片 8—12 秒：魏延停在帐外；姜维掀帘出来；镜头越过两人，帐内主灯仍明。

随后进行军情传报追责。游戏补写的军法执行者认定玩家越职截报、擅改传报安排，下令处斩。此处是本游戏架空的严酷规则，不援引真实军法，也不让诸葛亮亲自下令杀玩家。姜维此前的军事处置不等于对玩家程序的追认。

为避免毫无铺垫的惩罚，前面的证词、甲的警告和“承担责任”选项必须保留。演出用被押走、刀影、黑场即可，不制作血腥镜头。

押送时，传令卒乙经过，说：“你若先来侧帐递话，得了姜将军的准信，何至于此……”

结算分别显示：

- 主灯：守住。
- 军情：送达。
- 玩家：越职转报，被处斩。

玩家最后看见的仍是亮着的灯。黑场后出现【回到傍晚】；保留记忆，重置物品和当夜行动。

### 普通失败与教学死亡的区别

灯灭：目标未达成，回溯后给出失败原因。第一次普通失败不会自动解锁侧帐，避免“随便失败都能拿到关键线索”。

保灯后处斩：达成局部目标，获得乙的侧帐线索，开启第二核心路线。该影片完整播放一次；再次走同路线可跳过。

## 六、第二轮：先取得准信，再让方案成立

### 环节 1B：发现另一名小卒

回到同一个傍晚。禁入告示、斥候证词等实体证据须重新查看或询问，可以提供“按记忆快速确认”按钮，避免重复长对白。旧笔记保留来源与内容，标为【上一轮记忆】，不能直接作为本轮凭证出示。

新导航入口【传令侧帐】出现。玩家主动切换，并选择传令卒乙。

乙：“守门是守门，递话是递话。你找我有什么事？”

玩家出示本轮重新取得的【禁入告示摘录】和【斥候军情证词】，输入希望他做什么。

示例：“今夜不许外人入帐，但魏军逼近，急报必须有人接。请你向帐内姜将军问一句，能否由你在帐外接报，交给他处置？”

这里的证词冲突是：**不让外人进帐，并不意味着军情不能进入。** 解法是取得可靠传报途径，不是宣布急报不重要。

判定要求：说明禁入与急报的同时存在；引用本轮证据；请求递话，不冒称已经得到姜维命令。乙没有调兵权限，不能直接批准玩家的军令。

### 环节 2B：和姜维打招呼

乙答应代为通报后，出现行动【托乙向姜维递话】。玩家必须点击，才算递出请求。

可以在递话界面选择一句预设请求，并补充文本：

- “请确认今夜急报的接收办法。”——推进。
- “请把守帐和应敌一起安排妥当。”——推进，仍由姜维决定具体军令。
- “命魏延不得靠近中军，军情明早再报。”——不接受，反馈延误军情且玩家无权命令。

短对白或影片：乙从帐外通报，姜维到帘边听取请求。

姜维：“军情不能迟。来报的人在帐外候着，由传令卒递入；有敌情，我出帐处置。你去告知文长，勿误传。”

获得【姜维传报凭条】。此物为游戏补写的有限授权凭证，说明：**只证明该夜这次军情可由乙转递，不能调兵、拘押将领或替姜维下战术命令。**

### 环节 3B：说服魏延并完成交接

切换到营前传报处，选择魏延。玩家出示【姜维传报凭条】，同时引用军情证词，输入交接安排。

示例：“姜将军已让乙在帐外接报，他本人出帐处置。请将军把军情交给乙，在候报处等回话；无需闯帐，也不会耽误应敌。”

魏延：“凭条我看过了。报信的人呢？你带来，我当面交代。”

对话通过后，连续执行三步，均为明确可点击的行动：

1. **到侧帐请乙来接报。** 乙到候报处；不能用“我已经叫过他”一句话替代。
2. **选择魏延，交接军情。** 魏延向乙讲清敌情，乙递入；证据卡更新为【已交接】。
3. **选择乙，收取姜维回话。** 姜维确认收报并出帐，向魏延安排应敌。玩家选择【转达原话】，魏延领命。

不做部队微操。军令修订表现为玩家提交“传报程序建议”，姜维批准、调整并发布；本关玩家不能自行更改战术。

接报、回话、领命三步完成后播放安全结局影片：魏延与姜维在帐外交接，主灯不灭，玩家仍站在帐门边。

## 七、方案兑现与失败反馈

| 玩家行为 | 世界结果 | 反馈 |
| --- | --- | --- |
| 说服魏延，却没有去递话或找乙 | 等待到下一个关键事件后魏延入帐，灯灭 | “你提出了传报办法，但接报的人没有到场。” |
| 把旧轮记忆当姜维本轮命令 | 不授予凭条，不进入授权路线 | “你记得他说过，不等于这一夜已经得令。” |
| 只证明不能进帐，不安排军情出口 | 魏延不接受 | “禁入的理由成立，急报的问题仍未解决。” |
| 凭条获准后提出关押魏延、拖到明早 | 超出授权，要求修订 | “凭条只准转报，没有拘押或延期的权限。” |
| 军情递入却没取回话、没转达 | 尚未通关，显示未完成交接；推进关键事件才结算失败 | “姜维已有回话，魏延还在等你。” |
| 直接路线完成传报 | 保灯、玩家被处斩，解锁侧帐 | 明确分开局部成功与玩家死亡。 |
| 授权路线交接全部完成 | 保灯、军情送达、玩家生还 | 本关完成。 |

不以真实秒数计时。读文本、输入或等 AI 不消耗事件时间；调查、交接、转移至与承诺无关的地点等剧情行动才推进事件。给予一次临界提示“魏延正在等回报”，再进行失败结算。

## 八、AI 判定与固定剧情的边界

普通调查、选择人物、切换场景、交接和死亡结局由固定节点驱动。AI 只用于两类关键输入：证词举证、传报方案修订。

判定输入包括当前人物、当前证词、玩家选择的证据 ID、本轮已知事实、当前授权与玩家文本。输出有限结果：通过、缺证据、方案不完整、超出授权、待澄清。每次说明具体哪项事实或行动未满足。

通过后只能进入预设节点。AI 不能判定“魏延忽然背叛”“姜维提前离营”“玩家靠一句话拥有统帅权”，也不能自行触发斩首。直接路线的追责由固定世界状态触发。

开放输入接受不同措辞与合理等价方案，不要求背标准答案；程序检查实际行动与授权。网络失败保留输入，允许重试或用预设示例提交，不扣剧情时间、不造成死亡。

## 九、实现状态与 UI 交付要点

最小状态：

```text
永久记忆：seenLampFailure / seenExecution / knowsRelayTent
本轮证据：entryNotice / scoutStatement / guardStatement
本轮许可：jiangWeiApproval
本轮执行：weiYanWaiting / relayRequestSent / relaySoldierPresent
          reportDelivered / replyReceived / orderRelayed
结果：lampLit / playerAlive / unauthorizedReroute
```

`seenExecution` 才解锁 `knowsRelayTent`。回溯重置本轮证据、许可和执行状态；“按记忆快速确认”重新生成当轮证据，不复制旧授权。

保灯直接路线需 `reportDelivered=true`；其 `unauthorizedReroute=true` 触发架空追责。安全通关要求 `jiangWeiApproval && reportDelivered && replyReceived && orderRelayed && lampLit && playerAlive`。

UI 需要兑现的选择与反馈：

- 场景入口；当前场景可选人物；证据明确出示给当前人物。
- 复活后侧帐新入口的一次性引导，保留玩家主动选择。
- 证据卡显示来源、上一轮记忆 / 本轮确认、授权范围。
- 对方答应后的轻量行动提示：“去递话”“带乙来”“取回话”；完成后切换到下一步，不叠加复杂任务面板。
- 姜维凭条与军情回执的获得反馈；成功结算分开灯、军情、玩家三个结果。
- 死亡后的回溯入口；重复影片跳过；输入保留与技术错误重试。

## 十、关卡收尾与验收

安全结局中，姜维回帐，玩家从帘缝看见主灯仍明，但诸葛亮的咳嗽没有停止。提示：**“你守住了这一夜。此前的病与劳损，还没有改变。”** 随后解锁向更早时间回溯的入口。不要把“灯不灭”直接写成诸葛亮永久痊愈，也不要用立刻无条件病死抵消玩家刚完成的成果。

后续关卡可沿用既定北伐粮运危机与谷中失机方向；本关只展示章节入口，不制作后续完整内容。

验收场景：

1. 首轮通过场景与人物选择取证，直接阻止魏延；玩家实际递报后灯保住，处斩、复活、新侧帐引导顺序完整。
2. 首轮只说服不执行，灯仍会灭，不能假成功，也不能凭普通失败解锁侧帐。
3. 复活后向乙举证、实际递话、获得姜维凭条，再说服魏延并完成三步交接，灯保住且玩家生还。
4. 旧轮凭条不能沿用；AI 同意不能代替交接；AI 故障不能推进时间。
5. 两条路线的结局、场景入口、人物选择、证据来源与行动提示在 UI 上可辨识。
