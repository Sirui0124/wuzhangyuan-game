# 五丈原：开发选型与接入

2026-10-11

## 当前决定

当前试玩继续使用 **HTML + TypeScript**。界面以 `UI设计` 线程（01a128be-dc5d-7320-a92c-95b79026192a）的定稿资产为准；剧情读取正式 `content/chapters/wuzhang/chapter.json`，状态和规则复用 `GameStarter/assets/scripts/narrative/`。

当前核心操作是点击地点与人物、读对白、调查、整理线索、出示道具与证据、交涉、执行行动、观看结局、回溯地图和重新调查。浏览器已经能验证完整闭环；现阶段主要工作是调整剧情条件、信息表达和交互排布，因此继续在现有 HTML 试玩层开发更合适。这是根据当前工程和玩法作出的工程判断。

## 与 Cocos 的比较

| 判断维度 | 当前 HTML + TypeScript | Cocos Creator 3.8.8 |
| --- | --- | --- |
| 当前文字、证据、对话界面 | 已接入，浏览器可直接试玩 | 需将布局重建为节点、组件和预制体 |
| 剧情与重开规则 | 复用现有独立核心与正式章节 | 同样可以复用核心与章节，另写界面适配 |
| 当前视觉需求 | 场景图、人物镜头、浮窗可直接实现 | 可以实现，但目前主场景还未接入玩法 |
| 后续动画与场景编辑 | 需要按实际需求补充工具 | 编辑器更适合组织复杂场景和动画资源 |
| 平台发布 | 当前只验证桌面浏览器 | 有 Web、原生和小游戏构建流程，仍需逐平台验收 |

Cocos 也支持浏览器发布，不能以“需要浏览器”作为排除它的理由。平台能力以 [Cocos 3.8 构建发布文档](https://docs.cocos.com/creator/3.8/manual/en/editor/publish/index.html) 与 [Web 发布文档](https://docs.cocos.com/creator/3.8/manual/en/editor/publish/publish-web.html) 为依据。

当目标明确为微信/抖音小游戏或原生安装包，或玩法需要大量场景动画、角色移动与实时交互时，再评估切换 Cocos。届时保留剧情 JSON 和 TypeScript 核心，重写 Cocos 界面与平台适配；现有 HTML 画面不能一键迁移为 Cocos 场景。

## 当前接入

[美术试玩](http://127.0.0.1:8811/)与[基础白模](http://127.0.0.1:8811/?white=1)共用规则、剧情和本机存档。HTML 读取正式章节，场景与人物采用 UI 资产；整屏参考图仅作为设计依据。斥候已替换为透明 v02 人物。

当前 v06 只有两次关键魏延交涉。第一次先禁令、后斥候证词，成功后显示牺牲结局；重试本关并重来进入第二轮。第二次先禁令，再逐项出示营门未失守和姜维接报两张证词，只有实际提交齐全才出现输入框。成功后直接由写定剧情执行接报，没有第三次 AI、旧版许可或四步交接。两次均有成功、入帐灯灭、严重挑衅处斩三种结果。

五种结局的文案独立保存，底部仅「重试本关」「返回首页」。终局前稳定存档与终局自动档分离，读档可继续改变表达；重来清空本轮证据、NPC状态、历史和草稿，仅保留教学完成标识与独立收集/地图进度。

安全结局对白后播放 EN01 → EN03+EN04，影片后显示结局；返回首页显示黑屏“下一次时光倒流：北伐粮运危机”，随后进入山河回溯地图；失败结局直接返回地图。北伐粮运已解锁但筹备中，谷中失机仍锁定，均不可进入。教学牺牲在对白结束后播放已剪辑的 EN02 v02，约12.96秒，保留完整问罪台词及架走镜头；灯灭及严重挑衅不播放结局影片。结局页和首页地图可打开独立「我的结局成就」卡册，调查过程中及临时地图隐藏入口；帮助为最右侧的圆圈问号。历史解锁记录跨重玩保留。

## 验证与边界

正式章节版本为 `69b7e1b15a782bbda26cc1ac23eebc2d0841387db8cc90b5cbd78e25ad270f01`。规则单测、TypeScript、结构校验和浏览器流程分别验证；最终结果以各报告时间和版本为准。

逐项举证已在美术/白模 ×1672/390 验证单选替换、取消、重复与错误不推进、部分与完整刷新、离开重新确认禁令、反向证据顺序与重开清空。结局验收覆盖五种结果、终局前重试、首页与收集。语义判定 mock 的报告不能当作真实 AI 质量结论；实际代理路线记录于 `v06-routes.json`，编剧另做多轮分类/措辞模拟并分别记录语义结果和技术失败。新增输入大弹窗与 AI 润色由编剧另行验证，不计入较早的 v06 整合快照。

当前媒体清单包括开场、通用守灯、新版问罪、最终结局四份视频；旧问罪文件保留作历史资料。新版问罪已验证只在教学牺牲分支播放，并覆盖倍速、拖动、刷新续播和自然结束；HTTP Range 与文件指纹另记。成就卡册分别验证独立页面、游戏入口与旧记录只读。当前仅验证 HTML 浏览器；Cocos 主场景尚未挂载叙事玩法，不能将 TypeScript 编译或 HTML 试玩通过等同于 Cocos 试玩通过。
