# Cocos 开发环境

配置日期：2026-10-11。

## 已配置

- Cocos Dashboard 2.2.2，中文界面。
- Cocos Creator 3.8.8，安装在 `/Applications/Cocos/Creator/3.8.8/CocosCreator.app`，支持 Apple Silicon，应用签名验证通过。
- Dashboard 已登记本文件夹下的 `GameStarter` 工程。
- 使用空白 2D 模板、TypeScript；主场景为 `assets/scenes/Main.scene`。
- Creator 默认脚本编辑器已保存为 `/Applications/Visual Studio Code.app`。
- `GameJam.code-workspace` 可用 VS Code 打开；2026-10-18 已将空 Git 仓库边界扩到整个工作区，仍无提交。

## 开始使用

1. 在 Dashboard 打开 `GameStarter`。
2. 双击 `assets/scenes/Main.scene` 打开主场景。
3. 点击编辑器顶部的运行按钮，在浏览器预览。
4. 在 `assets/scripts` 添加 TypeScript 组件，在场景节点上挂载组件。
5. 后续每款独立游戏创建自己的工程目录；原始素材放在工作区 `source-art`。
