## 分类与清理

`GameStarter/web-demo/visual-assets.json` 为游戏图片绑定的唯一来源；`runtime-map.json` 是其导出镜像。角色、场景、系统图标分别放在 `runtime/characters`、`runtime/scenes`、`runtime/ui`；空间模型单独放在 `spatial/camp-v1`；抽帧证据与图册放在 `review/20261022`。详见 [目录规则](../../source-art/visuals/ASSET-ARCHITECTURE.md)。

E1/E2 两张已明确停用的风格旁支移至 archive 并记录原路径与哈希。四张本轮生成的木板／麻纸／朱印／深麻布 UI 样品在用户反馈后撤下，移至 `archive/20261022/ui-material-prototypes`，不进入游戏构建。历史人物、视频参考包与现行 Prompt 引用原件保留，不能把未绑定图片一概当成无效文件。没有永久删除或改动 Cocos `.meta`。

## 场景与空间

中军帐前、传报处、姜维帐前三张新背景已经独立绑定。修正了原“姜维帐前”复用“传令帐内向外看”图的问题。中军帐与20261022视频保持闭帘主帐、黑旗、低位灯和开阔前场的视觉锚点；传报处改为小型开放棚与低案；姜维帐为较小独立闭帘帐。新背景采用冷暮色和粗土，降低旧图的金色高光与大片湿地反射。

Astra 已制作营区总平面、主帐内部平面、人物朝向、机位、通行轴线与灯位，交付3份真实OBJ、MTL和离线WebGL预览。它是可复用的空间样机，不是影视精模。尺寸和坐标是本轮设计约束，不是从既有视频实测还原。图像生成保留了主要空间关系，但远山、霞色与小道具不能保证逐点一致；不同时间段仍须按具体镜头复核。详见 [空间报告](camp-spatial-20261022.md)。

旧流程专用传令帐、候报处、合成人物镜头仍保留旧绑定；主菜单与章节舆图保留既有构图。它们已被盘点，不冒称全部完成重制。第二章目前以视频预览为主，本轮没有凭空增加尚不存在的可玩地点或人物交互。
