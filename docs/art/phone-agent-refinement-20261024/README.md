## 原三版探索（历史）

- **B1 留白**：去掉助手气泡的整圈边框，商品只留一段短线，减少重复的图章和强调色，让文字先被看见。
- **B2 墨笺**：用户已选定。在留白基础上，给商品一层淡墨纸、一个微小纸角，输入区有轻微材质。印章边缘略不规则；主按钮不再叠描边。
- **B3 微光**：将细节放在状态变化里；等待回复时，助手名字旁一粒暖光缓慢呼吸，输入底线轻微移动。静止时保持收敛，系统设置减少动态时停止动画。

共同调整：机身边框减薄变暗；标题、正文、辅助字重新分配亮度；助手回答与其商品建议成为同一次回复；快捷提示去掉盒子；输入区改为淡底线；购买按钮收在右下角。保留钱包、估价标签、用途限制、报价展开、明确确认才扣款和附物入口。

字体为本机华文行楷与楷体，未复制或重新分发系统字体。正文实际字形已通过Chrome核验。正文保持18–19px，辅助信息12–14px；将来的跨平台接入仍需确定有授权的完整字库。
