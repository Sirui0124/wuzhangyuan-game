# 手机 Agent 对话界面 · 四版设计稿

2026-10-24。范围是游戏中随身手机里的助手聊天界面，不是整个游戏的手机端适配。本组为可点击的视觉探索稿，未替换正式游戏，未连接模型、购物接口或存档，未获得用户审核通过。

运行 `node docs/art/phone-agent-concepts-20261024/serve.mjs` 后打开 http://127.0.0.1:8824/ 。也可直接用桌面浏览器打开本目录 `index.html`；所有样式和交互都在本地，无外部依赖。

## 方案

| 方案 | 视觉方向 | 用途 |
|---|---|---|
| A 宣纸朱批 | 暖纸、墨字、朱印、书信批注 | 最直接的古典阅读感 |
| B 玄墨金笺 | 墨灰、米金、薄边、朱砂小印 | 推荐与现有暗色山水界面统一 |
| C 青玉尺素 | 淡青玉、黛绿、柔和签牌与圆角 | 清润且有独立辨识度 |
| D 朱印军牍 | 暗朱页首、暖纸、文书竖线、票据商品卡 | 军营文牍感最鲜明 |

四版保持相同内容与功能，便于比较。可切换商品建议、日常问答、正在回复、已购买、回复中断和资金不足六种状态；可输入、发送预设回复、停止、展开报价详情、模拟购买、附物与撤下、收起与重新打开。所有金额和回复为设计示例，确认按钮只改变本页面的演示状态。

## 字体与层级

标题使用本机华文行楷（STXingkai），正文为楷体（KaiTi）18px，可切换宋体。正文、标题已用 Chrome 实际字形检查确认；没有复制或重新分发系统字体。跨平台接入时需选择有相应许可的可嵌入字体并检查完整中文字库。现有 ending-brush.woff2 是小型结局字库，不适合直接作为聊天全文字体。

钱包、助手身份固定在顶部；单条聊天流独立滚动，默认定位到最新内容；输入区固定在底部。问答与购物不拆页，保留“帮我买…”和“我想问问…”两个只填入、不自动发送的提示。标题与正文采用同一套古风字族，组件的边线、色彩和操作样式在各版内部一致。

## 玩法边界

- 商品明确显示“AI估价 · 未核实市场价”，用途限制直接可见；报价细节可展开。
- 只有确认购买才扣演示资金；已购显示回执、剩余余额和附物入口。
- 询问与购买保持同一聊天流，不新增商城、任务或背包分页。
- 等待时发送变为停止；停止或关闭保留原话；正文对玩家使用“我”。
- 设计稿中的附物演示假定处于可附物的第二轮；正式接入仍须使用真实关卡条件。

## 核对和验证

依据本轮读取的根 README、web-demo README、手机对话及商品视图、supplies.css、现有对白与思绪规范制作。已通过飞书 CLI 读取协作原则在线修订30，换行归一化后与本地副本一致。未修改在线策划或审核状态。

独立 Chrome 上下文检查1840、1366、768、390、320px宽度，六种状态无横向溢出；检查提示仅填入、空前缀不可发、模拟扣款、附物切换、取消保留草稿、收起重开；无页面脚本错误或资源加载错误。窄宽度下聊天区滚动到最新消息，购买按钮保持可达。截图禁用过渡动画，避免把中间透明帧误当成字体颜色。详细记录在 `outputs/phone-ui-concepts-20261024/verification.json`。

这是设计稿浏览器验证，不代表正式游戏、AI语义、Cocos编辑器或用户审核通过。
