# 美术资产盘点与安全整理

以下“接入前”事实来自 2026-10-22 本轮工作开始时读取的主入口、剧情 flow 和 visual-assets 绑定；最终绑定以可重复生成的 [技术清单](inventory-20261022.md) 为准。文件归类见 [架构说明](../../source-art/visuals/ASSET-ARCHITECTURE.md)，图片可直接在 [分类图册](catalog-20261022.html) 对照。

## 本轮开始时的缺口

| 类别 | 实际情况 | 处理要求 |
| --- | --- | --- |
| 人物透明度 | 六张旧人物原件中仅斥候有真实 alpha；魏延、姜维、诸葛亮、甲、乙均有不透明军营背景 | 新版本保留身份，生成真透明 PNG；旧文件保留给历史流程和视频身份参考 |
| 人物表情 | 六张角色原件均只有一种表情 | 魏延、姜维、诸葛亮至少 2–3 个独立表情；由剧情节点选择，不能随机切换 |
| 亲兵 | manifest 的 `jiangwei_guard` 复用甲；script 有 4 句 `亲兵·固定`，但旧 `personId()` 不处理“亲兵” | 补人物映射与明确的复用说明；不能把文件存在等同于实际显示 |
| 场景 | manifest 有 6 个 ID，实际仅 4 张底图；第一章 flow 使用中军帐前、营前传报处、姜维帐前三个地点 | 姜维帐前原本复用传令帐 `relay_tent.png`，需根据连续空间关系建立专用底图 |
| 系统组件 | 原 manifest 有 8 张 UI SVG，但新主入口的 `Media` 只读取角色与场景 | 逐组件接入与验证；旧 UI 图存在不等于完整游戏已经采用 |
| 结构索引 | `runtime-map.json` 标称 v1.2，运行时 manifest 标称 v1，ID 命名也有横线/下划线差异 | 以实际 manifest 为权威；旧索引明确为历史，避免双份配置互相覆盖 |

## 系统元素拆分范围

完整静态交互定义保存在 [ui-controls-20261022.json](ui-controls-20261022.json)。本轮初始扫描在主游戏四个 UI 模块找到 83 处按钮/输入定义；循环按钮以定义计一次。除按钮外，下列框体与状态也应使用同一套材质与尺寸规则。

| 模块 | 需要分离的部件 | 状态/可读性要求 |
| --- | --- | --- |
| 开始页 | 主按钮底、选中底、悬停/按下反馈、书法标题、箭头、独立文字 | 继续、新游戏、舆图、卡册、设置均独立触发，文字不烘进整屏 |
| 场景 HUD | 章印、思绪/记录/存档/设置/菜单、场景标题、数量标记 | 不能依赖发光与塑料圆角体现可点击；小字号仍清晰 |
| 场景探索 | 热点标记、地点签、当前地点标记、提示条 | 在场、可前往、不可操作可辨识，人物与背景独立 |
| 对白 | 纸面/布面底、姓名签、继续箭头、斥候两项选择 | 长对白可扩展，素材边缘不遮字，全文点击域保留 |
| 思绪物品栏 | 竖签、抽屉面、单条见闻、展开/收起、添加与关闭 | 开、关、已放入、待重组分别清楚；拖拽抓手与正文分开 |
| 推理画布 | 线索签、移除、思考印、连线端点、结果标题、行动按钮、撤回与回到当前 | 连线采用代码绘制以跟随内容；纸面和装饰可用图像，动效不遮挡操作 |
| 表达页 | 依据签、输入纸面、润色、取消、确认、回退、重试 | 等待、失败、禁用、可确认均需状态反馈；输入文字保持原生可编辑 |
| 设置与存档 | 弹层纸面、关闭、滑杆轨道/滑块、复选框、输入底、保存/读取按钮 | 原生键盘与焦点可用；API 密钥字段保留安全输入，不把配置画成静态图片 |
| 结局/舆图 | 主行动底、返回、地图节点、锁定状态、结局卡面、翻页、筛选 | 未解锁不泄露剧情；卡面、标签、文字独立 |
| 视频 | 播放/暂停、声音、跳过、进度轨道/滑块、倍速 | 与游戏 UI 同色系且遮挡少；不能破坏键盘与拖动控制 |

## 安全清理结果

E1 营门、E2 候报是原 README 已明确排除在第一视角候选之外的构图旁支，已移动到 `source-art/visuals/archive/20261022/style-branches/`。移动前检索只发现原目录 README 的文件链接，没有运行时或视频 Prompt 路径引用；链接已改为归档路径。移动后 SHA-256 与原值一致，[归档清单](../../source-art/visuals/archive/20261022/manifest.json) 可以逐项恢复。

没有永久删除图片，没有移动 `.meta`（这两张没有 sidecar），没有改缓存/构建目录。其他风格候选、用户参考、视频参考和旧人物原件全部保留。初始技术扫描没有发现损坏图片或缺失 manifest 文件，不能为了“清理”把未绑定文件判为无效。

同 SHA 的副本主要来自各轮视频制作的独立参考包；主菜单、角色和场景也在这些包内。`campaign-map.svg` 的 source-art 原件和 public 发布副本相同。这些均有明确角色，本轮不做无收益的去重删除。

## 甲、乙新透明立绘技术复核

新增 `runtime/characters/guard/neutral-v3.png` 与 `runtime/characters/relay/neutral-v3.png`，均为内置 image_gen 对旧人物图进行身份保留编辑，1024×1536。四角 alpha 均为 0，透明像素分别约 40.05% 和 43.78%；主体生成 alpha 约 253–254，保留原始通道，没有程序抠图或涂改。

已查看原图、新图和 [黑白底合成联络表](npc-alpha-proof-20261022.jpg)：面貌、头巾、衣甲及文书道具连续，场景矩形背景已移除，肩臂与文书未截断；肤色较克制，粗麻/暗铁质感自然。甲的长矛顶部留白较窄，未截断；若后续需要旋转/晃动，需在布局外侧预留额外空间。该结论是技术与本轮视觉检查，仍待用户对角色表现作最终审阅。

实际 Prompt 与原图路径保存在 [npc-neutral-v3-generation.json](../../source-art/visuals/runtime/characters/npc-neutral-v3-generation.json)。人物、场景与 UI 的最终程序绑定及浏览器验证由整合阶段完成，本报告不替代试玩结论。

## 整合后的审阅入口与未完成边界

[整页优先的离线审阅图册](../../source-art/visuals/review/20261022/index.html) 从最新 manifest 生成；人物按角色与三表情分组，附旧身份原件和确切的最新视频母版来源。诸葛亮为预备资源，没有为了展示表情而强插第一章对白。三处第一章场景按当前绑定对照旧版；传报棚与姜维帐的新稿来自各自空间样机，不把它们称作视频的精确三维复建。

用户否定首轮木板/材质方向后，四张样品及两份制作记录已整目录移入 `source-art/visuals/archive/20261022/ui-material-prototypes/`；确认没有 `.meta`，四图哈希不变，四项材质绑定已取消。图册只在默认折叠的未采用区保留追溯，不列入当前整页墙。素材存在或技术自检不代表采用。

现用思绪页仍保留并发新布局中的玻璃效果与圆角，需结合完整截图继续审核。本轮没有宣称所有按钮与面板都已拆成独立生成美术资产。主要页面先审完整排布，再决定细材质与组件扩产；所有视觉状态继续保留待review。

`runtime-map.json` 已改为 `visual-assets.json` 的导出镜像；旧版快照原样保存在 `archive/20261022/runtime-map-before.json`。表情索引的值为资产 ID，审计器先在 `characters` 中解析，不将它当文件路径误报。
