## 统一判断

整体采用“电影叙事、案牍操作”：人物和场景延用既定写实影像，开篇墨晕对话框保留；需要输入、选择设置、存取进度时，使用灰褐厚纸、炭黑底、暗铜边与少量朱漆。影像与操作层用相近的明度和材质衔接，不把全部场景套成棕黄色，也不把所有画面改成纸本插画。

本轮直接查看了崇祯 UI 样本板、江山北望的暂停背景与章节介绍框、第四章当前实际截图、魏延人物原图及本项目调整后的运行截图；其余资产通过映射、文件与哈希建立索引。没有逐一审阅全部人物、完整影片或外部游戏实机流程。

| 主菜单 | 现有营帐灯火背景与题字符合电影方向；旧按钮与新操作面板材料不同 | 保留背景、题字、导航位置；按钮统一为暗纸与朱漆主项 |
| 暂停、设置、存档 | 原来独立封面图与新案牍风格存在差异 | 共用深纸铜角外壳；保留实际控件、标题纸签与阅读内页 |
| 第五章问话 | 深绿色纯色输入栏与新厚纸不一致 | 军报外框与消息也接入纸面；复用厚纸输入和朱漆提交，不改军报内容、问答次数及判定 |
| 第四章独立交互稿 | 当前材质与布局已经建立 | 作为参考与复用来源，不覆盖当天其他任务的修改 |

| 视频、结局、卡册 | 具有自己的内容和审核状态，不能用 UI 同步代替审核 | 保留现有来源和状态，本轮不重拍、不调整声音 |

资产整理采用“保留路径、增加职责和状态索引”，避免移动现有文件破坏 UUID、场景引用、发布映射或历史审阅。没有把两个外部参考库复制进发布资源，也没有生成压缩副本。

## 组件规则与实现

共享颜色为纸白正文 `#e8dfce`、灰褐辅助文字 `#c3b49b`、暗铜 `#ac9060`、炭黑 `#211e19`、朱漆 `#542c24`。这些是本项目设计值，不是外部游戏官方色板。

- 读剧情：沿用24px对白、22px说话人、20px普通选项与16px导航。开篇对话框的形状、透明度和位置不变。
- 写原话：前三章输入统一20px、1.8行高楷体；输入区域比托底纸面略亮，聚焦显示铜色轮廓。第四章独立原型18/16/14px的局部字号不覆盖正式章节。
- 执行动作：确认采用朱漆，润色等次级动作采用深纸；保留禁用、悬停与键盘焦点。颜色不作为唯一状态提示，按钮文字与程序状态继续有效。
- 看长文：回顾等浅纸正文保留墨字；材料统一不要求所有阅读区都改深色。
- 窄屏：原有滚动与软键盘适配继续使用，正文不靠缩字塞入面板。

实现入口：[campaign-art.css](../../../GameStarter/web-demo/public/campaign-art.css)负责材料与操作组件，[narrative.css](../../../GameStarter/web-demo/public/narrative.css)负责前三章单栏表达结构。样式从现有 `narrative.css` 导入，章节共用，不增加各章的复制版。
