# 画面与交互

2026-11-12 · 结构修订 v4。用户认可v1整体美术风格；本次简化结构和危机标记仍待审阅。效果图是位图视觉稿，不代表交互已实现，也不把图片中的中文当正式UI字库。

## 总体画面

以现有夷陵地图和营门、渡口、山林场景为底。自然日光、山林灰绿、江水灰蓝，禁止全画面黄褐滤镜。人物与场景保持历史电影实拍质感；界面用灰褐旧铜、亚麻织物、浅纸页和少量朱红。金属只在边角和兵筹上出现，不做满屏金边。

地图给空间感，人物给代入，纸页给阅读。每个时刻只让一种操作成为重点。没有浏览器式侧栏、白色长表单、任务下拉框、常驻教程和效率加成按钮。

## A 地图：一眼知道哪里有事

- 16:9全画面。地图占主体，顶部安全区5%，底部操作区不超过12%。默认不显示人物大头像。
- 左上只放「夷陵·三路归途」；右上放「第一回合」和折叠菜单。菜单收存档、设置、回顾。
- 当前三个纸签：傅肜后阵方向、冯习·张南南岸旧营方向、沙摩柯南面山林。移除黄权，不将双将直接换到江北原坐标。不要为了排版把三人排成一行卡片。
- 地点签固定三行：人名、危机程度「暂稳／吃紧／危急」、3—10字的固定职衔或角色说明（跨回合不变）。底纹约20%透明，即80%不透明，文字保持全不透明；整体字较v2效果图缩小一档约15%—20%。危机颜色辅助文字，不用颜色代替文字。例：沙摩柯／吃紧／五溪首领。该缩字要求仅用于本次地图UI，不擅改其他章节对白基准。
- 去掉全屏装饰边框、标题牌框中框和厚重底栏。标题、回合、待命人数以简短文字呈现，只有“结束回合”保留必要按钮底。纸签保留薄纸材质与轻微阴影。
- 下沿左侧「待命2500人」，点开才看已占用和返回的兵筹。右下主按钮「结束回合」；有未确认军令时提醒“这份尚未传令”，允许返回或明确放弃草稿。
- 队伍位置在下令后显示细小兵筹和路径，结束回合时才移动到结果位置。确认阶段用空心军标表示计划，执行后实心，防止把计划误认作事实。
- 纸签第三行只说明人物角色，不随剧情与任务进展变化；当前难处、详细剧情、任务进展和依据点击后再看。全部目标撤出后第二行改为「已脱险」，失去联系改为「失联」；部分获救仍显示剩余救援对象的危机，详情说明谁已撤出，避免把将领获救误写为全体安全。

## B 剧情：先听见人的处境

点击地点，地图轻推至该位置，短切现有场景。人物镜头第一视角：对方朝镜头说话，不新增玩家肩背。报信兵可以新设计，傅肜等既定人物露脸须复用已确认角色参考；未确认前只用声音、背影或不出镜。

上方场景约65–70%，底部浅织物对白带约30–35%。每屏只显示当前说话人和一段话。首幕两条剧情选项放在对白下方，选项不挤成按钮墙。点击选择，人物下一句替换本句，不把整段聊天永久堆在屏幕上。

引导结束后，同一条对白带出现一个自然说话入口，可输入询问或军令。旁边只有「说出」与「拟军令」，不要再做另一块“也可以自己问一句”。历史对话由一个回看入口展开。

后续进入该处只播新回报。不再播放首次出场、身份介绍或重复摆相同两条问题。暂无变化时显示一条现况，直接允许询问和改令。

## C 拟军令：兵力与原话在同一张笺上

沿用当前人物场景，左侧保留人物与环境约52%；右侧44%展开军令笺，其余为安全边距。人物看着我等待，不在输入时循环张嘴。

军令笺从上到下：

1. 「拟军令」标题。
2. 五枚兵筹。初始每枚500人；已占用者压一条去向纸签，不可误选。选中用朱红绦带和勾痕，不只变色。
3. 合计人数，受损时显示实际人数与编制，不能虚构补兵。
4. 玩家的军令原话，可直接编辑。
5. 军侯一句复述或一个必要澄清问题。
6. 「再改一下」「照此传令」。

军侯不能靠复述偷偷改写军令。系统涉及人数、地点或条件调整时在笺上明确变化，确认前可编辑。确认后笺面出现小「已传」印记，兵筹移到对应地图位置的计划状态，返回地图后继续安排其他路线。

AI等待只让军侯保持安静，军令笺显示小墨点与「正在拟令」；可以取消，原话保留。失败时同位置短提示，不弹浏览器报错，不出现代码或模型名。人物的固定对白、玩家原话与模型返回内容都不得被错误朗读成导演说明。

## D 回合结果：变化发生在原来的地方

按下结束回合：先锁定本回合军令，地图队伍移动，再依次出现三地短回报。单次镜头变化克制，不强迫每回合看三段长视频。

每处最多两行：事实变化＋剩余难处。例如：

- 「西口已经换防。后门还剩一批伤兵。」
- 「第一批过江了。黄权仍在北岸守后队。」
- 「东沟已经找到人。林口还没人接应。」

位置签同步更新，不另开大统计表。一次结算中的重点按新危险、获救、受阻排序；普通部署只用图标移动和短字。右下「查看新军情」回到可操作地图；已经发生结局时改为「回营点名」。

结果有明确因果，但不用每次报公式：无守岸兵就说船靠不上，无守口兵就说找到的人出不来。玩家愿意查看依据时，再展开详细数值和该回合执行的军令。

## 字体、响应式与可读性

正式实现复用第一章标准：对白24px/1.8楷体，人物名22px/1.5，剧情选项20px/1.7，导航16px/1.6。数值、兵筹和小标记另设清楚的中文正文，不拿书法字写长段落。字号是CSS逻辑尺度，效果图里的像素字号不替代该标准。

1920×1080作为桌面布局基准。实际1280×720时维持字号与安全区，必要时对白分句分页，不整体缩成小字。窄屏故事仍占主画面，兵力筹与军令笺顺序展开；地图可拖动，三个节点有可点击焦点。不可把完整桌面UI缩到手机里。

对白底纹不盖住脸和关键物件。对比度以文字可读为先，不追求“纸旧到看不清”。兵筹最小点击区域44×44逻辑像素，键盘可选；退出确认和草案确认用游戏内纸页，不用浏览器原生弹窗。

## 运动与声音

地图到场景短切约0.4秒；军令笺展开约0.25秒；回合结果逐处出现约0.6秒，支持跳过到完整结果。动画不偷偷推进回合。焦点移动服从当前说话或操作对象，不自动滚屏到无关处。

轻微风声、江水、布料、营中脚步按场景播放；传令用简短衣甲和脚步声，不每次盖章都配夸张轰鸣。BGM本稿不新增。语音仅读对白原句，不读人物名、节点号或数值说明。可静音，也可完全只读字。
