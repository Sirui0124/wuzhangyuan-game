## 本章的故事

御驾已经脱险，我接过最后五队兵，要把还留在战场上的人带出来。傅肜守着营门，黄权隔在江北，沙摩柯的部众散进山沟。三人都不是等一句劝告就能离开：他们各自还有人要带、有地方要守。

本章的问题是：有限的接应兵该替谁接下哪件事，什么时候才能抽身。救到将领不立刻清空该路；留在后面的接应兵，也要有人安排回来。

## 内容规模与阅读节奏

- 1段承接开场；3路×3幕，共9个主要剧情节点；每幕2个引导选项。
- 选项只帮助理解处境，不是隐藏口令。首幕提供代入，之后只说变化；未触发新事件时不给重复长对白。
- 每次进场默认显示1位人物的1段话；选择后的回应再显示。单屏不堆整幕全文。
- 自由询问与军令共用一个说话入口；点击“拟军令”才展开人数筹与确认笺。
- 共8回合上限。阅读、询问、拟令均不耗回合；“结束回合”统一结算三路。预计5–10分钟是设计目标，尚未人工计时验证。
- 结尾采用“总场景＋每路结果＋接应兵情况”组合，避免为每个排列编造一套长故事。
