# 存档留痕与回溯舆图

来源：2026-10-25 用户要求，“存档留痕”放玩家保存的游戏进度；“回溯舆图”以地图为主，已解锁成就在右侧以档案卡片呈现。

## 已实现

- 主菜单“存档留痕”连接原有进度存档面板，显示自动进度、两个手动档位及场景和保存时间。读取复用现有恢复逻辑；游戏内手动保存和覆盖前确认保留。主菜单没有正在游玩的会话，只提供读取，阻止将初始化的新会话覆盖到原档位。
- 舆图桌面布局以地图为主，右侧约四分之一宽度展示成就档案；窄屏改为地图在上、档案在下。原章节入口保留，影像回看收进可展开区域。
- 成就使用现有解锁记录，只显示已解锁卡片，点击展开现有卡册详情，关闭返回舆图及原焦点；未解锁时显示空档案状态。查看不写入进度、授予线索或重复解锁成就。
- 结局页的“翻阅存档留痕”改为“查看成就”，通往舆图。新游戏确认说明区分手动存档与成就。
- 原存档键、存档版本、成就键不变，无数据迁移。此次调整的是第一章主菜单入口；第二章原有独立存档流程未改动。

## 验证

- `npm run check`、`npm run build`、`npm run check:assets` 通过。
- `tools/migration/map-archive-save-smoke.mjs`：主菜单入口、手动档恢复、刷新后自动档恢复、覆盖前确认、主菜单不提供保存空会话、成就只显示已解锁、关闭恢复焦点、查看不改写存档或成就、空档案、1440/1920/390 宽度检查通过。
- 截图与结果：`outputs/map-archive-20261025/`。使用隔离浏览器测试数据，没有操作玩家的真实存档。
- 浏览器效果待用户试玩；未验证 Cocos/native。
