## 实现决定

- 人物位于右侧，以肩胸构图保证笔记本上能看清神情；左侧留给语言和操作。场景调为低饱和暖灰，墨色底纹托住文字，朱砂色只强调继续和确认。
- 使用楷体，正文、主要标题为 18px；辅助信息、已选依据与上一句提示为 14px；按钮独立使用 16px。长短线索自然宽度，不拉成等宽卡片。
- 普通对白、斥候选项、玩家已说出的内容、等待回应和拒绝后修改共享视觉样式。继续仍使用原生按钮和原有键盘行为；长文本在区域内部滚动，动作保持可达。
- 只有表达环节出现“自己的话 → 润色表达 → 准备说的话 → 确认说出”。润色预览可以编辑，确认后才固定本次发言；等待、取消、失败与重试使用原有状态。
- 表达时的搜索栏与详情放在依据下方的自然布局中，详情位于搜索栏右侧且同顶；不盖住输入区或人物。开关搜索不移动上方模式按钮，收起时保留查询。
- 右侧上一句对白来自实际已发生的对白或反馈，使用小片羽化暗墨底提高甲片背景上的可读性。
