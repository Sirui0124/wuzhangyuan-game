# 物品行为处罚修正（2026-10-28）

用户确认：帐前点燃仙女棒、晃圈取乐的原话不应只得到喝止，要能进入妖异失败或魏延怒而斩首。

原物品分支将用途不成立等情况统一返回可修改的质疑，且只在 mainlineEligible=true 时进入普通魏延判定，危险行为反而会被排除。这使物品功能判断间接屏蔽了人物处罚。上次回应口吻调整没有修复这一问题。

现由 `weiyan-item-conduct.ts` 独立核验当前言行：先沿用时代异常的双条件判断；不满足妖异失败时，所有物品路径都要检查人物处罚。该检查不读取模型给出的物品路线或主线资格，不能因为物品办法成立、不成立或可交主线而跳过。处罚引文必须来自本次确认发言，格式或引文异常返回技术重试，不默认放行、不默认判死。

行为区分：帐前点火耍弄、整段戏弄催报将军属于off_topic，直接辱骂、人身威胁或明确攻击属于offense。普通携带、递物、未点燃、询问许可、正当用途、缺配件与失败建议仍可解释；没有仙女棒或打火机黑名单，否定、引用和提问不按既成行为处理。核心物品能力、通关与妖异双条件未放宽。

结果复用现有execute回应、斩首页与本轮重试，不消费物品。判定版本更新为 `weiyan-item-conduct-20261028-v6`，尚未阅读的旧结果会重新判断。普通物品测试的行为判断单独用明确none夹具隔离；新增专项直接测试真实适配器，包括物品路线/主线资格六种组合均不能绕过处罚、妖异优先、非法引文、取消、失败存档恢复与重试。
