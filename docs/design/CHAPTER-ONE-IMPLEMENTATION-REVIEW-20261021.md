## 本次可试玩内容

完整路径：A-01 起首轮 → 首次死亡与回溯 → D01—D26 逐句收录 → P1 同一画布 Q1/Q2 → J01—J14 本人出帐承诺 → W02 开场及 P2 原画布表达浮层 → 亲兵核验 → 正式完整军报 → 回令到执行者 → 第一章结尾。

“直接体验画布”是显式标注的审阅样例：依次提交 A-01—D26 的已发生事件，再进入 P1。它不会继承正式游戏或前轮全库；正式游戏存档使用其他键。完整体验入口仍从首轮开始。

- 点短摘要原位展开逐字原话、说话人、行 ID 和上下文；推论展开证据链。
- 拖圆环到另一笔记，或依次点两个圆环；第三条接入已有组即可；没有关系选择题、推演提交按钮或必填长文。
- 有意义但不回答当前题目的关系保留。Q2 时 R01+C05 可补强敌情判断。
- 移动点阵可拖动笔记，也支持点阵获焦后按方向键。图形布局及连接自动保存。
- 重复连线去重；删除支撑导致依赖推论显示“待重组”，不能继续解锁。既有授权、实际接报与回令事件不因删线撤销。
- “去向姜维问准”是执行已形成方案的叙事出口，不承担推理检查。
- P2 可选 R01+C08 或等效原始证据确认短表达，无需输入长文即可完整通关。只选 C08 不会自动说服魏延。
- 确认后先展示实说文本，再主动听取回应；确认前只显示草稿。
- 自由改写接入现有本地 `GameApi` 代理。判定仅返回允许的结果码，不能写剧情事件。取消使用请求序号及 AbortController，迟到结果不推进。超时/异常保留图形、已得授权、草稿及待处理表达；刷新可以重试。
- “记录反馈”在本机保存意见并导出 JSON，不自动发往飞书或其他对话。

## 页面方案与 review 重点

画布采用暖灰纸面、深墨文字、细线、留白。原始见闻为浅纸色，推论为低饱和灰绿；类别文字说明证词、回忆、职责消息、本人承诺、推测及行动方案，颜色不表示真假。无工作台侧栏、相关度分数、情商评分。

第一轮建议 review 以下四点：

1. **短摘要的密度**：一次看到多条见闻，是否仍能自然理解？是否要减少局部推论的同时呈现？
2. **连线手感**：圆环加双点连接是否易懂；自动短句出现后，是否能明白还缺什么？
3. **原话展开**：原位展开是否足够连贯；遮挡其他笔记时，是否需要再引入局部自动让位？
4. **表达浮层**：收起后选证据、展开后确认短句是否顺手；浮层高度与遮挡是否合适？
