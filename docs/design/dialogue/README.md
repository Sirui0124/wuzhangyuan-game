# NPC 对话设计维护

本地编辑入口为 [魏延对话设计](weiyan-dialogue.design.md)，分类条件与回应意图由用户用自然语言维护；JSON、Prompt、运行映射与验证由执行者负责。不依赖外部文档或修订号。

架构与历史窗口统一遵守 [AI 对话架构](../AI-DIALOGUE-ARCHITECTURE.md)：每个 NPC 对话节点配置最近 N 轮完整问答，分类器与回应器共用同一快照。具体 N 尚需逐节点填写，不能把架构规定冒充运行代码已更新。

同目录 design.json、阶段配置和 Prompt 文件仍可能被编译与测试引用，修改时必须核对实际浏览器调用链及镜像。现存设计与 Cocos 侧三分类、重试路径存在差异，不能把旧文档中的实现日期和测试次数当作现状证明。核对后维护唯一的现行设计，不从旧同步快照恢复条件。

玩家修改的条件、正反例与回应意图必须保留；模型输出校验不是用户审核。运行结构、历史窗口与剧情分支分别验证。
