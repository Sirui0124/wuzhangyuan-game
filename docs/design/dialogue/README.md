2026-10-23补充回应等义审核：职责仍分判定与回应，实际请求可增加第三次审核（温度0）。成功固定句与原样返回的intent跳过审核；其余候选先过长度、句式守卫，再由 `GameStarter/web-demo/src/weiyan-reply-audit.ts` 核对是否仅改写intent。审核只接收speaker、intent、candidate，不混入玩家原话或事实表；禁止新增情报、授权、已发生动作、行动人或通过条件。仅严格返回 `equivalent:true` 才采用；不等义、格式错误、服务异常均回退intent，不改变三结果判定，取消请求仍作废。该模块与 `weiyan-reply-audit-prompt.txt` 的逐字镜像纳入测试。

`spokenTurns`合并本轮所有确认原话，`current`只限定当场完全无关／直接冒犯的判定范围。精简facts只从实际取得的证据生成：C08明确本人承诺，T02/C01明确已知营门情况，其余状态标未知。它们只核验真假，不填补没说的话。无据引文与正向check交叉时清除冲突check、继续解释；无效结构或不存在的原话引文是技术失败。
