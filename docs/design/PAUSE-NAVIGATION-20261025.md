# 顶部导航字号与暂停菜单

2026-10-25 用户要求：右上角各页面字号按展开思绪后的大小统一；设置移入菜单，菜单展示暂停页面与返回首页、设置等操作。

## 实现

- 游戏顶部导航统一为 16px，与当前思绪展开页一致。包括人物志、思绪及数量、物品、记录、存档、菜单；两章共用，窄屏保持同样字号。视频右上角的菜单与人物志也使用此字号，分开位置避免重叠。
- 游戏场景右上角移除独立设置入口，菜单打开玄青夜绢风格的暂停面板，操作为继续游戏、设置、返回首页。进入菜单即暂停，不再设置一个需要再次点击才生效的“暂停”按钮。首页原有设置入口保留。
- 暂停层保留底下的场景、思绪和视频 DOM，背景不可交互。视频停在当前时间，设置关闭后先返回暂停菜单，继续后恢复此前播放状态；原先手动暂停的视频不会被自动播放。
- Escape 从设置返回暂停菜单，再按一次继续。可见游戏菜单时 Escape 也可打开暂停。Tab 焦点限制在暂停/设置层内。
- 第一章暂停会停止当前 AI 语音，阻止暂停期间自动接话；继续时由原对话呈现逻辑恢复。AI 语音不是音频采样位置续播。本轮未改语义判定、生成提示词或剧情条件。
- 第二章使用同一菜单和设置面板，模式更改保存当前状态后重新载入；普通查看设置、调整音量和关闭不会重新载入影片。
