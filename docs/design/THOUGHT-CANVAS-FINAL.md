# 思绪画布定稿规范

版本：2026-10-26。用户本轮指令为依据；本文件是思绪画布的维护入口，覆盖旧稿中“一题右侧展示多个中间认识”和“答案一出自动展现下一题”的描述。规则方向按用户要求落实，细化分类与视觉效果待用户review。

## 一、问题与唯一答案

每组问题在左侧组织依据，在右侧至多显示一个当前答案。未完成时右侧留空，不提前展示答案。中间认识可以保留、查阅和复用，放在依据侧或详情里，不另占一个答案位。补充推理更新本题答案，不追加第二个并列结论；推论始终保留不确定性。

本次第一问：“此前袭扰，闻号即退”（C02）与“今夜闻号不退，交替试探两翼”（C03）共同支持“今夜敌军有变，可能在试探”。调兵观察及尚未攻营分段补在C03，不再单独发卡。第一题最多2条、冗余0；缺任一条不能用叫嚷替代。

第二问沿用R01，须选择“帐前禁令”（C06）与“姜维可以代为处理军务”（C07）两条，冗余0。C07在乙D08/D09完整后解锁，通传路径在D11—D13完整后补入详情。缺任一依据不能推出“向姜维请求接报”；R02只作画布结论，不进入线索选择列表。C08“姜维已答应帐外接报”仍在J09—J11本人完整答复后取得，不作为第二问前提。全章七条事实线索为C02、C03、C05、C06、C07、C08、T02。

## 二、支持的因果关系及填写方式

以下是策划可采用的关系规范；每题须明确具体依据与门槛，不能由AI凭名称推断。不是给现有章节自动增加剧情。

| 类型 | 自然语言填写 | 显示与判定 |
| --- | --- | --- |
| 单一充分依据 | 这条原始记录足以回答本题 | 一条依据连一个答案；须明确其为何充分。 |
| 多条共同支持（且） | 结合A、B、C才得出这个判断 | 多条汇合一个答案；缺一不能当完整答案。本章第一问的两条军情对照属于此类。 |
| 等价支持（或） | 原件或可靠摘录，任一可作同一依据 | 只画实际采用的来源，不重复计数；替代范围由策划指定。 |
| 对照与变化 | 对照往日和今夜，再结合行动变化 | 仍是多条依据汇合一个答案；保留时间、对象和比较条件。 |
| 反证与限制 | 已知A则不能断言B／只能说可能 | 反证阻止过强结论，反馈留在当前题；不另生成“反证答案”。 |
| 前答作为后题依据 | 先判断军情，再考虑交给谁 | 旧答案连向新问题，新问题另有自己的唯一答案。 |

当前第一章程序已覆盖多条共同支持、对照、有限推论及前答衍生。单一充分依据、可配置的等价替代和通用反证条件是策划支持范围，未来章节落地时须配置并分别验证，不宣称本次做出了通用规则编辑器。

## 三、完成后的两种出口

- 继续推理：答案保留，出现“继续推理”；玩家点击后才展示下一题，不自动继续判定。
- 行动：展示清楚的行动按钮，如“去找姜伯约”；玩家点击才执行。提出接报方案不等于姜维已经应允，也不等于军报已经送达。

出口由当前题的策划配置决定，不要求每题同时出现两个按钮。本例第一问继续推理，第二问行动。玩家始终可以收起再打开，保存已有答案、依据与当前进度。没有当前推理任务时只能回看和查阅，不开放自由推理；完成最终题后不再出现添入／推理入口。已有线索不代表当前必有可推理的问题。

## 四、问题之间的关系

| 关系 | 开启条件 | 连线 |
| --- | --- | --- |
| 答案衍生问题 | 前题完成且点击继续推理；后题使用其答案 | 前答连新问题；不是直接把前答当后题答案。 |
| 独立问题 | 自己的剧情触发条件成立 | 独立标题，无前答因果线；顺序相邻不代表因果。 |

同一材料可被多个问题引用，但每个问题单独保留依据、完成状态、唯一答案和出口。独立问题是本规范支持的编排类型；本章现有两题为衍生关系，本轮不虚构独立问题加入剧情。通用多题调度、同时出现多题的顺序以及循环依赖不属于本次实现，后续按具体策划接入。

## 五、视觉与动画

### 进入画布前的停顿（2026-10-23）

正式剧情完成调查后先停留在场景中，下方使用普通选项样式显示“让我想一想”。点击这一项才初始化本轮画布、记录打开状态并展开第一问；点击背景不代选。等待阶段持久保存，读档后继续等待；已进入画布的存档及收起后重开直接恢复，不补放入口或重播入场动画。此规则不把阅读已得线索变成新的剧情推进，也不改变专项试玩直接打开画布的用途。

本轮入场采用700ms墨色淡入，内容轻移8px后静止，与推理答案的描线动画分开。游戏或系统启用减少动态效果时直接显示。入口沿用70%屏宽、左右对称的楷体选项，无额外的继续按钮。

保持参考图的背景、楷体和左右布局。所有画布文字增加2px：正文及辅助14→16px，问题／答案18→20px，原16px按钮→18px；图标字号同步增加2px。

2026-10-23构图微调：目标标题和各题文字共用居中容器、左右内边距，滚动条两侧对称预留，避免标题与问题产生几像素错位。内容最大宽度从1040px收至960px，左右内边距对称；笔记本尺寸下整体约下移20—24px，题内与题间的紧凑关系保持。滚动区聚焦时只保留淡色侧边提示，不再框住整个画面。已检查1366×768、1280×720、1440×900及900×768下的对齐、两题结果和线索详情，记录见 `outputs/thought-alignment-20261023/verification.json`；待用户视觉审阅。

线条采用低饱和米灰色、1px细线，常态透明度由40%降至26%，聚焦关联线50%，无关线12%。新依据连接由左向右用900ms描出，多条相隔90ms；答案轻淡入，不使用循环流光。问题分组线只表示归属，答案衍生线表示后题来源，独立题不连前答。回看、关闭重开及滚动不重复播放完成动画。系统或游戏关闭动态效果时直接显示静态结果。
