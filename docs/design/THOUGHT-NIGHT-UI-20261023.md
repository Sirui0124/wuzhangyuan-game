# 思绪画布 · 暗色脑图落地

日期：2026-10-23。状态：浏览器实现完成，待用户试玩审阅。

本轮根据已讨论的 UI 图开发。最新补充优先：线索详情浮窗位于搜索选择栏的右侧，二者顶端对齐；这对浮窗位于当前推理关系下方，不覆盖已有左右两列。

## 已实现

- 暖灰夜色背景、低对比底纹、朱砂推理按钮；背景由已确认的美术图去除 UI 后生成，非整张界面截图铺底。
- 正文和线索统一楷体 14px，问题、起点、结论 18px；按钮字号独立。线索左对齐，底纹按文字自然宽度伸缩，小叉紧随文字。
- 左侧问题和选入线索、右侧已有认识与新结论。固定继承的上一轮输出保留在模型中；紧凑版直接使用历史中的实际结果节点，不再复制一份“起点”，以浅色弧线连接后续问题。
- 各步按内容高度连续排列，在同一个固定画布内上下滚动，进入或读档默认最新。回看历史时查看线索就在该步展开，不跳到最新。空的搜索区域不占高度。
- “添入线索”打开搜索选择栏。按标题与原文即时筛选，支持空结果提示、清除查询、中文输入；搜索不改变已选依据、推理记录和结果。
- 点击条目文字查看原话与边界，点击加号立即加入；已加入显示勾。完成推理后，库存仍正确标示这次使用过的线索。
- 搜索选择栏与详情使用相同暗色绢面。桌面上详情距选择栏 16px 且同顶；长文在详情内部滚动。窄屏空间不足时详情移到选择栏下方。
- Escape 先关闭详情，再关闭选择栏；搜索与加入操作保留查询。新结论有短暂显现动效，尊重减少动态效果设置，读档不重播。

图中的示例没有追加到正式第一章。游戏继续使用实际取得的资料与原文，结论不会代替姜维的真实授权。推理、表达、存档及章节事件的业务规则未因本轮美术调整而改写。

## 同日补充：连续排布、问题顺序与行动出口

用户试玩发现每轮占满一屏导致大片空白，所有步骤重复询问接报人，而且在“可向有职责的人请求”后看不出如何继续。本次保留已确认的字体、底纹、搜索和详情，修正以下行为：

- 总目标“如何在不惊扰丞相的情况下，不误军情？”常驻画布上方；先问“今晚的军情如何？”，完整军情判断形成后，才展开“不惊扰丞相，军情应该交给谁？”。同一阶段的问题只显示一次，旧记录不会被最终进度改写成第二问。
- 取消每轮最小整屏高度和空详情占位。上一轮结论直接连接下一问；同一问题下的后续判断连续展开，正文仍为 14px 楷体、问题与结论 18px。
- 完整方案 R02 下显示朱砂按钮“去找姜伯约”，调用原有 `followPlan()` 进入真实 J01 对话。推理不提前给予 C08 或记录姜维已经应允。
- 兼容用户已经走到的 I01 → I03 分支：显示军情尚待判断的说明，提供“接回此前军情判断”按钮，显式选入已得到但未选中的 I01/I02。原始军情仍不齐时，失败反馈指出本次缺少的依据，不再笼统说“已经想过了”。只有真实已取得的判断可以接回。
- 没有增加强制答题顺序、自动选择新证据或放宽原有通过条件；既有直接推理、职责先行等路径继续可用。本轮只读核对在线协作原则修订 11，与本地相同，未写入在线剧情表。界面文案待用户试玩审阅。
