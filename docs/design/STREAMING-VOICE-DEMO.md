在游戏设置的“实时配音：配置音色与试听”进入配置页，填写火山引擎语音 API Key、我和魏延的音色 ID。音色由用户从控制台选择；不预设正式角色声音。保存立即生效；密钥只存到本机服务 .env，不回显、不写入游戏存档。空密钥保留已保存值。页面支持各自试听、停止和配音关闭（刷新游戏生效）。

确认说出时，原有魏延判定立即发出，同时开始合成“我”的语音。模型完整回应经原有校验后提前合成魏延语音，自动等待“我”的整段音频实际播放结束；如果魏延回应已就绪，立即切换并播放，尚未就绪则等待后自动接话。仍允许点击跳过我的语音。静音或配音失败时保留手动继续，取消和离开不会触发自动推进。首轮和次轮共用此适配。未确认的草稿、旁白、心声和视频不配音。取消、重新组织、换轮、读档、回菜单和页面隐藏会停止相关语音。语音失败提示原因，文字玩法仍可继续。

服务端使用官方双向 WebSocket 协议，按标点提交文本，不逐字人为延时；返回的 24kHz 单声道 PCM 经本机 NDJSON 流传给浏览器，Web Audio 分块调度播放。客户端处理跨传输块的 JSON 和半个 PCM sample。模型的判定 JSON 不朗读，也未改成增量判定。此 Demo 每句独立连接；后续真实试听再评估连接复用和更低缓冲。

参考：[火山引擎双向流式 TTS](https://docs.volcengine.com/docs/DoubaoVoice/bidirectional-streaming-text-to-speech-websocket?lang=zh)。配置字段见 GameStarter/server/.env.example。新增 ws 运行时依赖已锁定在根 package-lock.json。
