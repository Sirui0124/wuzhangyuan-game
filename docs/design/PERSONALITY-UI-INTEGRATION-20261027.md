# 三国人格：页面与游戏接入

2026-10-27。浏览器版已接入，页面与新文案待用户试玩审阅。人物坐标与选项配置沿用 2026-10-26 的设计，不改通关、物品或 NPC 回应规则。

入口为三章共用的右上角暂停菜单 → 三国人格。页面沿用暗色书册、暖色纸页和朱红标记：上方展示“若在三国，你更像……”与当前人物，中段是四条双向刻度，下方展示章节和实际选择原话。更多依据及死亡历史折叠；分享按钮复制当前人物、方向与行为依据，复制受限时提供可选全文。打开时暂停原影片，返回保留位置；Escape 逐层返回，键盘焦点留在弹层内。

下方现统一命名“典型依据”。每条以章节、至多两行的依据摘要及性格方向紧凑排列，展开可读当时提示与完整所选原文。确认类按钮同时展示确认背景，避免单独出现“确认”。构建从实际章节脚本按节点和选项编号生成 `story/personality/evidence-sources.json`，页面以记录中的节点、选项和原话关联；读取依据不改变当前分数或存档。自由输入保留评估引文与完整已确认原话，未替玩家改写。桌面每条约70像素，390像素手机每条约91像素；上方人物区与四维区保持本轮调整前布局。

四个维度为谋定／敢行、直陈／周旋、守则／权变、大局／情义。当前 36 位人物都有四维坐标。第二章任一已提交结局后解锁，后续章节继续改变结果。至少三维已有真实依据时才展示人物，依据不足的轴显示“尚无依据”，不把未知伪装成中立。

第一章必死任务的整个首轮不计人格。真实死亡另存只读历史，保留当时原话和快照；被拘捕、马谡死亡不误算为玩家死亡。历史不会叠加进当前分数。重玩只清该章当前记录，其余章节最近一次记录保留；读旧存档不凭历史剧情猜分。手动读档只能恢复当前尝试的有效人格前缀，已被重玩清掉的旧尝试不会重新成为当前贡献。刷新同一死亡页不新增次数。

固定选择只有游戏实际接受后才记录；第二章最终确认的行动替换同一取舍上的开放意图，取消确认不产生替换。开放回答在玩家确认且剧情判定接受后后台评估。同题追问汇总已确认原话，明确改口以后句为准，只保留该题最新评估。失败保留待评原话，刷新或重新启用 AI 后可续评；跨章跳转也续评上一章未完成的回答。代拟、未知来源的表达不计“直陈／周旋”；混合文本只接受保留下来的自写原句。

人格独立保存在 `wzy:personality:v1`；玩法存档只嵌入本章检查点，不嵌入全局历史。重玩、改口和回退会让旧请求失效。试玩使用独立人格与章节存档。

实现入口：

- `GameStarter/web-demo/src/game/pause-menu.ts`：统一入口、暂停、焦点和分享交互。
- `GameStarter/web-demo/src/game.ts`、`chapter-two.ts`、`chapter-three.ts`：实际选择与存档挂接。
- `GameStarter/server/personality.mjs` 与 `/api/game/personality`：沿用当前 provider 的独立人格评估。
- `GameStarter/web-demo/public/personality.css`：页面样式。
- `tools/personality/prepare-playtest.mjs` 与 `preview-witness.json`：隔离展示样例，构建不依赖 outputs 临时报告。
