## 第一场 山路上的手

【运粮山路／白日。第四次北伐。】

粮袋从车边滑落。我伸手去抓，脚下碎石塌下，半个身子悬出路沿。一只手扣住我的右前臂，把我拖回地面。

救我的人伏在路边喘气。他松开手，先摸了一下我的胳膊。

苟安：还能动？下回别拿命去捡粮。

后面的车夫招呼让路。他起身去扶歪倒的粮车。

切伤帐。数日后。帐侧伤员名牌写着“苟安”。那人伏在榻上，背上缠着伤布。我端水进来，搁在他伸手够得到的地方。

我（心声）：第四次北伐，我成了运粮兵。救我的竟是苟安。我记得他受罚后投魏，回来散谣，逼朝廷召军。眼下还来得及吗？

苟安：山上没摔着，倒叫我这副样子吓着了？

**选择一：怎样开口？**

- **A　先谢他救命。**

  我：那天还没谢你。伤好些了吗？

  苟安：活着就成。把水递近些。

- **B　直接问误粮的事。**

  我：听说这顿打是为误粮。路上到底怎么了？

  苟安：喝了酒，又误了期。上头问罪，我认。

两路合流。他试着撑起身，牵动伤处。我把碗送到他手里。

## 第二场 他交给我的说法

【本队交差处／白日，接伤帐／傍晚。】

管事核对本队交接记录，让我在经手一栏认名。我指住领粮日期。

我：那天才领到粮？出发的日子不是早定了吗？

管事：在后方等了几日。你就在队里，还能不知道？准你抄这一笔，别的账不能动。

切伤帐。我将抄录放到苟安面前。

我：粮没交下来，等的日子也算在你头上？

苟安：喝酒是我的错。可粮早备好了，是李严压着不发。

我：你替他办事，他为什么不替你说话？

苟安取出李丰的信。纸上两句清楚可读：“前议之事，切勿再行。若有人问起，莫再牵及家父。”

苟安：他儿子都叫我闭嘴。我还能找谁？

我：前议的是什么？

苟安：把迟粮的事往上报。不叫我报，我就去找别的出路。

我：魏国？

苟安看着我，没有答。

我：先别走。我查这批粮。查到什么，就报什么。

苟安将本队领取凭据压在信上，指住日期。

苟安：就这一天，粮已备足。你查李严为什么扣着。

我收好凭据。

我（心声）：若真是扣粮，查出来，也许还能赶上。

## 第三场 那批粮在哪里

【后方转运仓／白日。凭据核过，管事陪同查本批记录。】

仓吏将本队签收与出仓记录并排放下。两边批次相同，实交相合，缺额单列；途中损耗另记在行程册上。

仓吏：你们领走的，就是这里发出的。

**选择二：接下来查什么？**

- **A　核入仓和实收，找领取前的缺口。**

  我：领到手时已经不足。往前查，仓里究竟收到多少？

  仓吏：本批的都在这里。

- **B　先核损耗，确认是不是路上丢的。**

  我：这些损耗，能解释少的那一部分吗？

  管事：损耗另有登记。交到队里时已经少了，得再往前核。

两路合流。仓吏依次展开同批的入仓、地方实收、应征与缺额记录。每张停留足够读清关键栏，不另开收集页面。

入仓与实收相合；实收低于应征。已入仓部分都有发往本队的对应。

我：收到的都入了仓，入仓的都发了。缺的是起初就没征齐的这一截。

仓吏：催征后来停了，交付数却没改。

我：那苟安说的“早已备足”呢？

管事取出缺额报告，叫仓吏对照回执。

管事：同村，同一批。交接那日他就签认了，还在受罚之前。

我：签了之后补齐过没有？

仓吏：没有。当日的入仓账也在这儿。

报告上的“未征齐”与苟安的签认并列。我的手停在纸边。

## 第四场 他为什么选中我

【伤帐／傍晚。】

苟安伸手接我带回的材料。我没有递给他，将缺额报告摊在榻边。

**选择三：怎样问他？**

- **A　直接指出谎话。**

  我：你早知道没征齐，为什么还说粮已备足？

  苟安：我若说实话，你还肯替我查吗？

- **B　问他借我做什么。**

  我：你要我查李严，却把自己的签认瞒了。你到底想让我报什么？

  苟安：报粮不够，让大军退。你不是李家的人，比我说话管用。

两路合流。苟安抽出榻边一份军报底稿，放到缺额报告旁。军报写着“粮已备足，运途受阻”，具名者是苟安。

苟安：这份报出去的，也是假的。李严叫我这样写，我照办了。

我：先瞒住缺粮，又借我揭开？

苟安：他怕据实报上去，上头换个人继续催。我也怕再挨打。后来商量，宁可连他一起查办，也要叫这回停下来。

我：所以你就挑中了我。

苟安：你想留我，也想让大军继续打。说李严扣粮，你才肯查。

我：崖边救我，也是为了这个？

苟安：那时你快掉下去了。骗你，是后来的事。

我拿起军报底稿。他没有拦。

苟安：账你查过了。跟粮队回去看看种粮的人，回来再骂我。

## 第五场 最后一袋粮

【征粮村落／白日。管事获准返村核缺额，带我同行。】

村口的粮车没有装满。老妇抱着一个小袋站在车旁，递出袋口，另一只手仍攥着袋底。

我：这是家里剩下的？

老妇：大的死在军中，小的没熬过荒年。剩我一个，吃得少。

老运粮人拉住袋口，没有往车上提。

老运粮人：说好了，口粮和种粮留着。这袋拿回去。

老妇：前头的人也得吃饭。

他替她扎好袋口。她抱着袋子，站了一会儿才走。

我：别家还能再凑些吗？

老运粮人：能再装一点。装走了，开春种什么？

切返营交差。我把缺额和村中见闻交给军吏。他将材料放进待呈的军报中。

军吏：粮情照实呈。军中已在议退，粮不足，不能硬撑。只是魏军也在修路积粮，明年未必比今年容易。

我看向帐外。军士正在修补车轴。

## 第六场 他还留着一条路

【伤帐／夜。】

我：村里确实拿不出了。军中也在议退。把假报补正，别再走险路。

苟安：李严怕的就是只退这一回。来年换个人，再征一遍。

我：所以你还准备去魏国？

苟安：借他们的手，让“丞相要篡位”的话传回成都。朝廷收了兵权，才不会年年再打。李严知道这个后手，李丰的信劝的也是这件事。

我：魏人先问粮道在哪，你说不说？他们若趁退军来追呢？

苟安捏住衣角，半晌松开。

苟安：真话送上去，就一定肯听？

切交差处。军吏正在核阅我先前交来的缺额与村中见闻。假报底稿仍收在我衣内，此时尚未向他交代具名者及完整案情。

我：若有人早知道粮没备齐，却仍报足数，如今肯自己补报，还有没有回头路？

军吏：前军还在等先前军报上说的粮，后方却根本没备齐。伪报军情，查实可至死罪。肯停手、交代、补正，都能随案呈上。谁授意的，谁也得认；你我许不了免罪。

切伤帐。我取出底稿，原话转告。苟安把自己的名字看了一遍。

我：这份报，我会交。你和李严做过什么，也不能再瞒。

苟安：你准备怎么交？

**选择四：最终决定。**

- **A　交出全部材料，请军中接管查办。** → 第七场A。
- **B　陪他自陈，请李严共同补报、停止赴魏。** → 第七场B。
- **C　替他隐去赴魏安排，任他离营。** → 第七场C。

选项出现前，完整播放军吏的风险说明。选择后不再追加无信息的“确认／返回”一轮；不设限时，不因停留或回看自动选路。

## 第七场A 真相到了 人没回来

【伤帐／夜，接查问处／数日后。】

我：我不能再拿粮队去赌。全部交军中查，你留下接受查问。

苟安把军报底稿推向我。

苟安：拿去吧。查到哪一步，就说到哪一步。

我向军吏交出交接记录、缺额报告、签认、李丰来信和假报底稿，并当面说出两人的安排。军吏收下，命人看住苟安，另行传问李严。没有新的假报或赴魏消息在此时被放走。

数日后。查问处，我作为见证人在旁。

军吏：军中留的正报，与这份底稿对上了。“粮已备足”是谁写的？

苟安：我写的。我签名，托人递的。

我：他已说过，是李严授意。李丰的信也在案中。

军吏：李严一并查。苟安，明知不实，为何还发？

苟安：不这样报，就要继续追粮。最后还是这些村子出。

军吏：可以把实情补上。此前是谁议的，往后还准备做什么，一并写清。

苟安接过笔，写下自己的名字。

苟安：李严知道，也答应过。可报是我发的，去魏国也得我去。他倒了，换个人来，照旧征粮。这一份算我的，别再让旁人替我写了。

我：这不是你一个人的事。你还要替他扛到什么时候？

苟安没有接话，将笔放下。供纸上列着他已经承认的发报经过，却没有写撤回赴魏计划和更正粮情的补报。

切政务房。李严的回陈与其他卷宗并案。他交出官印；旁边的假报仍署着苟安的名字。

军吏宣读：李严隐瞒粮情、授意欺报，革职。苟安明知粮缺，具名伪报军情，判处死罪。赴魏之议未行，另记案中。

切伤帐。我走到榻边。铺盖已经收起，水碗倒扣着。

管事站在帐口，手里拿着名册。

管事：昨日行刑了。粮队要走，他这份东西，你帮着收一收。

我把碗翻过来。碗底干了，留着一道水痕。

接共同尾声。不要在宣判后追加“选错了”“未能说服”等评价。

## 第七场B 人还在

【伤帐／夜，接军吏案前及传信蒙太奇。】

我：跟我去，把假报怎么来的说清。再请军中送信，让李严把他的那一份也写上。赴魏的路，今天就停。

苟安：他若不认呢？

我：你的实话先交，不替他等。原信、原报都在，军中会查。

苟安：你就不怕连我也保不住？

我：怕。可我不能把这张假报藏起来，说你什么都没做过。

苟安把底稿摊平。

苟安：把纸拿来。粮未征齐，我明知。报是照他的意思改的，我愿当面认。魏国……不去了。

切军吏案前。苟安亲手交出署名的更正与自陈，我交上原有材料，并陈述自己所见。军吏核对存档正报与底稿，核收全部材料后安排苟安留营待查，由军中递送给李严的问询及两人联署的信。案情从此进入核查，不扣着案卷私等回信。

切李严书房，数日后。李丰把来信与军报副本放到案上。

李丰：他把自己的名字写上了。父亲呢？

李严：当初说停征，我怕百姓交不出；说粮已备足，又怕问罪到我头上。

李丰：如今还让他一个人认？

李严把只写苟安具名的军报移开，取纸。

李严：假报是我授意。粮情照实补，借魏的后手作罢。我署名。

切营中。军吏拆开回陈，核阅李严的署名补报，与苟安自陈、原始材料合卷。

又数日后。军吏向我和苟安宣告裁处。

军吏：两人自陈、补正粮情，停止未行之计，核实从轻。李严免去本次督运之职，另受处分。苟安免队长，留作粮兵。

切退军途中。苟安的伤已能随队做活。他和几名粮兵推着空车，车轮陷进车辙。

他回头看见我。

苟安：别光看着，搭把手！

我抵住车后，和他们一起用力。空车越过坎，继续往南。

接共同尾声。处分以本场正式告知为准，不能在写信或署名时提前显示获救。

## 第七场C 还是走上了险路

【伤帐／夜，接营外及退军路。】

我：粮情和假报我照实交。去魏国的事，我暂且不说。你若非走不可，我不拦。

苟安：想清楚了？方才你问的那些，我也没法保准。

我：你说是为了让他们活下来。别把粮队交出去。

苟安没有应下。他撑着榻沿起身，穿好外衣。走到帐口时回头看我，我没有喊人。

切交差处。我交上粮账、报告、李丰来信及假报底稿，说明已知的欺报经过，隐去赴魏散谣的具体后手。军吏将材料收下。

军吏：苟安呢？要叫他来核问。

我看了一眼帐外。

我：不在伤帐。

军吏起身，叫人去找。

切营外，苟安的身影沿山道走远。此后几日，查找未获。

切魏军营门。苟安被带到案前。魏军吏员展开一张道路图，压住他试图递出的说辞。

魏军吏员：想让我们信你，先说粮车从哪儿走。

苟安看着图，没有立刻伸手。画面停在他的手上，切黑。

字幕：此后，苟安经魏人安排返蜀，散布篡位之谣。召军的命令终于传来。

切退军路。军吏念完召军文书，将它与先前查粮材料放在一起。

管事：他去魏国的事，你早知道？

我：知道他打算去。

管事：那时怎么不说？

车夫在前方催人跟上。我把原先替苟安端过的碗放进车里，跟着队伍向南。

接共同尾声。本线确立投魏、返蜀传谣及召军，不把图前停顿当作已交出粮道，不追加未经演出的追击或伤亡。

## 共同尾声 再往前找

【退军山路／白日，接书库。】

空车经过山路。A线车旁没有苟安；B线他与我同推；C线我独自跟在车后。只播放本路线画面。

车轮声延续到书库。案上的缺粮记录下，露出更早的征发名册。我的手掀过几页，停在又一处成片的缺额。

我（心声）：这回的粮，还是没有。再往前找。

我把更早的一卷移到面前。翻页声停，章节结束。

## 单轮时长预算

以下是排演目标，包含对白、动作、文书停读、转场和一次正常选择思考；不是成片或试玩实测。剧情中的“数日后”用转场压缩，不要求玩家真实等待。

| 段落 | 目标时长 | 主要留时 |
| --- | ---: | --- |
| 第一场 | 60秒 | 救援、认人、一次选择 |
| 第二场 | 75秒 | 交接疑点、第一封信、查粮动机 |
| 第三场 | 90秒 | 同批账页与签认停读、一次选择 |
| 第四场 | 80秒 | 一次选择、谎言与假报揭露 |
| 第五场 | 65秒 | 老妇交粮动作、沉默、返营军情 |
| 第六场 | 90秒 | 赴魏风险、处罚预警、最终选择 |
| 第七场A | 130秒 | 查问、供纸、处分差异、空帐 |
| 第七场B | 130秒 | 自陈、李严署名、核收裁处、推车 |
| 第七场C | 110秒 | 放行、隐瞒、投魏与返蜀后果 |
| 共同尾声 | 20秒 | 本路线退军画面与旧卷 |

共同段落460秒。A、B各610秒，约10分10秒；C为590秒，约9分50秒。前三处局部分支的对白略有长短，应在对应场次预算内调节，不逐个增加停顿。正常选择思考合计预留约40—50秒，包含在上表；长时间停留、重复回看和未来可能增加的AI输入不受十分钟硬限制。

对白按每分钟约220—250个汉字作初估，紧张处可以快，空帐、村口、推车处留动作与沉默。不能为了追时长加速所有台词。若排演超时，先压转场说明及重复账页展示，不删第六场风险提示、A线查问或B线真实补报。
