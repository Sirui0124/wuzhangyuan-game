# 思绪画布：连续推理与语言组织

正式入口为 `http://127.0.0.1:8812/`。2026-10-22 用户选定「灯下墨卷」材质方向：暖纸、深墨与朱砂，页边浅云纹，军营退为极淡底景。结构为已确定的「左右对照」：左边为实际参与的依据，右边为本次得到的认识。所有内容统一楷体，只保留问题／结果28px、正文／线索20px两档；按钮独立设置。画布分为线索推理与语言组织，按当前剧情开放；交谈中可以回看推理，再返回自己的表达。

## 灯下墨卷：本轮材质与密度

- 花纹集中在页边、线索栏与详情浮窗角落；正文区域保留干净的暖纸底。线索不再铺深色方框，以细墨线、朱砂小点组织。
- “推理”采用朱砂印章形按钮；添加、收回、线索选择与浮窗关闭沿用朱砂色和同一纸面。语言组织的长文案按钮采用较扁的印记形，尺寸独立于内容字阶。
- 线索行最小高度34px、行间距4px；推理记录间距22px。详情仍锚定点击位置，不挤占历史流。首次进入时不重复显示同一个问题；有历史时在当前编辑区重现目标。
- 本轮将这一材质接入浏览器版。用户已选择方向，细部外观仍待试玩审阅。

### 第一章数量与版式示例

按当前 `chapter-one.script.json` 配置，首轮交谈取得T01、T03，分支A另外取得T02，因此是2–3条；回溯后的推理阶段可取得C01–C07、C09、C10，共9条原始见闻。主解法使用C02、C03、C04、C06、C07五条，另外四条提供补充信息。C08“姜维已明确应允”在实际通传、问准后才取得。

此前材料比较图中的9条原始见闻均来自当前配置；三轮拆分、分问和重复引用是版式演示，不表示额外剧情线索，也不表示正式流程强制分三步。新版预览用现行规则成立的一条路径演示：C02+C03→I01，I01+C04→R01，再由R01+C06+C07→R02。线索栏同时列出原始见闻和已有推想，因此条目数可能大于原始见闻数。此次不增删剧情线索或修改推理规则。

## 最终确定：固定画布，默认最后一屏

- 在同一窗口尺寸下，画布区域保持固定大小，历史在内部上下滚动，游戏页面本身不随历史变长。
- 每次打开、重新进入或读取推理存档时，默认展示最后一屏，即最新认识与当前操作区；历史向上回看，右下角保留“回到最新”。
- 推理成功时，新连线和节点显现，视野平滑移至最新位置。减少动态效果时直接展示。
- 玩家回看历史时，查看原话、展开或收起线索栏、放入或收回线索及普通重绘均保留阅读位置；不因这些操作强制回到底部。
- 线索详情在点击内容旁边浮窗显示，避开相邻的加号／移除按钮，随锚点移动，锚点滚出可视区域后关闭。详情不插入历史流，不撑高画布。
- 线索采用紧凑单行操作，移除为同行半透明小叉。加号打开可选线索栏；常规操作为“推理”，“润色表达”只在语言组织阶段出现。

多结构比较中的演示分问只用于版式讨论，不自动导入正式剧情或替代连续推理规则。此处确定桌面结构；窄屏仍按可用宽度排列。

## 连续推理

核心问题仍是“不能惊扰丞相，又不能耽误军情，怎么办？”左侧物品栏点击展开，一行一条短语，点击查看原话与来源，也可以拖入下方画布。首次进入时，默认摆好剧情中已经取得的两条见闻。默认摆放可以删除，不限制推理方向。

取消固定三步进度、预设分问及“下一步”按钮。玩家点击“推理”后，按实际放入的原始见闻和已有认识判断所有可成立的关系。支持直接得出较完整的结论，也支持同时产生两个独立分支。以下只是可行示例，不是必须遵守的顺序：

| 放在一起的依据 | 可以得到的认识 |
| --- | --- |
| 今夜闻号不退、随我军调动换向 | 或许在看我军如何应对 |
| 今夜不得入帐、伯约受命接报 | 可向有职责的人请求 |
| 往日闻号即退、今夜不退、随调动换向 | 今夜有变，可能试探 |
| 军情变化的判断、禁令、姜维接报职责 | 向姜维请求接报 |

每次的输入、曲线与新认识永久留在当前画布中。每条线索以边缘渐淡的纸墨底纹托住文字，不加下划线、小点或字印；朱砂色“推理”按钮紧邻当前编辑区。桌面每组输入位于左侧，新认识位于右侧，每条实际使用的依据分别连至结果；窄屏上下排列。上一轮实际得到的新认识自动带到下面编辑区的最前方，作为本轮固定依据，无移除小叉，线索栏也不能收回；点击仍能查看依据。若同轮产生两个分支，两条结论分别继承。手动添入的线索仍可自由增删；改变已形成的思路使用“撤回最近一次推理”。上方历史不会因增删手动线索清空。历史内容随推理向下增长，固定画布内部滚动；右下角入口可回到最新位置。展开物品栏、读原话、放入或收回线索时保留滚动位置。拖拽至画布上下边缘会自动滚动。

形成可执行的办法后，在下方出现“行动 · 去见姜维”。点击才进入真实通传、问准与同行剧情。推论本身不会产生本人应允、亲兵在场或军报闭环等事实。当前第一章的推理内容在这一行动处收束；画布容器不再依赖固定步骤数。

固定依据的样式（2026-10-22最新反馈）：移除上一版“承”字印。普通线索采用淡墨纸纹，上一轮结论在本轮作为固定依据时采用稍深的暖赭纸纹，文字保持20px、同一左边距与同行布局。底纹无描边，带轻微纸纤维和自然起伏的边缘；画布与线索选择栏统一使用，不再逐条加横线。固定项同时通过来源细线、无移除小叉，以及详情中的“承接上轮 · 固定依据”说明区分。开场预放的原始见闻仍按普通可选线索显示；沿详情回看原始来源时不沿用固定说明。减少页边云纹对比，去除结果下方笔刷线和编辑区装饰横纹，让结构线只承担来源关系。本次仅调整外观，固定关系沿用已有机制。

纸纹调整的构建、完整画布交互及固定视野检查通过，验证固定项详情、回看原始来源、原位浮窗、拖拽、增删、撤回、存档和新节点动效。1366×650窗口中的画布仍为1171×500，历史增加前后内部滚动范围由164增至333，页面滚动位置始终为0。实机图见 `outputs/paper-canvas-20261022/clue-wash/`；预览通过桌面及390px检查，正式8812入口已核对加载同一纸纹样式。表达检查使用模拟响应；本轮未重新运行整章通关或Cocos编辑器验收。

## 曲线与反馈

- 每个结果按 `output.used` 逐条连接实际输入；桌面由左侧来源连至右侧结果，窄屏从上至下连接。多分支只连接各自采用的依据；未采用的纸签淡显，保留在记录中，不加入实际推理依据。
- 新曲线逐条画出，连接点与认识内容随后显现，整组约1.6秒；连线采用淡墨色，重点与交互使用朱砂色。旧记录的连线不重播。上一轮结论与下一轮固定依据用1px浅色细实线相连：从结果左下方直接弯向固定线索底纹的上缘，以一段平滑弧线经过两栏留白，不再沿画布外侧折返。落点在文字上方，避开同排手动线索；窄屏沿左侧留白轻弯到固定项。鼠标或键盘聚焦可突出相关来源。
- 仅对最新认识轻微滚动以保证可见，之后由玩家自由上下阅读。减少动态效果时直接呈现；恢复存档不播放旧动效。
- 线索不足时不扣时间、不丢物品；提示补充相关见闻或更换方向，不再提示必须进入某个预设步骤。
- “撤回最近一次推理”移除该次新增的支持联系，收回相应行动，恢复该次输入；更早的记录保留。原始见闻和已发生的真实剧情不被撤销。

## 语言组织

使用相同的暖纸墨色、线索物品栏、楷体字阶与曲线。已选依据与“想说的话”输入区保持清楚的组织关系，旁边是“润色表达”按钮。允许输入最多600字，也可只写几个字或仅选依据。编辑文字和选择依据不会自动请求AI；玩家点击按钮后，调用现有AI生成及依据核对接口。要求保留玩家原意，并保留推论的不确定性，不从玩家原话中增加他人承诺或权限。

润色结果沿一条组织曲线向下展开，呈现为同一纸墨体系中的可编辑文本。该曲线表示依据向表达的组织过程，不表示新增推理或取得授权。玩家修改后点击“确认说出”才进入实际交涉。生成失败或取消会保留玩家原话与依据，也可以明确选择参考句。魏延仍位于右侧，窄屏优先保留操作区域。调整文本框高度时曲线跟随，结束动画不会打断正在输入的文字。切换回推理不会清空所选依据或表达草稿。

## 实现与存档

- `thought-workspace.ts`：基于实际输入选择可成立的新结论，保存 `version: 2` 的连续历史；原三步存档自动转换。
- `chapter-session.ts`：放入、收回、思考、撤回与模式切换；保留事实来源检查和真实剧情行动。
- `thought-workspace-view.ts`：历史节点、多个结果、末尾编辑区与行动区域。
- `thought-curves.ts`：按实际DOM坐标逐条绘制used来源曲线，处理连续引用的外沿绕行、表达组织曲线及相关来源高亮。
- `game.ts`：Pointer 拖拽、边缘滚动、默认进入最新位置、回看位置保持及渐次显现。
- `thought-detail.ts`：锚定在线索旁边的原话／依据浮窗、边界避让与滚动跟随。
- `thought-workspace.css`：保留画布基础结构与交互样式。
- `xuan-thought.css`：玄青风格与基础布局。
- `thought-final.css`：在玄青样式后加载，落实最终左右对照、固定滚动区、28/20px内容字阶、紧凑线索、独立按钮、浮窗和新节点显现。
- `thought-paper.css`：最后加载，覆盖画布的暖纸墨色、朱砂印章、统一浮窗与线索栏、紧凑间距；不改变其他剧情页面主题。
- `ui/ornaments/paper-cloud.svg`：页边与浮窗共用的浅色云纹。

同版本旧存档迁移保留已有事实、推理关系和待放置内容。旧图存档缺少操作历史时，将其已成立的认识作为起点；不会凭空补写玩家当时的操作顺序。剧情内容版本的兼容判定仍沿用完整游戏自己的规则。

固定依据不新增存档字段，从上一条有效历史的实际输出计算；旧存档曾移走该结论时，读档恢复其在编辑区的位置。撤回后由新的上一轮输出接替固定，撤到最初一轮则恢复可自由选择的原始见闻。此调整不为玩家新增未推导的结论或未发生的事件，也不要求固定推理顺序。
