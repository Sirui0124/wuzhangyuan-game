# 美术浓度对照 · 历史样张

用户认可现有整体方向，但认为过淡。本次提供三套可比较的视觉方案，保留浮动短句、细线、纸感与营地人物的构图。

本地入口：`/art-review.html`。可切换推理、交涉、对白、探索四组画面，支持三版并排、原版对照与单图全屏。

第二稿根据用户反馈回到舒展的脑图构图。推理页将八个已有见闻/推论沿曲线分布，交涉页保留三条敌情来源、两条所选依据及其通向表达的曲线。移除上一稿过于整齐的左右栏排布与粗重的文字效果。默认主文字采用系统楷体，提供同一构图的宋体切换；小号出处、操作和导航使用清晰的无衬线字体。

| 方案 | 视觉构成 | 适合的偏好 |
| --- | --- | --- |
| A 松烟朱砂 | 暖纸 `#f0e8d6`，深墨 `#272e28`，朱砂 `#a23d2f` | 延续原版纸感，重点醒目；建议优先考虑 |
| B 青碧铜金 | 青纸 `#dfe9e3`，青墨 `#176963`，铜金 `#88652a` | 保留青绿基调，增加色彩浓度和正文对比 |
| C 夜青鎏金 | 夜青 `#142c30`，月白 `#f2ead6`，暖金 `#dfb56b` | 更强夜营氛围与深色界面 |

共同调整：正文和来源的层次分开，推论使用强调色，连接点和线条更可见，圆形行动按钮填色，交涉中的魏延提高可见度。探索和对白保留当前素材，分别调整遮罩、姓名、对白框和行动指示的颜色。

此页保留当时的评审样张。用户已确认曲线脑图与楷体方向，现已按新交互接入默认游戏，见[思绪交互接入](THOUGHT-WORKSPACE-20261022.md)。以下说明描述原评审副本：四组内容取自独立浏览器内实际走过的第一章，不读取玩家存档、不调用 AI。第二稿的曲线展示已有推论的来源关系（包括中间推论）和所选表达依据，不增加游戏中的连线操作、知识或授权。位置调整仅存在于评审副本。原版按钮现在显示完整保留的默认游戏画面；字体按钮则可在第二稿相同构图中直接比较楷体和宋体。三种配色的剧情、人物、文本和知识状态一致。

楷体通过 `local('KaiTi')` / `STKaiti` / `Kaiti SC` 使用设备已有字体，未复制、打包系统字体文件。当前 Windows Chrome 已通过实际渲染字形信息确认使用 KaiTi；其他设备按本地字体回退，未宣称已验证跨平台一致性。

源码入口：

- `GameStarter/web-demo/src/art-review.ts`：评审页切换和只读画面容器。
- `GameStarter/web-demo/src/art-review-layout.ts`：第二稿的舒展脑图样张与来源关系曲线。
- `GameStarter/web-demo/public/art-review/mindmap.css`：楷体、同构图字体对照和脑图视觉细节。
- `GameStarter/web-demo/public/art-review/themes.css`：三套颜色变量与组件提案。
- `GameStarter/web-demo/public/art-review/scenes.json`：四组画面副本。
- `tools/migration/capture-art-review.mjs`：原布局的历史采集工具，不适用于现行物品栏布局；不要用它覆盖已确认的样张。
- `tools/migration/preview-art-review.mjs`：导出截图，检查切换、窄屏和存储隔离。

历史样张保持现状，可用 `node tools/migration/preview-art-review.mjs` 复核既有对照。现行游戏使用 `npm run build` 后执行 `npm run test:thoughts`；截图位于 `outputs/thought-workspace-20261022/`。

验证：TypeScript 构建；3 版 × 4 画面浏览器截图；楷体真实字形、楷体/宋体切换；笔记不遮挡中央问题和表达正文，完整表达不裁切；并排/原版切换；768px 和 390px 评审页无水平溢出；评审页面无游戏存档写入。未更改默认游戏玩法、正式资源绑定和视频审阅状态。
