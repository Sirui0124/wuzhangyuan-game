# 语言组织请求结构修复

2026-10-23。用户要求修复选中材料与原始对白混用，导致魏延旧话被复述给魏延、历史方案覆盖后来承诺的问题。此记录不代表用户审核通过。

开发前读取飞书协作原则修订30的语言组织约定、魏延两轮设计修订167相关内容，与本地约定核对。本次是生成接口修复，没有修改逐句剧情、魏延三结果条件或在线审核状态。约定的 AI 编剧聊天当前无法访问（no rollout found），由本次执行直接完成生成模块，未改其判定模块。

## 原因与改动

- 原生成输入复用了判定输入：selected 含整段 originals，推论又展开连通组的底层原话。生成端现在只收到独立 brief：当前交谈、玩家原意、实际选中的语义材料。核验端另外收到 verificationSources。没有把全库、脚本逻辑字段、存档状态或推论底层对白发给生成端。
- T03 标明魏延在本轮已告诉我，生成必须承接，不冒充新情报向他复述。C05 单独标为上一回的回忆，不能伪造这次会面双方刚发生的对话。屏幕与 Prompt 使用同一函数取得眼前魏延的话，解决首次进入时 UI 有追问而请求 feedback 为空的问题。
- 推论的来源只取自身配方，不展开连通组其他卡片；原始对白保留在核验请求中，不丢失溯源。
- R02/I03 在表达投影中是历史方案，不再作为当前未应允的状态。已完整取得且本次选中的 C08 表达姜维本人接报、判断、担责和帐外等候；职责、方案或未选中的承诺不能代替它。原画布历史卡不改写。
- 空补充输入时组织所选材料；有原话时保留原意、否定、疑问及不确定性，不自动补过关答案。玩家主动写出的真实细节可以由对应所选来源核验，不因摘要较短而被误拒。移除首轮默认追加“请将军稍候”的安排，并明确未来提议允许保留不等于允许代填行动。
- 输出仍需独立核验才进入 ready；失败保留实际草稿，并明确显示先前草稿标识。玩家编辑后才重新确认，不自动说出或推进事件。
