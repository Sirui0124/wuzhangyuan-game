# 通用物品失败结局：妖孽现世

2026-10-25，用户要求：手机购买的物品在表达沟通中出示，AI判定非常不符合朝代常识且不能自圆其说时，被当作妖孽抓走。机制已接入；用户随后指定的猪血版文案已更新，实际游玩仍待用户review。

## 已实现行为

- 第一章第二轮魏延物品交涉、第二章当前已实现的苟安开放交谈，共用时代常识判定契约。没有按物品名称或编号设置禁用清单。
- 仅在玩家确认说出时，检查本次实际出示且仍可用的已购物品、真实原话和相关历史解释。购买、库存、附上但未提交、润色均不触发。
- 同时满足“实际展示严重违背当时常识”和“解释不能成立”才触发。现代来源、陌生名称、一般用途不成立或缺配件不构成此结局；合理解释或证据不足不触发。物品规格不支持的超能力不能因为玩家夸口就被当作真实发生。
- 先看到对方的抓捕回应，再继续进入黑底文字结局“妖孽现世”。本轮未制作新视频。
- 失败不批准方案、不加交涉分、不收礼、不消耗物品、不完成军报交接或解锁下一章。第一章纳入结局卡册，独立于成功物品结局。
- “重试本次交谈”保留原话、所选物品、购买账本、余额和此前线索；仅回溯失败发言。玩家可以撤下物品或修改解释。第一章已有真实授权和先前交谈保留。
- 读档验证物品来源、两个条件、实际原话、回应与历史一致性；第一章旧版未读AI判断要求重新判定。服务异常、无效JSON、未知物品或不实引文保留输入供重试，不进入失败剧情。取消、读档、重开后的旧响应不能提交。
