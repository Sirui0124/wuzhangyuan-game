# 历史章节顺序解锁

来源：2026-10-27 用户明确要求顺次体验，兼容已经玩过后续章节的存档，并重新打包。实现前读取了在线协作原则修订39；本条是用户后续新要求，不改变章节内部的通关条件。

顺序为五丈原、祁山、街亭、夷陵。新玩家只能进入第一章；成功通关前章后才开放下一章。章节失败、影片播放完成以及开发试玩不算通关。原有各章成功条件保持不变。

`wuzhang-chapter-history-v1` 独立记录实际进入过及成功通关过的章节。若旧自动档、手动槽或重玩备份能证明已经进入后续章节，则保留该章并开放此前章节重玩，但不推断该章也已通关，不开放它后面的章节。正式成功结局卡与原有 completed 标志可以补回通关历史。损坏记录、孤立影片记录和专用试玩存档不作为资格。

2026-10-28 用户纠正：主菜单“新游戏／开始新的经历”重新建立章节进度，只开放第一章，各章自动档和通关标记先备份再清除，后续必须重新通关解锁。手动存档和成就保留，但不再自动补回旧解锁资格；以后正式游玩产生的通关记录仍正常解锁下一章。章节内“重玩本关”和舆图重玩保留已开放章节，读取早期存档也不撤销本轮资格。补认此前章节只设置进入资格，绝不写入虚假的线索、通关成就或人格选择。舆图对补认章节显示“已解锁／重玩这一章”，仅对有正式成功记录的章节显示“已通关”。

`entry.ts` 在加载章节之前检查资格，旧第二章页面也回到该入口；未开放网址返回舆图并提示所需前章。数据由 `chapter-access-manifest.mjs` 从正式剧情节点和成功结局生成，入口与舆图共用同一读取函数。各章仅在正式游玩持久化时记录历史，开发试玩不写正式历史。

验证：`GameStarter/tests/chapter-progression.test.mjs` 覆盖新记录、顺序完成、死亡失败、旧自动／手动／重玩备份、坏档、试玩隔离和旧记录补认；`tools/migration/chapter-progression-smoke.mjs` 用独立浏览器资料检查舆图、直达网址、别名、旧页面和重玩后历史保留。实测报告位于 `outputs/chapter-sequence-20261027/`，安装版检查与本次安装产物另存于对应发布目录。测试不操作真实玩家存档。
