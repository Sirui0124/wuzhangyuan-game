# 街亭：分兵轴与对话反馈

2026-10-27 用户要求展示 25,000 人的分配与剩余交流机会，固定在页面上方，每 5,000 人一格；中间写“目标：尽可能多地让马谡把兵分到山下”。最新追加要求已改为最多五次自由进言，20,000 人到营时完成本段目标，提前进入第三幕；完整规则以[连续进言与分兵](CHAPTER-THREE-PERSUASION-20261027.md)为准。

## 当前实现范围

第二幕共用一条上方固定的只读横轴，放在对话和表达滚动区之外。在线表达、普通选项、马谡回应、军令和到营回报使用完全相同的顶端位置与宽度。绿色表示山下已到营，褐色表示尚未计入山下的部队，虚线斜纹预示拟增派或已下令待到营的人。

每 5,000 人一个分隔，10,000 人处强调“可商议诱敌”的兵力门槛，20,000 人处为分兵目标；仍须完成第三幕，不承诺达到任一数值即赢得本章。目标句位于横轴顶部中央，左右分别为总兵力和剩余进言。正文 18px、人数 20px、刻度 16px，窄屏对应 16 / 18 / 14px；维持其他共享对白和选项字号。

最多五次分兵机会，每轮可有一次必要追问，补充理由不再扣一轮。只有本地记录一轮决策后，剩余机会才减少；润色、错误、中止等待和重试不占机会。两万人实际到营后显示目标达成，不再要求用完剩余机会。
