# 傅肜断后 · 导演分镜稿

2026年11月11日｜22镜｜预计142秒｜第三人称原结局影片

先让观众看清能撤的路，再看它被一层层堵住。以一名举盾军士的转身、护卫和倒下贯穿战斗；劝降时让厮杀暂缓，最后停留在傅肜撑不起身体的动作上。

## 摄影与场地基准

16:9满幅。烟尘遮光的自然日光为本稿拟定，中性自然色，远处火光只影响邻近物体；不加雨、不加整体黄染。通常采用稳定机位，50mm正常视角为主，全景可用35mm、近景可用75mm。全程正常速度，只有环境声、动作声与明确写出的对白，无BGM、无配乐。

山脚退路横贯画面，刘备与退兵从右向左撤；吴军从右向左追，右上坡有支路可绕到窄口左侧。傅肜请命后转身向右迎敌，之后向左突围。丁奉位于右侧高坡，向左下看围阵。举盾军士徒步，始终留在傅肜近侧；傅肜全段骑马。

## 连续性关键

1. **方向与视线。** 01、09、11建立同一条退路及坡上绕行支路；刘备向左离开，傅肜转马向右迎敌，随后向左突围。12、14、15中丁奉看左下，16、17中傅肜看右上，接在11的空间关系之后；不插入把高坡移到退路另一侧的反打。
2. **人、马与兵器。** 举盾军士在02转身、05归入后阵、06与10护住傅肜、13仍在，18才倒下；19余下两名蜀兵倒下，此后不再出现活着的随从。傅肜始终骑同一匹马、持同一支长矛，22矛落地但人不坠马；已经倒下的人与盾保持原位置。
3. **递进与死法。** 身上尘污、盾面损伤与喘息逐镜累积，21之前不提前出现口中血。两次突围受阻后才劝降，拒降后再战；死亡来自力竭吐血，21以后不增加穿刺、斩首或摔马。15的刘备被擒是丁奉劝降的假话，前面刘备已经撤出的画面不可删成真假不明。
