# 魏延回应口吻修正

2026-10-26，用户在“规划线下演示PPT内容”中要求通知AI调整：彻底去掉“莫把XX当作XX”及同类说教，NPC不必把条件分析说得如此细碎。

## 改前与改后

原截图台词：“这物件倒能派上用场。先交清军报，再按你说的条件试，莫把打算当作已成。”

这句来自 item-dialogue.ts 的固定接受台词，修改模型提示词本身不会改变它。现改为：“好，先把军报交给伯约，再照你说的试试。”对讲机与灯号两条固定回应也删去重复解释；物品方案仍先交军报，具体能力与配件照常在后台判断。

普通追问与物品交涉提示词要求直接回应当前问题，不列检查清单、不拆解责任、不说教；显示前检查“莫把／不要将／别拿……当作／视为”等形式，以及“不是……而是……”和“不要以为……”的训导表达。命中后使用当前分支短回应，不截断成残句，不修改接受或拒绝结果。此检查覆盖明确句式，不声称能穷尽所有不自然表达。

本次只改魏延的普通AI回应与物品交涉，没有改供应商配置、语义通过条件或其他章节正在开发的AI模块。原始试玩记录和截图保留在 `outputs/demo-desktop-playtest-20261026/`。

## 验证

构建、架构检查通过；NPC与物品相关56项测试通过，其中确认违规句式不会将拒绝变成接受，接受文案也不能改收件人或声称已经完成行动。

使用真实接口，按原试玩输入重建纸笔属性，得到：

- 两件齐全：接受item-plan，“好，先把军报交给伯约，再照你说的试试。”
- 只有纸：继续解释，“纸有了，笔呢？军报先交姜将军，别耽搁。”
- 首轮只说明禁令：继续解释，“帐门不可闯。这军报，教谁去传？”

同轮收到二锅头与仙女棒的补充样本后，增加对当前物品和动作的回应要求，去掉“核令、具体安排”等流程词，并重新构建与运行56项相关测试，全部通过。最终真实接口复测使用原试玩发言、重建商品属性，得到：

- 二锅头：继续解释，“酒先搁着。军报呢？姜将军还在帐外等着。”
- 仙女棒与打火机：继续解释，“帐前岂容你玩火？收起来！军报呢？”

这两条仍判为未说服，没有把喝止或推拒改成接受。回复开始承接具体物品与动作；没有增加点燃动画，亦未验证画面效果。新样本记录为 `outputs/npc-voice-20261026/live-items.json`。

这是实际接口测试，未重新购买商品，未操作用户当前会话；不冒充新的桌面截图或用户审核。输入、原始模型输出和最终台词见 `outputs/npc-voice-20261026/live.json`，构建和测试日志同目录。8812服务已确认提供新固定台词。专用在线设计稿已追加本次反馈并回读核验，待用户试玩。
