## 主界面与整体视觉

沿用用户已明确的布局：剧情画面为核心，中下方放对话与选项，右侧「出示证据」点击展开浮层，右上角保留设置、存档、帮助三个常规按钮。用户进一步明确：玩家自主决定先后去哪个已开放场景、找谁聊天和选择什么对话。地点入口、人物热点和对话选项共同支持这一探索过程。

人物采用电影写实方向，参考《隐形守护者》《盛世天下》的影像叙事感。普通对话使用人物与场景静帧，关键结果用视频；人物融入现场光线，面容、服饰与影片连续。五丈原以冷暗秋夜军营、旧帆布、粗木、麻绳、铁器和油灯建立氛围。保留风尘、疲劳与材料磨损，服饰在正式制作前核对时代依据。

UI 的历史感来自符合军营的文书、凭条与墨线。墨黑半透明底 #171917、绢白文字 #E7DDC8、暗朱砂强调 #954638。标题用有书写感的字，正文与输入使用易读中文字体。口述证据直接展示人物来源与原话。

2026-10-11 用户对首张风格图明确修订：人物总体方向保留，写实感再增强；下方对话框相对首稿增高约 30%，透明度 30%（按 70% 不透明度制作）；移除金黄色对话框边框和装饰；对话选项字号与主台词字号一致。这些要求优先于下文早期比例建议。最新图为 `../source-art/UI风格探索_v02/01_剧情对话主界面_v02.png`。生图中的几何和透明度为视觉近似，正式分层 UI 使用准确尺寸、字号与透明度值。

以桌面 16:9 为讨论起点：画面主体约占上方 70%，中下方约 25%–30% 容纳对话、选项或输入。地点入口沿画面左侧边缘排布，避免和右侧证据入口及中下方对话冲突。证据浮层打开时覆盖右侧约 35%–40%，仍可看见交谈人物；比例在设计稿中验证。

## 人物与场景资产

| 人物 | 剧情职责 | 表现与交互 |
| --- | --- | --- |
| 玩家 | 穿越到普通值守小卒的位置；可询问、递话，没有调兵和擅改传报权限 | 游戏内以第一人称为主；开场可见穿越前人物与小卒衣袖，称谓按小卒身份统一 |
| 守帐卒甲 | 告知禁入、急报规则；直接路线接报并警告风险 | 朴素军装、职责明确；可点击选择，与乙的面容、服饰细节和站位区分 |
| 斥候 | 提供真实军情和未知范围 | 奔走后的呼吸与风尘，紧张但不夸大；可点击选择与追问 |
| 魏延 | 急报必须抵达有权处置的人；关键举证对象 | 急迫、警戒、履职压力；可点击选择，不能以反派造型暗示蓄意害人 |
| 传令卒乙 | 第二轮关键举证对象；向帐内姜维递话与转报 | 以传令职责识别角色，保留普通小卒的身份感；许可由姜维给予，乙不表现为指挥官 |
| 姜维 | 始终在帐内，听取通报、给予有限许可并出帐处置 | 帘边回应、出帐接报与军令演出；不设置远处军营中的可选人物入口 |
| 诸葛亮 | 情感目标，病中位于帐内 | 咳嗽、疲态、灯火与帘缝视线；本关不增加直接问话入口 |
| 军法执行者 | 架空直接路线的追责演出 | 只需押送、刀影与黑场所需镜头，不新增可交涉系统；不借诸葛亮形象下令 |

四名可选择交谈角色为甲、斥候、魏延、乙；姜维、诸葛亮与执行者属于剧情演出人物，不计入四名交谈角色。

| 地点入口 | 当前可选对象 | 场景表现与解锁 |
| --- | --- | --- |
| 中军帐门 | 守帐卒甲、禁入告示、帐帘 | 首轮和复活落点；查看告示、听咳嗽、询问；首次显示「第六夜·傍晚」 |
| 营前传报处 | 斥候、魏延 | 营内传报位置；听军情，选择魏延交涉；不扩成营外自由探索 |
| 传令侧帐 | 传令卒乙、递话窗口 | 首轮导航中隐藏，保灯后被处斩并得知线索才解锁；普通灯灭不解锁 |
| 中军帐外候报处 | 魏延、传令卒乙、军情交接点 | 帐门底图可复用构图；乙到场后才出现他的可选热点 |

地点入口表示当前可去的位置，依据场景发现、人物到场和事件状态开放，同一阶段开放的地点可由玩家选择访问顺序。切换场景清除当前交谈对象和目标证词。当前可选人物以轻微热点和姓名提示呈现，选中后在对话框显示名字。首次进入多人场景给一次「选择人物交谈」提示，随后收起。

侧帐解锁时短暂显示「你记起了另一条传报途径」，地点入口旁显示小号常规「New」，玩家主动点击后进入。此线索跨循环保留，后续普通回溯不用再次播放引导。

### 场景内人物选择与 New 标记（最新视觉修订）

左侧地点字号与「军情紧急」主台词一致，标签相对原稿横向加长约 20%，保留旧纸和暗朱砂材质。正式 UI 共用字号变量，并用相对原稿的 1.2 倍宽度落实；位图只表示视觉方向。最新视觉稿位于 `../source-art/UI风格探索_v03/`，替代 v02 的主界面导航样式。

此前图 3 是人物造型对照，不是交互页面。现新增独立人物选择状态：点击地点后展示场景中景与当前在场人物，人物腰侧显示简洁对话图标和姓名；点击人物或姓名，进入该人物的近景对话。结束交谈返回同一场景，再选另一人。此时不展示大对话框，底部只保留「选择人物交谈」提示。人物离场时移除热点。未选对象时，右侧入口只允许浏览证据，不提交举证。

「New」使用小号常规无衬线文字和低饱和灰色圆角底，不发光、不闪烁、不用大红点。新场景标在地点标签旁，首次进入后消失；新人物标在姓名旁，首次开始交谈后消失。发现与已读状态跨循环保留，已知人物换场景或普通回溯不重复标新。侧帐在剧情条件满足前仍隐藏，不能通过标记提前透露。视觉稿同时展示两类标记用于讨论样式，不代表严格的同一存档时刻。

## 玩家决定探索与谈话顺序

基本操作为：**选择地点 → 选择当前在场的人物／调查物件 → 选择话题或查看 → 获得信息 → 继续追问、换人或换地点。** 对话选项与人物选择是两层操作：先决定找谁，再决定问他什么。结束当前一段对话后可选择「换个话题」或「结束交谈」，回到场景；新证词和证据保留。

首轮在两个已开放地点间，可以先问甲再听斥候，也可以先去听军情，再回帐门查看告示。营前传报处可以先找魏延了解诉求，也可以先找斥候取证。缺少关键证据会影响交涉是否成立，但不禁止玩家先与人物聊天。

第二轮侧帐已发现后，玩家也可先去找乙了解职责，再回其他地点重新取证；乙不会因为玩家先来就自动批准转报。凭条取得、乙到场、军情交接等有因果依赖的步骤仍需按实际条件完成。

人物的话题列表随当前信息和事件更新。已问话题可重读，新解锁话题轻微强调；关键行动和普通询问以文案区分，避免玩家把「询问传报办法」误认为已经「托乙递话」。人物离开后更新场景热点，不能通过旧头像继续对话。

场景导航轻量呈现地点名称与当前位置，不用编号指示唯一访问顺序。待兑现承诺只提示当前需要处理的事情，不强制自动跳转；玩家仍可选择离开，但会推进等待窗口的无关行动须在执行前提示后果。阅读、输入、重读和等待服务响应继续不推进事件。

## 从人物选择到举证

证据浮层顶部显示「向魏延出示」或「向传令卒乙出示」，同时保留当前要回应的原话／话题摘要。按钮面向当前选中人物，不默认魏延；未选人物时可查看证据，但提示「先选择交谈对象」，不发起举证。单纯查看告示或帐帘不等于选中交谈人物。

1. **选人物与原话。** 对话框显示当前人物，关键证词可拆成短句选择。乙的交涉以请求递话的当前话题为目标，不强行替他编造「必须进帐」的错误证词。
2. **选证据。** 右侧浮层展示本轮可用证据，支持查看、选择和组合；选中证据不会立即提交。
3. **表达理由与安排。** 浮层收拢为证据条目，对话区展开输入框。对魏延提示「为什么不必闯帐？军情由谁接、怎样送达？」；对乙提示「这些证据说明什么？你希望他向姜维递什么话？」
4. **提交与回应。** 按钮分别显示「向魏延说明」「请乙代为通报」。回应进入已编写分支，再出现可执行行动；不会因 AI 认可直接更新接报、授权或通关结果。

普通调查、场景切换、选择人物和交接使用预设操作；关键举证与传报方案修订支持开放输入。切换人物后清除上一个目标与已选证据，文本草稿按交涉对象保留但需重新选择并提交，避免把给乙的请求误送给魏延。

## 本轮证据、回溯记忆与许可

证据浮层默认显示「本轮证据」，低强调入口打开「回溯记忆」。每条内容显示名称、类型、来源、原话／内容、取得时机、已知和尚未确认的范围。剧情来源在详情中区分正史背景、演义情节与游戏补写。

| 内容 | 可证明的范围 | UI 状态 |
| --- | --- | --- |
| 守帐卒证词 | 禁入安排存在，急报不能扣；玩家没有改传报权限 | 本轮询问取得；风险提示可重读 |
| 禁入告示摘录 | 禁止闲人入帐 | 明确不能据此宣布急报无须处理；本轮查看取得 |
| 斥候军情证词 | 魏军逼近、营门尚未失守，敌军意图未定 | 保留原话；不得将敌军试探画成已证实事实 |
| 姜维传报凭条 | 本夜这次军情可由乙递入，姜维出帐处置 | 游戏补写的有限许可；不得调兵、拘押或延期，回溯后重新获取 |

【姜维在帐内】是笔记事实，不伪造为盖印文书。姜维回话／军情回执是交接记录：取得后弹出简短获得反馈，并可从对应军情条目重读；不为了回执新增第五类推理证据。军情交接完成时关联证据增加「已交接」标记，原始证词仍可读。

回溯记忆中，旧证词、告示与凭条均标记「上一轮记忆·本轮未确认／未获准」，可读但不能选入提交。按记忆快速确认必须重新触发当前地点的查看或询问，生成本轮记录；旧凭条始终需要本轮向乙举证、递话，再取得姜维许可。

四类证据无需复杂背包和搜索。通过两处入口组织本轮与记忆，不用大量分类页；记忆不额外增加主界面按钮。

## 说服后必须兑现行动

对话框上方只保留一行当前承诺，例如「魏延在等回话：去帐门递报」。行动完成后更新下一步；详细来往记录可展开，不铺满常驻任务栏。行动按钮和人物反馈共同明确哪些步骤仍未完成。

| 路线阶段 | 提示与玩家操作 | 完成反馈 |
| --- | --- | --- |
| 直接路线：魏延暂缓 | 「去帐门叫姜维」或「返回解释办不到」 | 仅获得等待机会，主灯与军情暂不结算 |
| 甲告知风险 | 展示未经许可改变传报的警告；选择「先把军情递进去，责任由我承担」或收回安排 | 警告必须可见，避免无提示惩罚；承担责任仍不等于军情已送达 |
| 直接路线递报 | 实际点击「交付军情」 | 甲递入急报，姜维出帐处置，主灯保住；之后进入固定架空追责剧情 |
| 乙答应递话 | 实际点击「托乙向姜维递话」；可选预设请求并补充文本 | 展示递话、帘边回应，再获得凭条；乙答应时尚无许可 |
| 凭条说服魏延 | 魏延查看凭条，要求接报人到场 | 「到侧帐请乙来接报」；本轮已有许可，但乙未到场 |
| 乙到场 | 切换侧帐选择乙并请来；随后前往候报处 | 候报处出现乙；更新提示「选择魏延，交接军情」 |
| 军情交接 | 选择魏延，点击交接 | 乙接报递入；条目标「已交接」，提示「选择乙，收取回话」 |
| 回话与转达 | 选择乙收取姜维回话，再点击「转达原话」 | 回话已取得、魏延领命分别确认，执行链完整后播放安全结局 |

未经许可路线的风险是游戏架空剧情，应在帮助与剧情来源中明示；不展示为史书记载或真实军法条文。追责不由 AI 自行生成，姜维出帐处置也不等于追认玩家程序。

本关没有真实倒计时。阅读、写字、看可暂停影片和等待请求不消耗事件时间。推进事件的行动标明影响；已承诺递报时选择无关行动会先出现「魏延正在等回报」临界提示，后续按规则结算。场景导航不能把去侧帐找乙等必要转移误判为无关行动。

## 三项结算与回溯

结果影片结束后以一张简洁结算面板呈现三项，不用统一「成功／失败」印章覆盖不同结果。第三项处理完成和领命等执行事实放进军情说明。

| 结局 | 主灯 | 军情 | 玩家与下一步 |
| --- | --- | --- | --- |
| 普通灯灭 | 熄灭 | 按实际状态显示未送达／交接未完成等 | 显示具体因果缺项，回到当日傍晚；不新增侧帐入口 |
| 直接路线保灯后处斩 | 守住 | 送达，姜维已处置 | 越职转报，被处斩；取得乙的线索，黑场后「回到傍晚」 |
| 授权路线完整执行 | 守住 | 送达，回话已转达、魏延领命 | 生还，本关完成；提示此前病与劳损仍未改变，进入更早章节入口 |

处斩演出采用押送、刀影和黑场。玩家最后看见仍亮的主灯，乙的侧帐线索在死亡前出现，不能被第一次观看的跳过操作漏掉；重复影片可跳过，跳过时展示必要文字摘要，按确定的剧情事件结算。

死亡后完整回溯至傍晚，保留已见结果、乙的线索和记忆；物品、当轮证据、姜维许可与全部执行状态重置。本关结果界面不提供越过教学死亡、直接沿用许可的检查点入口。常规存档继续用于保存进度，存档缩略信息标明是否得知侧帐、当前许可和交接状态，避免恢复时混用轮次。

任何技术错误与论证驳回都留在当前交涉，保留草稿和证据，不显示死亡结算，不解锁侧帐。请求期间防止重复提交；返回后若已切换对象、场景或回溯，旧结果不能落到新状态。

## 常规入口与首版界面清单

设置包括音量、文字速度、字幕／重复影片跳过与显示选项。存档包括当前章节、地点、关键状态与保存时间。帮助用例子说明证据范围、有限许可、承诺兑现、事件推进和回溯规则，并区分正史、演义与架空内容。

首版覆盖同一主界面的对话、人物选择、地点导航、调查详情、证据浮层、交涉输入、行动提示和交接反馈；另需结算／回溯、设置、存档、帮助面板。复用同一字体系与面板样式。

## UI 验证清单

1. 初始导航无侧帐；普通灯灭无侧帐；保灯处斩取得线索并回溯后，侧帐出现一次性引导，玩家自行进入。
