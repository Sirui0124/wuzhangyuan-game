## 共同边界与清理

`projectDecision` 仅复制编号、文案和可用状态，不把跳转、条件与效果交给界面。章节按既有状态计算当前选项，界面确认后以 `acceptsChoice` 再核对节点与选项；失效或伪造选项不执行。原运行器继续复核并记录动作。

删除第二、第三章手机适配器和第二章运行入口的手机解锁分支。旧物品附件回归支持独立标为 legacy；钱包、物品、旧聊天的解码仍保留以兼容历史存档。清除线索获得提示功能，将现有剧情物品获得提示迁为独立 `item-receipt` 模块与样式，不再存在向思绪面板飞入的提示分支。

本轮没有修改存档 schema 或 contentVersion；正文、分支、效果及条件配置原样保留。选择投影为副本，不能通过界面改写剧情节点。
