## 架构结论与本轮修改

网页入口负责装配，各章运行器分别维护剧情状态和存档，共享层负责进度、存档保护、影片、字幕与界面组件。检查了 214 个 TypeScript 模块，未发现运行时循环依赖或章节越界导入。当前没有证据表明需要整体替换章节框架，因此保留现行机制和存档格式。

本轮将素材发布约束提取到 `tools/video/media.mjs`，构建与资源检查共用。复制影片前检查配置与清单是否一致、编号和文件是否重复、来源与 URL 是否对应，以及文件大小和 SHA-256。校验发生在清除构建目录之前，缺片或内容被替换时直接报错。新增四项故障测试，覆盖漏列、冗余清单、路径错误、文件截断及同大小内容替换。

本地服务现在监测素材校验模块、字幕工具、字幕目录及空轨记录的变化，使这些依赖更新后能重新构建。

补查发现第二章旧浏览器脚本默认依赖已清理的历史构建，街亭旧脚本没有准备前章通关条件，也没有处理第四、第五轮固定发言。现已改用当前构建、隔离测试存档并补齐五轮选择。街亭结局测试默认自建临时 HTTP 服务。`test:chapters:browser` 收入第二章六结局、街亭四条结局/重试路线、分兵界面和五轮进言验证，并接入 `test:stability:browser`。
