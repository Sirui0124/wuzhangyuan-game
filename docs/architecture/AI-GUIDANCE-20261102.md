# AI 配置引导与日常维护

日期：2026-11-02。本轮保留原有未提交内容，没有更改剧情判定、结局条件或存档格式。飞书协作原则读取 revision 39，与本地副本正文一致；未写在线剧情和审核状态。

## 架构中处理的冗余

设置界面及保存逻辑由前三章共用，继续沿用。夷陵和荆州通过一个轻量对话框复用同一控制器和 Token 表单，没有新增按章保存的密钥、代理服务或通用配置框架。原控制器读取配置后同时逐字段改 DOM 和重渲染的重复操作已删去。

街亭与荆州原先部分入口直接读取“启用 AI”的偏好，绕过启动时的配置检测。现统一读取实际运行模式，未配置时显示预设玩法，避免输入后才发现服务未配置。这项修改不改变已配置但请求失败时保留草稿、允许重试的规则。

验证入口原来混有慢速全分支浏览器流程，完整技术检查中又重复调用架构检查。本轮将日常、按需和发布验证分开；历史测试保留，不默认全部执行。

| 命令 | 使用场景 |
| --- | --- |
| `npm run verify:daily` | 架构、类型、构建及第一章主线烟测；日常默认 |
| `npm run test:settings`、`npm run test:ai-guidance` | 设置或引导改动；使用模拟配置，不写真实密钥 |
| `npm run test:game` 或具体测试文件 | 状态、规则、存档等相关实现改动 |
| `npm run test:stability` | 发布前完整技术检查 |
| `npm run test:release:browser` | 发布前全套浏览器流程，含各章全分支 |

旧存档兼容导出、存档备份、取消请求和素材哈希校验具有实际用途，不作为废代码删除。当前仍有较大的章节运行器；没有仅为缩短文件而拆散状态机。

## 用户能看到的变化

首次进入的新玩家会看到 Token 是什么、配置后可用的自由表达/人物回应/润色/追问、需要填写的地址和模型，以及“暂不配置，继续游戏”。关闭后在本浏览器记住，不在每次启动重复弹出。已有模式偏好或主线存档的玩家不强制重走。

第一章表达说明当前使用本地参考和判定；第二章无 AI 时保留预设发言；街亭在进言选项下提供可展开说明；荆州区分预设问题和自由追问。均可直接打开配置。AI已开启时，能力说明按需展开，不作为人物台词朗读。

夷陵当前依赖 AI 完成自由问讯、军令核对及军报，进入前会提示这一要求，并能在当前页面配置。没有编造一个已经可用的离线营救模式。

Token 仍由原本机服务保存，输入框遮蔽。保存不会发模型请求；只有显式测试连接或实际使用 AI 才请求模型。通过引导入口保存有效的非空 Token 会启用 AI，并保留既有手机偏好。

## 实际验证

架构、类型与构建通过。运行了与本轮修改相关的模式、街亭会话、荆州追问单元测试，共 38 项通过。设置浏览器检查覆盖原有保存/测试连接/读取失败保护；引导浏览器检查覆盖首次跳过及记忆、第一章切换、第二章预设、街亭未配置、荆州草稿、夷陵配置入口，模型请求计数为 0。第一章主线烟测通过。截图和日志在 `outputs/ai-guidance-20261102/`。

本轮没有重跑所有章节结局、极端存储和媒体故障测试，也没有调用真实模型来代替人工体验审核。没有重新制作 Windows 安装包。
