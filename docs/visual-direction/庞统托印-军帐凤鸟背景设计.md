# 庞统托印：军帐凤鸟背景设计

2026-11-05，设计稿与生成参考图，待review。保持已确定的庞统身份、中性写实影调、25毫米私印与原句，不增加对白。

## 场景方案

庞统站在军帐案前，低漆案与黑漆朱绘凤鸟纹木屏位于身后。镜头在玩家眼睛的位置，人物正面看向玩家，右掌递出铜印。近处帐帘框住边缘，中间人物和手掌清楚，身后漆案、木屏、帐壁及支柱形成层次。人物由真实帐口侧光照亮，远端逐渐变暗，让此前托梦仍有记忆中的空间感。

案台取适于席地使用的低案比例，不做现代书桌。案上只放展开的简牍、一卷简牍、文书匣与远侧小油灯，留出大量可读的空处。案台放在庞统身后，不阻隔玩家接印的路线；不用地图墙、密集兵器或守卫补充未经确认的剧情。

凤鸟纹绘在木屏表面，以黑漆、暗朱和木材磨损建立真实材质。取对鸟、卷尾、云气的线性组织方式，头颈与尾羽从人物两侧露出。凤鸟的规模足够在中景辨认，但对比低于脸部，不围成头顶光环，不把鸟翼接在人物肩上。此处使用凤鸟纹与“凤雏”称谓形成观众能读到的联系，不宣称是庞氏图腾或庞统真实军旗。

主光维持中性柔光，自帐口方向落在脸和掌心；背景油灯仅提供很小的局部暖点，不能把全画面染黄。皮肤、暗铜、旧漆、织物和绳结各自保留真实反光。夜间奔马与梦中军帐通过直接切镜区分，梦中不添火场、下雨或灵魂透明效果。

## 镜头应用

沿用交印片段20秒结构：0—14秒正面中景，台词开始时先读到眼睛与身后凤鸟，托印的手前送时轻微前移，将注意力带到铜印；14—20秒随玩家视线切手部，完整交接。镜头不环绕人物，不让屏风上的凤鸟发光、飞起或转化成实体。铜印仍是25×25毫米、含钮总高约15毫米的同一件道具。
