## 2. 人物身份：跨时期保留什么

角色 ID：`zhugeliang`。不同年龄使用同一演员身份，通过须发、皮肤状态、体态和服装表达时期变化。换帽、披发、雨水和衰老都不能掩盖换脸。

| 项目 | 固定要求 | 允许变化 |
| --- | --- | --- |
| 脸部骨相 | 偏长而清瘦的脸，保留参考图的额头、眉骨、颧骨和下颌关系 | 随年龄出现适度面颊消瘦，不改变骨架 |
| 五官 | 眉眼间距、眼形、鼻梁及鼻翼、嘴唇轮廓沿用身份参考 | 细纹、眼袋、唇色与疲态随时期和场景变化 |
| 须发 | 保持发际线和胡须生长区域的对应关系 | 胡须长度、灰发比例、束发或披发按阶段变化 |
| 身体 | 清瘦、成人肩宽，颈肩与头部比例自然 | 末年病弱、坐姿与支撑动作；不能突然缩肩或变成佝偻老人 |
| 神态 | 思考时目光有落点，情绪克制，动作有目的 | 青年更舒展，中年沉稳，末年疲惫但仍有意志 |

现有人物库与开篇监斩台图存在造型、年龄观感和部分脸部差异，尚缺统一的正侧面对照图，不能直接宣布所有素材已统一。既有游戏身份参考继续保留；已经建立的马谡镜头组则优先保持组内同脸、同衣、同冠。以后跨时期生成，先做身份对照，经审阅后再选择统一母版，不自动用一张新图覆盖所有旧图。

## 4. 羽扇道具标准（本次新增建议）

### 4.1 轮廓与尺寸

建议建立一把成年诸葛亮通用羽扇，先确定正面、侧面和持握照，再应用于各时期；年代久远时可有合理的新旧替换，但同一段连续镜头必须是同一把。

| 项目 | 建议设计值 | 检查方式 |
| --- | --- | --- |
| 总长 | 约46厘米，可在44—48厘米内调整 | 从扇柄底至最高羽尖，不能只量扇面 |
| 扇面最大宽度 | 约30厘米，可在28—32厘米内调整 | 正面展开视图；不用侧转后的投影宽度判断 |
| 羽毛区高度 | 约32厘米 | 从羽毛根部聚合处至羽尖 |
| 外露扇柄 | 约14厘米 | 一手握住后仍能看见少量柄尾，握持处不悬空 |
| 人体比例 | 正面扇宽约为不含耳朵头宽的1.7—1.9倍 | 扇与头处于相近景深时比较；摄影透视优先 |
| 掩面功能 | 能自然遮住眉眼至鼻部，并横向覆盖双颊 | 不靠靠近镜头突然放大，不改变扇形或羽毛数量 |

数值用于统一制作，不要求生成工具精准模拟实物毫米。最终以同一人物持握、正面尺寸关系和掩面测试共同确定，不能只在提示词里写“大羽扇”。

扇面为自然展开的宽卵形，上缘圆缓，向扇根收束，羽毛有前后叠压和少量不齐的羽尖。避免细长束状、孔雀屏式巨大扇面、现代折扇骨架或塑料扇片。羽梗能看见但不过粗；羽毛有柔韧感，不能像金属刀片。

### 4.2 材质与颜色

采用天然羽毛、旧木或竹质柄的视觉效果，柄面有握持磨亮与轻微磨痕。新建通用道具以灰米白、浅灰褐为主，局部深灰羽梗，麻白参考只约束浅色部分，不把整把羽扇刷成统一米黄色。

监斩台当前镜头的羽毛偏灰褐。局部修改时保留这个色系，先改宽度与展开方式，避免同时换成纯白羽扇而破坏前后镜头。未来若决定统一成浅色道具，需要把同组相关图片一起审阅。

### 4.3 当前监斩台图片怎么改

保留人物脸、年龄、冠帽、衣袍、身体姿势、握扇手位置、案桌及刑场布景。让扇面向两侧更充分地展开，先以现图可见宽度增加约三成为试改起点，必要时小幅调整羽尖高度；这只是图像修订起点，不是测量结论。保留自然侧转，避免为了显示宽度把扇硬贴成正对镜头。

手掌真实包握扇柄，虎口与柄接触，羽根不能穿进手指。羽尖不碰下巴或胡须。若增加扇面后与衣袖重叠，要有对应遮挡与接触阴影，不能改变手的位置来掩盖错误。

### 4.4 举扇掩面的连续动作

1. 扇停在腰腹前，脸与扇同框，可以确认尺寸。
2. 肘部抬起，前臂带动扇向面前移动，手腕自然转动，使扇面逐渐朝向镜头。
3. 羽扇停在面前近处，遮住双眼和鼻梁，仍可露出部分胡须；不压进鼻尖，不穿过冠帽。
4. 若以羽毛转场，靠镜头推进或扇继续接近镜头完成遮满画面；扇子实体尺寸从头到尾一致。

不用持续夸张抖肩表现痛哭。低头、短暂停顿、下颌绷紧与抬扇稍迟即可承接“挥泪斩马谡”。

## 5. 场景服装与状态分开管理

| 场景版本 | 锁定内容 | 可随动作变化 | 禁止串用 |
| --- | --- | --- | --- |
| 监斩台 | 当前蓝灰外袍、织纹缘边、浅色交领、黑竖纹冠；当前灰褐扇 | 袖褶、持扇角度、单次泪痕与表情 | 不加雨、不改黑袍、不换发冠、不自动加甲 |
| 上方谷 | 选定参考中的冠、层叠外袍及扇；雨景另标湿润程度 | 湿发贴附、衣料加重、羽毛略聚拢 | 不把雨、山崖与火光带进监斩台 |
| 五丈原议事 | 依该镜确定的衣袍与头饰 | 疲态、坐姿、说话动作 | 不默认披发或持扇 |
| 五丈原借寿 | 已有核心参考的披发、黑袍白襟、灰黑长须 | 病弱与灯光下的肤色变化 | 不因身份相同强加监斩冠帽 |

同一段落内记录领口叠压方向、腰带位置、冠帽高度、鬓发灰度、扇色与握扇手。左右反转不能作为新机位素材直接使用，否则衣襟和用手会一起反转。

## 6. 需要具备的人物素材

每个时期先制作3张基础参考：正面头肩、四分之三头肩、全身自然站姿。采用中性背景、正常透视、自然光和中性表情。青年、北伐、末年额外补侧脸，保证跨年龄的鼻梁、下颌及发际线一致。

| 素材组 | 内容 | 用途与优先顺序 |
| --- | --- | --- |
| 羽扇独立参考 | 正面、侧面、背面；同一尺度，不带文字水印 | 优先完成，锁定扇形及羽毛叠压 |
| 北伐人物与扇 | 腰部持扇、胸前持扇、举扇掩面 | 优先用于当前马谡镜头，确认手与扇的比例 |
| 北伐表情 | 平静、忍泪、垂眼、决断 | 同一服装与布光，克制变化 |
| 五阶段身份图 | 各阶段的3张基础参考，重点阶段补侧脸 | 从同一身份母版派生，不能五次独立抽脸 |
| 末年状态 | 正常议事、疲倦坐姿、借寿病弱 | 分清年龄与当日身体状态 |
| 连续动作图 | 举扇前、遮住眉眼、羽毛近景 | 给视频提供动作端点与空间依据 |

单张图不堆多个人物、多阶段和大段文字。对照板可把已完成的单图排在一起，但真正提交视频模型时使用独立的清晰参考。

## 8. 可复用生成要求

### 同人跨年龄

> 严格以所附身份图为同一演员参考，保留脸部骨相、眉眼间距、鼻梁鼻翼、嘴唇和下颌轮廓。仅按指定人生阶段改变年龄观感、胡须长度、灰发比例、皮肤细纹和体态。使用对应场景服装参考，不混入其他时期冠帽与领口。自然皮肤与轻微不对称，禁止磨皮、夸张衰老、蜡像脸和游戏角色质感。横向16:9满幅，中性自然色温，50mm正常透视，脸、手与羽扇清晰；材质具有真实重量、磨损及接触阴影。天气、环境、动作和表情由本镜单独指定。

使用时必须另外写明阶段、场景、具体参考图关系和动作，不直接提交这段通用说明代替完整请求。

### 监斩台羽扇局部修订

> 编辑所附诸葛亮监斩台中景，只修正羽扇比例与展开形态。完全保留人物身份、年龄、表情、发冠、须发、蓝灰衣袍、领口、身体和双手位置、案桌、营地、相机位置与画幅。现有灰褐羽扇改为自然展开的宽卵形扇面，先适度增加可见宽度约三成，保持自然侧转；羽毛有层叠、柔韧性与真实羽梗，不变成孔雀屏或折扇。参考设计为总长约46厘米、最大宽约30厘米、外露柄约14厘米，最终以人体比例合理为准。手指真实包握扇柄，保持接触阴影。维持原光线连续性，不整体改色，不新增道具与人物。

## 9. 审阅检查

- 缩到普通观看尺寸后仍是同一个人；青年与末年的差别来自年龄，而非五官替换。
- 正面持扇能判断大小；举扇后自然遮住眉眼，不突然长大，不穿脸。
- 监斩镜头组的帽、领口、织纹、须发、持扇手和扇色一致。
- 末年约五十余岁的病弱可以读出来，但没有被画成高龄老者。
- 真人感来自自然光、皮肤、衣料重量和接触，不靠过锐纹理、黄滤镜或大量颗粒。
- 文件实际为横向16:9或记录近似比例的真实尺寸；不加黑边，不把Prompt中的8K当成输出规格。
- 新生成图分别标注技术检查和人工审阅状态；未获确认时不接入游戏、不删除旧参考。
