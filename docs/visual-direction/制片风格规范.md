# 逆转五丈原制片风格规范

最新明确要求（2026-11-04）：剧情图片与视频默认横向16:9、真人实拍质感、多细节与历史电影规模；统一使用 [写实电影影像风格](写实电影影像风格.md) 的中英文Prompt基底、材质与光照要求。用户新要求优先于旧参考中不一致的画幅或风格关键词。此前 E 的影调、人物不需退到景色中、交互采用玩家第一视角的要求继续保留；[原始参考关键词与第一视角适配](原始参考关键词与第一视角适配.md) 保留作历史依据。下文环境远景与小人物的参考用途不构成通用构图要求。

《逆转五丈原》的影像方向：**墨色山河，灯火有温，朱色有因。** 以有重量的三国军营和可亲近的人物表演为基础，用山河、军列与门框组织命运的压力，用有限而真实的颜色承载人的意志。适用于后续场景图、故事视频、转场和页面美术衔接。

这次融合以用户提供的五张图及图内提示词为视觉参考，结合现有主菜单、山河地图、营门、传令帐、候报处、魏延镜头和诸葛亮角色图。文中的配色与镜头规则是本项目的制作选择。图内“张艺谋风格”是用户提供的参考标签，不作为这些图片出自原片的证明。

配套浏览：[视觉对照板](style-board.html)。原始参考在 [references](references/)；保留完整截图供核对提示词。现行人物身份与服饰仍以游戏角色资产为准。

## 色彩如何组织

大面积环境采用低至中低饱和度，人物肤色、灯火、暗朱红和麻布保留色相。黑色中仍应分得出木、铁、布；灰色中仍应分得出天、山、烟。色彩来自物体与光源，不能只靠统一冷暖滤镜。

以下是沟通用目标色，不是从截图精确取样，也不是需要直接替换的 UI 参数。

| 色彩 | 参考值 | 职责与范围 |
| --- | --- | --- |
| 墨黑 | `#11191C` | 近处帐影、木栅、甲片暗部；保留材质层次 |
| 山青 | `#3D5359` | 远山、夜空和环境冷色；避免全画面青染 |
| 雾灰 | `#A4AFAD` | 远景空气与柔和天光；有天气依据才用雾 |
| 麻白 | `#D8CEB8` | 旧布、纸、羽扇与浅衣；偏暖且有使用痕迹 |
| 灯琥珀 | `#BA8749` | 灯照到的皮肤、木与布；火焰中心可更亮、更浅 |
| 暗朱 | `#803E36` | 魏延已有衣料、既有印记与少量重点；不把所有旗帜改红 |
| 旧土 | `#675B49` | 干湿地面、木器和营地生活色；湿处只在合适角度反光 |

夜营以冷色环境形成底，暖色集中在少数实际光源附近。白天保留泥土、枯草和布料的颜色，不机械延续夜景蓝橙。朱红应是一块可辨的物质色，而不是通篇染红的情绪层。

## 摄影与构图

**权力用秩序，人物用关系。** 营门与军令场景可用中心透视和重复排列建立压力；进入交涉后，按眼线、身体朝向和遮挡组织中近景。对称必须能说明谁面对谁、谁被围住，不能成为每一页的固定形式。

环境至少建立可辨的近、中、远层：近处帐帘或旗杆，中间人物与可行走空间，远处营地或山势。门框和帘缝承担叙事边界：谁可以进入、谁被挡在外面。不能让装饰性前景挡住说话者眼睛或关键证据。

大远景负责地形、军阵与人的处境；中景负责行动；近景负责眼神、手和改变局面的物件。正常透视作为对话基准，俯拍与极端广角只在地形或压力确有需要时使用。互动页面维持现有横屏构图；默认视频也按 16:9 设计，预留对白与导航安全区。其他画幅需单独适配，不能用上下黑边替代构图。

镜头通常稳定，让旗、火、衣角和人先动。推进、跟移或切换必须由注意力或动作变化触发。不要每句对白一切，也不要每个镜头都慢推。救人等动作先交代落点与支撑，再显示伸手、接触和受力，最后交代状态改变；不为了漂亮近景剪丢动作因果。

## 人物与材质

诸葛亮保留既有脸型、眉眼、胡须、头巾和灰麻衣的身份；魏延保留眉眼与胡须轮廓、头盔、暗铁甲和暗朱红内衣。其他角色同样先用现有资产锁定身份，再调整影像呈现，不能套用参考图人物的脸或服装。

真实感来自皮肤细微变化、松散毛发、布的重量、甲片搭接、脚踩地面和手的接触。肤色仍有血色，不用一层灰代替疲惫，不通过统一增加皱纹改变年龄。金属以暗面为主，只让少数边缘受光；泥地保留粗糙干湿差，不把整条路做成镜面；粗布与竹简保持功能感，不让每件道具都精雕金饰。

静态立绘可以继续服务识别；视频人物以自然表演增加可信度。说话之外保留听者反应，允许停顿、呼吸、视线转移与重心改变，但每个动作都要服务当前动机。避免持续怒瞪、满眼泪光和无目的摆姿势。

## 页面与视频如何统一

统一发生在色彩职责、材质和空间逻辑上：主菜单留白对应影片的帐内暗部；纸色地点签与证据入口对应麻白；克制朱色对应重点动作；场景图与视频共享帐门位置、灯向、天气和人物服装。

界面仍优先让玩家读懂和点击。对白文字延续当前米白，底板保持足够遮挡；不能把影像的低饱和度套到文字上。书法与印章只作已有标题和有限装饰，不能挤占正文与操作。地图可以保留绘卷式概括，人物镜头强调实拍质感，两者由共同色谱衔接。

现行 `color-grade.css` 为“旧影柔调”：`saturate(.65) contrast(.89) brightness(1.075) sepia(.18)`，并有轻微暖色罩层。新图先制作保留色相的母版，接入时在实际滤镜下检查一次；已经完成调色的视频需核查是否重复处理。后续若选择逐片调色，应由接入任务明确哪些素材仍经过公共滤镜。此次不修改该参数。

## 可复用生成提示词

不要仅提交导演姓名或电影名称。后续生成优先使用 [写实电影影像风格](写实电影影像风格.md) 的通用基底，再加当前剧情、角色参考、空间与动作。下面两段保留为五丈原军营的场景补充，不能把五丈原地点套到夷陵等其他章节；没有在本次上传的参考图，不写成模型已收到。

### 中文基底

> 三国时期五丈原军营，东方历史电影的实拍质感。墨黑、山青、旧土与麻白构成低饱和环境，保留自然肤色、布料本色和局部灯火的琥珀暖色，暗朱红仅来自画面中实际存在的衣物或物件。前景遮挡、中景人物、远景营地形成清楚纵深，以帐门、木栅与旗列建立空间秩序。方向明确的自然光与现场灯火共同塑形，暗部有细节，皮肤、粗麻、旧木、暗铁各有触感。构图克制，人物处于有重量的真实环境中，以微小而有动机的动作表达情绪。色彩含蓄但有生命，画面清楚可读。

### 单镜填充顺序

1. 说明本镜在已确认剧情中的信息与人物起始状态。
2. 列本次真实附件编号：哪张锁身份、哪张锁场景、哪张只参考光或构图。
3. 说明人物站位、眼线、天气、光源方向与服装连续性。
4. 只安排一个主要动作变化，交代接触点、受力与结束状态。
5. 写景别、摄影机是否移动、切点与下一镜衔接。生成时长与模型参数单列。

### 营前镜头示例

仅示范已有营前交涉的拍法，不增加台词、人员或剧情事件；实际人物和动作须按当前分镜填写。

> 以本次上传的魏延角色图锁定脸、胡须、头盔、暗铁甲及暗朱内衣，以本次上传的营前场景图锁定帐门、木栅和道路。横向中景，魏延与交谈对象的站位、视线关系明确，帐口位于他身后侧方；远处旗杆与营地形成纵深。冷色傍晚天光与邻近灯笼暖光共同照明，脸部保留自然肤色，背景暖色收敛在光源附近。摄影机稳定，按已确认剧情执行一个简洁动作，再留给听者反应。粗布有重量，铁甲反光克制；暗朱衣料可辨但不鲜艳，阴影中仍能分辨甲片与帐布。

### 排除项

黑白或全局去色；全画面蓝橙染色；无来源金边；蜡质磨皮；游戏宣传 CG 式过锐甲片；满地镜面反光；现代物件；参考截图的平台 UI、字幕、水印；女侠、纸伞、太极台与书法长廊的直接移植；未经剧情确认的法阵、仙光、持续雨雪或浓雾；复制军阵；无因慢动作；角色换脸；证据文字由图像模型随意生成。

## 制作验收

- 缩小画面后，第一眼仍能找到主角、行动方向与本镜重点。
- 肤色、暗朱、麻白和灯火仍有区别，黑布、铁甲和木器不糊成一块。
- 对称、留白与大尺度各自服务具体关系；人物交谈仍看得清表情。
- 与相邻页面和镜头核对人物身份、服装、帐门、天气、光向、道具与动作结束状态。
- 静帧检查材质与空间；视频另查身份稳定、步伐接触、口型、镜头运动与声音衔接；游戏内另查公共滤镜、文字和可点击区域。
