# 写实电影影像风格

2026-11-04 用户明确要求：项目剧情图片与视频统一向真人实拍靠拢，横向16:9，细节丰富，有历史电影的规模与质感。以本文件作为后续生成的默认风格，与《制片风格规范》共同使用；两者冲突时，本次明确要求优先。人物身份、已确认剧情、天气和动作连续性优先于装饰效果。

2026-11-05 更新：以用户新版英文Prompt为基准，优先中性自然色温、无全局黄偏、自然肤色、50mm正常透视、适度背景虚化与丰富材质细节。约5500K作为自然日光或中性布光的沟通目标，不把已有夜景改成白天，不消除实际火源应有的局部暖色。f/1.8仅表达柔和背景的参考，脸、手和证物需要同时看清时，应以足够景深为准。旧版偏琥珀的全局影调由本次要求替代。

## 固定要求

- 画幅为16:9，满幅构图，不加上下黑边。用户例文中的2.39:1不沿用。生成后记录真实像素尺寸；不得把“8K cinematic quality”等提示词当成实际8K交付证明。
- 以真人演员、实物服装道具和真实外景的摄影效果为目标。脸有毛孔、细纹、自然肤色差与微小不对称；毛发有散落和粗细变化。保留参考人物年龄、脸型与表演，不靠增加皱纹、油亮皮肤或夸张悲苦制造写实感。
- 布料有纤维、经纬、重量和受力褶皱；铜铁有符合使用状态的氧化、磨损与克制反光；旧木、皮革和泥土各自可辨。细节分布有原因，不把每件衣服都做成破布，不把常用铜印做成刚出土器物。
- 光必须有来源和方向。天光、灯火或火场形成明暗关系，暗部保留必要细节；轮廓光、体积光与空气颗粒只在空间条件成立时出现。肤色自然，夜景可以冷暖相映，不把所有场景统一染成蓝橙色。
- 大片感来自空间纵深、真实尺度、构图和表演。近景保留人的亲近感，不强制巨大远景、浓烟、密集军阵或英雄仰拍。交互镜头沿用玩家第一视角。
- 景深服务信息：脸、关键物件和接触动作必须看清。保留细微胶片颗粒、柔和高光过渡与轻微晕光，避免全景锐化、重降噪、涂抹皮肤、过强HDR和塑料反光。
- 雨、雾、泥、水渍、湿发、羽扇、悬崖和燃烧营寨属于具体场景，不能成为通用风格附件。已确定雨景时，雨滴大小、风向、湿衣、积水、接触飞溅、受火光照亮的雨帘及局部蒸汽须相互吻合；不能把暴雨自动加入夷陵火攻或梦中交印。

## 可复用中文基底

> 横向16:9，满幅，真人历史电影剧照。50mm正常透视，中性自然色温、无整体黄偏，适度背景虚化并保证人物与关键道具清楚。保留既定脸型、年龄、衣着和自然表情；皮肤有细微毛孔、自然色差与细纹，胡须和头发有可辨的单根毛发，无磨皮美容。布料纤维、重量和褶皱真实，旧皮革、褐灰铜、旧木具有与使用方式相符的局部磨损。方向明确且有来源的柔和自然光，暗部保留材质和空间层次；灯火暖色只出现在光源及实际照到的位置。前中远景形成真实纵深，细微胶片颗粒、柔和高光过渡、轻微高光晕染，避免数码过锐和夸张HDR。构图与表演克制，动作符合人体结构、重力和接触关系，具有历史电影的空间规模与真人实拍可信度。天气、时间、道具和环境服从本镜剧情。

相机、镜头和胶片名称仅作影像质感参考，不表示这些生成图由真实设备拍摄。焦距与景深按镜头选用，不固定每张40mm或T2.3；ARRI数字机与胶片颗粒也不写成真实同时使用的拍摄记录。色域、分辨率、编码与时长按实际输出核验，不由Prompt关键词推定。

## 排除词

> CGI, 3D render, game engine, Unreal Engine, Octane render, game screenshot, game character model, concept art, digital painting, illustration, cartoon, anime, cel shading, plastic skin, waxy face, doll-like features, beauty filter, airbrushed skin, fake fabric, fake metal reflections, perfectly clean props, uniform lighting, unmotivated rim light, oversaturated colors, unnatural yellow cast, excessive sharpening, heavy HDR, malformed hands, extra fingers, floating particles, cluttered redundant objects, distorted anatomy, modern objects, captions, subtitles, watermark, split panels, letterboxing.

雨景另加：fake rain, floating rain, identical rain streaks, dry clothing in rain, inconsistent wet surfaces。无雨场景不加入湿发、水滴与湿衣的正向词。
