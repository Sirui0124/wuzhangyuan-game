现有页面的共同底色

营门：让空间施加压力

保留帐门、木栅、旗杆与道路。后续用人物站位和纵深加强秩序，减少遍布每个物体的亮边和地面镜面感。

魏延：暗朱承载人的力量

保留面容、胡须、头盔与衣甲身份。暗朱依附真实衣料，脸上有自然血色；后续收敛过锐细节，以眼神和听者反应承载交涉。

帐内：光源建立关系

暖光落在案头和邻近人物，冷光来自帐口。近处帐沿、中间行动区、远处营地清楚分层；关键证据不能藏在暗部。

山河：宏观处境与微小的人

保留青灰山川与克制金色，地图采用绘卷概括。影片进入人物场景后回到人眼尺度，用同一色谱连接两种观看距离。

用户提供的完整截图。点击可放大查看图内提示词；吸收摄影方法，人物、服装、布景与天气按本作设定处理。

动作的触感

借衣料受力与速度边缘，不借女侠、伞与招式。

等待的空间

借暗框、空位与环境运动；不默认每场都下雨。

被注视的压力

借透视、队列与目光；改为本作军营空间。

秩序的重量

借门洞与军列的压迫，保留三国木栅帐营。

命运的尺度

借俯视与负空间，不移植太极台或玄幻建筑。

落到镜头上的三条判断

权力用秩序

门、军列、旗杆和纵深说明阻隔与权力。对称只在关系需要时出现。

人物用关系

交涉回到中近景、眼线与听者反应。让脸可读，让动作有动机。

色彩有来处

肤色有血色，暖色有灯火，朱红有衣物。白昼自然变色，不延续整晚蓝橙。

接入注意：游戏现有“旧影柔调”会再次降低饱和度并柔化反差。母版保留色相，实际播放时核查重复调色；文字和操作保持现有清晰度。
