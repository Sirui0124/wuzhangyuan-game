# 五丈原结局系统与页面

2026-10-11。适配当前 v06 正式剧本：两次魏延交涉。当前只有五丈原可试玩，筹备关卡暂不配置虚构结局。

## 现有架构与本次改动

正式故事来自 `content/chapters/wuzhang/chapter.json`，`GameStarter/assets/scripts/narrative/engine.ts` 执行条件、已确认对白的效果与节点跳转。AI 只分类本次表达，不直接写入结局状态。`loop.result` 区分未结束、灯灭、教学牺牲、处斩与安全通关；`loop.execution_reason` 区分军前挑衅。

原 HTML 界面在场景上叠加普通失败结算弹窗；教学牺牲确认完立即复活；成功播放视频后直接进入回溯和地图。现在，所有可达终局都在对白完整确认后进入统一黑底结局页。教学牺牲会停留，重来本关后进入第二轮；成功视频结束或跳过后停在生还结局。底部只保留「重试本关」和「返回首页」，返回首页进入现有关卡选择页，刷新后仍保持首页并保留原存档。严重挑衅不播放守灯成功动画。

引擎增加 `completeSegment({ deferRestart: true })`，供 HTML 暂缓教学复活。默认调用保持原行为，已有核心规则调用不受影响。结局页与收集系统读取已经成立的结果，不替引擎判定生死、推进剧情或授权。

## 文案独立维护

所有结局展示文本集中在 `content/chapters/wuzhang/endings.json`。修改标题、解释或提示后，在 GameStarter 执行 `npm run build:demo`；网页会读取构建复制出的 `/story/endings.json`。

| 编号 | 环节与结果 | 解锁标题 |
| --- | --- | --- |
| 001 | 首次阻拦失败，灯灭 | 你还在，灯却灭了。 |
| 002 | 首次阻拦成功，被抬走处置 | 诸葛亮活了，但你挂了。 |
| 003 | 第二次交涉失败，灯灭 | 一阵风，吹回了原来的命运。 |
| 004 | 第二次交涉成功，姜维接报 | 灯没灭，你也活下来了。 |
| 005 | 任一次严重挑衅，当场处斩 | 话还没说完，你先没了。 |

每项包含稳定 `id`、编号、环节、结果和可选条件，以及 `title`、`description`、`hint`、类别和可选注释。结局页以 `kind` 为名称（例如“牺牲”），`title` 为说明（例如“诸葛亮活了，但你挂了。”）；下面先解释这次选择的后果，再给下次尝试的方向，两段使用同一字号。不展示架空注释、编号或底部环节标签，不提供结局页回看入口。结局002中的“活了”指守住这一夜，未宣称病愈。旧版本的越职转报和四步手动传报分支在 v06 已不可达，因此不进入本版结局收集数量。

`GameStarter/web-demo/src/endings.ts` 使用引擎同一个条件求值器选择文案。终局必须唯一匹配；未确认的结尾对白不能提前解锁。收集面板显示解锁数量、已得结局标题和解释；未解锁项只显示编号和封存状态。

## 重试与存档

「重试本关」打开两种入口：

- 「回到存档」恢复本轮最近一次可继续游戏的稳定自动档，保留当时已收集的证据、调查和回看记录。它不会读取终局自动档。未完成的对白和选择不会作为存档。
- 「重来本关」创建新轮次，清空本轮证据、准信、行动、草稿与交谈历史。教学未完成时回到教学起点；完成后回到正常调查起点。

现有主自动档 `wuzhang-white-demo-v1` 仍可保存终局，刷新后能回到结局页。新增 `:retry` 键在结果为 `none` 的稳定边界更新，终局写主档时不覆盖它。读档前检查章节版本、状态合法性及当前轮次；缺失、损坏、跨轮或版本不兼容时禁用「回到存档」，仍可重来本关。新轮次清除旧重试档，防止带入旧证据。

结局收集使用独立键 `wuzhang-endings-v1`，跨重试、重玩与地图保留。同轮刷新和反复打开不会重复增加计数。无法解析的原收集记录会保留，页面给出保存提示。地图进度和视频播放进度继续分别保存，不进入 AI 上下文。

## 页面参考

借鉴《盛世天下》的多结局收集、后果说明与重试体验。视觉对照本项目当前军帐场景和设计 tokens，采用墨黑暗纹、灰白楷体、暗朱砂按钮、回纹云线边角与双层细边；不使用亮金色。重试与结局收集弹窗沿用相同材质和颜色。解释与提示使用相同字号（桌面 19px、手机 17px），底部仅保留「重试本关」「返回首页」。没有复刻参考游戏素材或整页像素布局。

参考：[《盛世天下》流程与结局攻略](https://www.gamersky.com/handbook/202509/2011269.shtml)、[公开体验文章](https://m.sohu.com/a/936135634_121212001/)。

运行 `npm run check:narrative`、`npm run validate:story`、`npm run test:narrative`、`npm run build:demo`。专用浏览器验收：`node web-demo/verification/endings-flow.mjs`，结果与构建摘要写入同目录的 `endings-flow.json`。

验收覆盖正式画面和白模的五种结局、刷新与收集读回、两种重试、无效存档禁用、各结局返回首页、刷新保持首页及从首页重玩，以及1672、900、390宽度。交涉使用确定性语义响应；视频使用跳过入口，不在此报告中声称真实AI表达质量或完整成片自然播放已验收。Cocos主场景尚未接入玩法，本次验收对象是HTML试玩。
