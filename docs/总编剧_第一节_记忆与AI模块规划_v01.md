# 总编剧 · 第一节：记忆与 AI 模块规划

> 当前魏延实现以 [证据与对白判定 v02](魏延_证据与对白判定_v02.md) 为准：本次出示证据 + 当前对白，无魏延记忆。下文含已被替代的历史方案。

2026-10-11，第一期简化版。根据用户修订，本文替代此前详细提案。记忆作为 NPC 的内嵌能力，仅用于内部判断和组织对白；不展示给玩家。当前为设计方案，尚未修改游戏实现。

## 1. 第一期开到最小范围

每轮围绕 2—3 处关键交涉规划 AI，调查和行动继续使用现有剧情。第一期优先接入已有的魏延、乙两处自由输入；姜维沿用固定批准演出，甲沿用固定责任选择。此前建议新增的甲、姜维自由输入暂缓，不为凑数量扩展节点。

玩家输入之后，结合 NPC 设定、少量内嵌记忆和当前事实做分类，程序选定写死的决策，再生成贴近玩家原话的回应。回应结束后，玩家仍须执行实际传报行动。

## 2. NPC 内部只保留两类小记忆

| 内容 | 第一期做法 |
| --- | --- |
| 预置关键片段 | 每名核心 NPC 最多 2—3 条，编剧提前写好原话或短句及生效条件。只放会改变当前判断的信息。 |
| 当前待解决的问题 | 最多 1 条。保存引起本次质疑的玩家原话和固定问题类型；问题解决就清除，新问题按预设规则更新。 |

人物身份、职责和说话风格使用现有角色设定。当前许可、实际军情进度和未完成承诺直接读取已有游戏状态，不再复制成一套记忆。玩家跨轮线索继续沿用现有规则，本模块不扩展玩家记忆系统。

预置片段在剧情实际发生或消息实际传到后才生效。起点已经知道的事可以预置为有效；尚未发生的批准、未来结局和其他人物未转述的对白不能提前生效。回溯后清空 NPC 本轮新增问题，恢复起点信息。

普通闲聊不加入该模块。不新增完整对话档案、自动摘要、向量检索、好感分数或多层记忆库。已有引擎日志继续承担技术记录，本次设计不要求删除或改造它。

## 3. 五丈原只准备这些片段

下表是编剧配置示例，均为内部输入。实际生效受现有事件或状态控制。

| NPC | 第一期关键片段 | 生效条件 |
| --- | --- | --- |
| 魏延 | “军情紧急，必须及时报给能处置的人。” | 当前急报情境已经成立。 |
| 魏延 | “姜维只准今夜这份急报由乙在帐外接取递入。” | 本轮已批准，且魏延实际看过有效凭条。 |
| 乙 | “我能替你向姜将军递话，准不准由他决定。” | 起点职责已有；可直接写入角色设定，不另存重复记忆。 |
| 乙 | “今夜这份急报由我转递，回话也须带回来。” | 本轮实际收到姜维准信。 |

姜维第一期仍用固定剧情处理批准，不建设独立的动态 AI 记忆。以后增加他的自由输入时，再给他同样少量的内嵌片段。

## 4. AI 流程维持简单

```text
玩家的关键发言
  → 当前 NPC 设定 + 已生效的少量片段 + 当前待解决问题 + 相关游戏事实
  → AI 分类
  → 程序选择已有固定决策
  → AI 生成贴近玩家原话的回应
  → 确认后更新该 NPC 的当前问题，继续现有行动流程
```

分类和回应仍是两个步骤。记忆不单独调用 AI，不需要额外生成摘要。分类沿用现有“接受、补证据、补方案、超出范围、澄清”结构；许可与行动由程序核验。回应保留固定的决定或权限信息，生成句只补充针对性表达。

分类失败或请求失效不写记忆、不推进剧情；只有回应生成失败时，可以使用已选决策的固定对白。世界事实中 NPC 尚不知道的内容只供程序核验，不能被回应模型说成亲历。

## 5. 不恰当表达只产生一个具体问题

例如没有当轮许可，玩家却说：“奉姜将军之命，你不许进去。”魏延拒绝接受这项权限主张，内部只记一条：

```text
待解决问题：许可主张尚未证实
对应原话：奉姜将军之命，你不许进去。
```

魏延自然回应：“你说奉姜将军之命，准信在哪里？”下一次交涉仍可要求核验。玩家澄清刚才的说法，或实际出示有效本轮凭条后，按固定规则解除问题并重新判断。

每个问题类型都由编剧预先定义触发和解除条件。无关发言不会覆盖尚未解决的问题；若出现多个问题，按预设优先级只保留当前最需要处理的一项，当前发言仍须完整判定。

语气急、说得短、没用敬语，都不单独产生处罚。后果针对明确的权限冲突、扣报要求或承诺矛盾。实际承诺兑现继续由现有行动记录判断，不能用一句“我办完了”替代。

## 6. 玩家只感受到 NPC 的回应

本模块不增加记忆面板、记忆卡、状态标签、话术评分、分类结果展示或记忆更新通知。NPC 内嵌片段也不作为通关提示直接提供给玩家。

玩家看到的是人物对白和实际剧情后果：NPC 要求出示准信、追问谁来接报，或提醒刚才答应的事情还没办。必要解释直接写成角色会说的话，不把内部问题类型和判断流程展示出来。

这条要求只针对本次新增的 NPC 内嵌记忆；既有证据出示、剧情对白和玩家跨轮线索仍按原玩法处理。

第一期验收只检查：角色能使用少量有效片段；未解决问题能在下一次关键交涉中起作用并被正确解除；回溯不串入旧轮认知；玩家看不到内部记忆或分类结果。本文仅修订设计，未改代码或正式剧情。
