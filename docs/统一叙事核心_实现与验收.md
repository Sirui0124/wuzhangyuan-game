## 验证方法与已覆盖路径

在 GameStarter 内运行：

```sh
npm run test:narrative
npm run validate:story -- ../content/chapters/wuzhang/chapter.json
npm run pack:story -- ../content/chapters/wuzhang/chapter.json
```

正式五丈原 chapter.json 已通过校验，并打包至 assets/resources/story/wuzhang。测试另用临时目录检查 .meta 保留，测试 fixture 不写入运行资源。

已执行严格 TypeScript 编译与 25 项自动测试（20 项核心测试、5 项正式章节测试），覆盖：

- 直接路线必须实际递报，灯亮、玩家死亡；确认处斩台词与乙的线索后，回溯才出现侧帐入口。
- 授权路线必须实际联系、取得本轮许可、请乙、交接、取回话、转达，才保灯且生还。
- 只说服不执行：首次无关 delay 警告，第二次 broken、灭灯；普通灭灯不解锁侧帐。
- 必要交接步骤不耗预算；再次说服不会重置原承诺等待预算。
- 旧授权、旧证据、NPC 认知和承诺随回溯清除；模型上下文不含上一轮人物互动或玩家永久记忆。
- 打开对话不发证据，台词确认才提交；重复确认、重复点击、跳影片不重复效果。
- AI 回溯后或改选人物后晚返回无效；网络异常保留文本、不改状态、不扣时间。
- AI 返回未出示证据被拒绝，模型附带 effects 不被执行；API 适配不沿用上轮 responseId。
- 无效动作后续节点导致整次操作回滚；条件组合、同版本存档、引用错误和打包 .meta 保留得到验证。

正式章节的直接路线、授权路线、两次无关耗时失败与旧授权失效已用预设语义通过结果验证，包含复活后的快速重取证和一次侧帐引导。实际模型语义质量尚未验证。

## 尚需衔接的边界

正式剧情由剧情对话维护 `content/chapters/wuzhang/chapter.json`、notes.md、walkthrough.md；本轮没有创建或覆盖这些源文件。chapter.json 已出现并完成校验、正式路径测试与单向打包；剧情后续修改应重新运行上述命令。

校验器能检查声明和直接冲突，不能仅凭静态检查证明任意条件组合下所有路线可达、所有许可符合剧情意图。正式路线必须用事件和 flag 变化验收。acceptanceCases 的顺序有意义，授权路线应先于直接路线；next 只引导节点，不执行其中的行动。

存档仅支持完成一次交互后的稳定边界，没有台词或媒体中途恢复；UI 自动存档尚未接入。当前导航没有隐含时间费用，无关耗时操作需配置为 delay Action。自由输入的真实模型质量、Creator 3.8.8 导入、Cocos 场景挂载、桌面浏览器操作与影片播放均未验证。本轮保留原资源与 .meta，不手工编辑编辑器缓存。
