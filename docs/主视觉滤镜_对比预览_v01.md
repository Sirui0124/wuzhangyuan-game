# 主视觉滤镜对比预览 v01

2026-10-11。独立调色预览，尚未应用到正式游戏。

入口：http://127.0.0.1:8811/visual-filter-preview.html

当前橙黄火光与蓝色天空形成强烈对比，人物肤色也偏暖。建议先轻降饱和度，避免加深黑色遮罩而丢失夜景细节。首选 A「克制写实」。

| 方案 | 饱和度 | 对比度 | 亮度 | 棕褐 | 额外遮罩 |
|---|---:|---:|---:|---:|---|
| 原版 | 1 | 1 | 1 | 0 | 无 |
| A 克制写实 | .76 | .96 | 1.025 | 0 | rgba(28,33,35,.035) |
| B 冷月夜色 | .62 | .97 | 1.025 | 0 | rgba(25,45,67,.12) |
| C 旧影柔调 | .65 | .89 | 1.075 | .18 | rgba(81,65,43,.055) |

CSS filter 顺序：saturate → contrast → brightness → sepia。只处理场景与人物，保留 UI 字体和按钮颜色。原有场景渐变遮罩保留。

支持斥候、魏延、营前场景；四版并排或大图；强度滑杆；按住查看原色。页面使用当前游戏的静态场景快照，不读写玩家存档。

源文件：GameStarter/web-demo/public/visual-filter-preview.html 与 public/visual-filters/。正式游戏代码未变更。

Playwright 验证 3 个场景 × 4 个方案：美术滤镜正确、UI 未受滤镜影响、强度为零恢复原色、无页面脚本错误。另验证按住/松开原色切换与 900px 宽度无横向溢出。
