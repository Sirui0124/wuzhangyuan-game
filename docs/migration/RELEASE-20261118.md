# 逆转五丈原 · 2026-11-18 当前开发快照

本次交付 Windows x64 可安装 EXE 与 Mac 本地网页版。Mac 支持 Apple Silicon、Intel，附带对应 Node 运行时，无需安装 Node/npm；解压后用终端执行 `bash 启动游戏.command`，浏览器访问 `http://127.0.0.1:18812/`。使用期间保留终端。

完整源码、各章设计、剧情与素材在本次 Release 对应提交中。Unity 移植已按用户要求暂停，现有试验工程仅保留。玩家包不包含凭据或作者存档；AI 需玩家在设置配置。

当前游戏仅开放第一章与第四章，其余章节在界面显示“暂未开放”，相关内容仍保存于源码工程。此快照保持现有开放范围和审核状态，不代表全部设计均已完成或用户已通过。

验证：架构及 TypeScript 检查通过；Windows 638 个运行文件通过大小与 SHA-256 验证。Windows 在工作区外独立目录进行程序实启、视频解码、设置、本机营救存档、重启恢复及退出清理检查。Mac 载荷在 Windows Chrome 检查菜单、API 代理、视频 Range、第一章与第四章入口及存档保留；未进行 Mac 实机或 Safari 验证。

完整回归未全通过：345 项游戏单元测试中 338 项通过、7 项失败，涉及章节结果、旧存档、入口与影片预期；完整浏览器回归在旧场景选择器等待超时。故本次为预发布开发快照，不标记为稳定版。没有把生成安装器视为 NSIS 安装/升级/卸载验证；EXE 当前未签名。真实模型质量及完整剧情试玩不在本次验证范围内。

固定流程见同目录 RELEASE-WINDOWS-MAC.md。附 SHA256SUMS.txt 用于下载校验。Windows 安装包与 Mac 分发包从同一份网页构建产生，Windows 启动器另修正了第一章和指令营救读取玩家配置路径的问题。
