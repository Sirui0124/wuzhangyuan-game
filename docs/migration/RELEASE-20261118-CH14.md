- Windows：运行 EXE 安装后打开游戏，无需安装 Node 或开发工具。
- Mac（Apple Silicon / Intel）：解压，在终端输入 `bash `（末尾一个空格），把“启动游戏.command”拖入终端并回车。浏览器打开后即可玩，游戏期间保持终端运行，按 Ctrl+C 退出。
- 打开游戏设置，只需填写自己的 **DeepSeek API key**。服务网址 `https://api.deepseek.com` 和模型 `deepseek-flash` 已默认配好，分发包不包含作者密钥。AI功能需要联网。
- Mac 请使用同一浏览器及本机地址保留进度，升级时保留浏览器数据和 `~/Library/Application Support/WuzhangyuanWeb`。
