## 路线与使用边界

- 开场：SC01→SC02→SC03，计划37秒。
- 最终结局脚本组合：EN01→EN03→EN04，计划46秒；仅EN03＋EN04为34秒。
- 旧问罪分支：EN01→EN02 v05，计划27秒；该数字不适用于尚未编写的视频v06。
- EN02与EN03／EN04属于不同路线，四段不能按编号全部串成同一结局。
