# 我的结局成就：卡册 v01

2026-10-11，用户要求独立卡册查看历史达成的每一种结局。最新入口要求为结局页和首页（关卡地图）显示；游戏调查过程以及中途打开的地图不展示。

## 页面与交互

入口统一显示“我的结局成就”。教学牺牲的底部只显示“继续”，作为必经复活过渡；常规结局显示“重玩本关”“返回首页”。打开卡册覆盖当前页面，关闭返回原页面，不重开本关，不推进视频、回溯或地图状态。

采用暗色书封、纸页和朱砂印章，五丈原为第一卷。总览展示全部五种结局，可筛选全部、已收录、未收录；每张已收录卡可展开对白结局说明、提示、首次达成日期和达成次数，并逐页翻阅。未收录卡只展示封面和编号，不显示结局标题、类型和剧情内容。窄屏采用双列卡片及上下展开的详情。

卡册是玩家的历史记录，主角每轮的证据、许可和对白仍按现行规则清空。打开或翻阅不解锁结局，也不增加达成次数。

## 数据与实现

复用 `content/chapters/wuzhang/endings.json` 和已有 `wuzhang-endings-v1` 存档；不迁移或覆盖旧记录。存档格式异常时保留原始数据，显示说明并提供空卡册视图。

- `GameStarter/web-demo/src/ending-album.ts`：卡册、筛选、翻页、关闭与键盘焦点管理。
- `GameStarter/web-demo/src/ending-album-page.ts`：独立页加载既有目录和存档。
- `GameStarter/web-demo/public/ending-album.css`：独立样式，避免覆盖结局页与地图。
- `GameStarter/web-demo/public/ending-achievements.html`：独立地址 http://127.0.0.1:8811/ending-achievements.html 。

主产品经理完成以上独立文件，执行程序协调 AI 编剧在 `app.ts` 最小接入 `openEndingAlbum` 与入口文案；共享文件按序交接。
