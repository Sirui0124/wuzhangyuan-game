## 视觉交付与分工

UI 设计负责地图视觉、状态排版和转场体验：古军用舆图、旧纸绢、山川墨线、印记与营地位置表达古风；逆向流动的墨线、已发生的历史痕迹逐层显现、时间刻度或纸页回卷表达时光倒流感。动画保持克制，不能仅靠静态古地图或炫光粒子来表现时间。桌面为主要验收面，同时保证较窄视口和减少动态效果设置可用。

执行程序负责成功结局触发、视频配置与加载、黑屏文字、关卡进度和保存恢复、地图数据与进入／重玩操作。UI 设计随后在这个稳定接口上实现地图和转场视觉。共享 app.ts 修改按顺序接手，避免覆盖；执行程序当前已被 UI 对话派发的告示与斥候修改先完成再整合本需求。

本次不修改 AI 判定。审稿工作台在正式剧情变更稳定后同步，保留用户备注和手工编辑稿。
