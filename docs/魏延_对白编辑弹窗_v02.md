# 对白编辑弹窗 v02 · 2026-10-11

本版按截图反馈修改对白入口、编辑弹窗和 AI 润色。剧情分类仍由原有判定模块负责。

## 玩家操作

- 对话区中央显示大字「撰写回复」，点击对话区即可打开编辑器。
- 弹窗在左侧导航右方的可用游戏区域居中；桌面宽度从 79vw 调整为 71vw，约收窄 10%。顶部与左侧导航保持可见，小屏使用内部滚动。
- 出示证据可查看、修改；玩家可以选记忆短语辅助写作。记忆短语不能替代实际出示的证据，也不作为 NPC 记忆提交。
- 「AI润色」展开目的、语气和补充信息。目的与语气使用统一风格的按钮组，替换系统原生下拉菜单。
- 「确认生成」把结果填入可继续修改的对白框；「确认回复」才提交 NPC 判定。生成期间可取消；玩家中途修改原稿，旧请求不得覆盖新稿。

## 润色提示词的职责

输入为当前原稿、所选目的、语气、补充信息、当前实际证据与玩家选中的记忆短语。没有原稿时，按补充信息起草。

目的分为「劝将军暂候」「说清接报安排」「保留原意」。前两种组织理由和传报办法，后者只调整表达，不补充新的事实、理由或行动。保留执行人、执行时点和承诺强度；不得把“我现在去”改成“我可以去”，也不得把“隔帘接报”改成“请姜维出帐”。未有材料支持的办法只能作为建议，不能写成已经获准或已经完成的行动。输出为主角对白纯文本，不包含分析、NPC 台词或通关保证。
