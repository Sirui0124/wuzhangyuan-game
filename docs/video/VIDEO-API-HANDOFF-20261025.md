依据：2026-10-25 用户在「整理视频重新生成清单」中的直接要求。本次要求覆盖旧的单条 15 秒限制。

- 用户已通知视频生成 API 过期；后续需要重新生成的内容先整理为本地 Markdown，不再新增视频 API 生成请求或自动重投。
- 每条生成请求独立一份 `.md`，时长为确定的正整数，最长 **30 秒**。不强行凑满 30 秒，不跨互斥分支、玩家选择或确认停点合并。
