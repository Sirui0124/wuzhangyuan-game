# Seedance 视频生成文档固定规则

2026-11-08从项目 AGENTS.md 原样迁入以下八条固定格式要求，仅调整读取位置，未改变约束。编写、修改或交付此类文档时必须执行，并同时遵守项目 AGENTS.md 中的发声原句隔离、口型与参考图核验、无BGM、版本审核和交付规则。

- 后续供上传参考图并生成视频的 Markdown 文档统一使用 [Seedance Prompt 模板](SEEDANCE-PROMPT-TEMPLATE.md)，每条生成请求独立成文；用户另有明确要求时以用户要求为准。
- 文档开篇依次为：`尺寸：16:9`、`模型：seedance2.5`、`声音：有声音`、`时长：N秒`。N 必须替换为本条确定的正整数，不把历史素材的小数秒直接作为生成时长。
- 随后按上传顺序列参考图的完整本地绝对路径、图片序号和用途，再写视频生成 Prompt。交付前确认路径实际存在，Prompt 的图片编号与实际附件顺序一致；路径文字不能代替实际上传图片。
- 模板中的双花括号均为待替换字段；按实际图片数量增删条目及 Prompt 中的对应引用。未确定的内容须标明待定，不将未填模板当成可直接提交的成稿。
- Prompt 必须包含明确的分镜，按实际需要增删模板中的分镜块。每镜标题标注 `分镜序号｜X-Y秒`，将 X、Y 替换为具体秒数；时间段从 0 秒开始连续覆盖开篇总时长，不要求每个分镜都为整数秒。每镜分别写画面动作、摄影切点及对白。
- 每个分镜必须单独写“参考图关系”，明确本镜关联哪些图片，以及各图具体负责身份、空间、构图、光照还是首帧等；不能只在全片开头笼统映射、只列图片编号或仅写“同上”。
- 连续性约束之后、声音要求之前，固定写“拍摄手法参考”：标明参考影片名称、具体拍法及应用于哪些分镜。采用已核验的参考研究，不凭空归因；不能只写影片风格名代替实际拍摄描述。
- 文档最后一段固定为声音要求：默认明确全片无BGM、无背景音乐、无配乐，同时列出与当前画面匹配且同步的环境声及动作音效；有对白则保留指定对白，无对白则明确禁止新增人声。声音要求之后不再追加其他段落。
