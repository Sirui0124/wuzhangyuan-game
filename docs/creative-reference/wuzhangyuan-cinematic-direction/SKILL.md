# 五丈原故事视频导演规范

## 任务边界

为游戏故事视频提供统一导演方法。默认交付分镜脚本、逐镜视频 Prompt、参考图及其用途清单。用户尚未给剧情时，只做视觉研究和规范，不代写新情节。本技能不代表授权生成视频、调用付费服务或替换游戏文件。

这是视频风格规范。现有人物静态图片可以保留；视频形象加强真实感，仍须让玩家认出同一个角色。不要直接改游戏整体 UI 或立绘滤镜。

与 hypit 配合时，先读其参考研究、image-direction 和 video-direction。当前规范是项目导演层，不是模型 API、固定模型选择或经过生成验证的效果保证。首次视觉研究的取样范围、证据与局限见 [参考研究](references/reference-study.md)。

## 可直接选用的参考图库

使用 [参考图文件夹](assets/model-reference-images/README.md)，其中是 12 张按人物光照、环境、军帐、行军战争分类的原片单帧，附用途、来源时间点和 JSON 索引。整体浏览用 index.html，实际模型附件用单张 JPG。

给模型的提交文字不能只写“合龙风格”或“北海风格”。每次选择与当前镜头有关的少量图片，写明实际附件序号和参考职责，并用普通视觉语言描述所需效果。优先以游戏角色图锁定身份，原片帧只供指定光照、材质或构图参考；不要把原片人物脸型、神话盔甲、字幕、水印或雪山设定带入新镜头。每次提交另写本次附件映射，不把 H01 等图库 ID 误当模型已经收到的附件。

静帧不能传递精确运镜、步伐或表演节奏；有这类需求时回到对应视频片段核验，再决定是否提供实际视频参考。原片帧是研究素材，不是为当前剧情创作的首帧，不默认作为精确起始帧使用。

## 统一风格

以《合龙》的**东方古装故事实拍质感**为底：人物在可触摸、有生活痕迹的环境里表演，以中近景和有视线关系的反应镜头建立情绪。用实物材质、方向明确的光、空间遮挡和自然动作支撑真实感。

以《封神北海篇》的**军事空间与行动层次**为补充：先看懂地形、队伍和目标，再进入盾列、脚步、车轮、手与军令的局部，最后回到行动后果。军帐先建立谁围着什么议事，再让地图、手势和人物反应承接信息。

迁移摄影方法，不搬运参考片角色、故事、神兽、法术、雪山气候或神话盔甲。三国服饰、地理和季节服从游戏设定；超自然内容只在已确认剧情需要时出现。

### 色彩与光

- 自然土色、木色、麻布与暗金属构成主体；保留肤色、材质之间的区别。
- 日外、阴天、夜外、帐内分别建立光照方案。帐内烛火或灯火可暖，帐门或夜色可冷；每种颜色须有环境依据。
- 侧光、逆光和局部暖光可塑造脸部与衣料体积，但脸上的关键信息须可辨。避免把压黑、泛灰、蓝橙对比当成统一风格的全部。
- 雾、烟、水汽、尘土是空间中的局部物质，密度与动作、天气一致；不能用满屏烟遮住因果和表演。

### 镜头与剪辑

- 镜头随人物的注意、动作、信息变化而切。不要每句台词自动切一次，也不要每个镜头都推近。
- 对话先确认相对站位、眼线和轴线；中近景负责表演，肩背或门框前景提供关系与纵深，反打保留听者反应。
- 远景交代关系，中景交代动作，近景交代改变局面的细节。每个场景按需要选择，不必机械凑齐。
- 军事段落用远近交替建立规模与重量；近地低机位适合盾牌、步履、轮轴，避免连续无目的航拍。
- 在一个生成请求里保持动作可执行、因果清晰。复杂多人接触或长动作可按有意义的节拍拆分；是否多镜一条，服从模型能力与连续性需要。
- 焦段数值、摄影机型号、原片精确运镜若无证据，不当作参考事实。可以提出“正常透视”“压缩纵深”等目标，但标为设计选择。

## 视频人物真实感

先读取当前角色图与设定，记录 3–5 个辨识锚点：脸型、眉眼关系、鼻口结构、年龄、发髻胡须、标志衣甲。服装颜色与道具的连续性也要检查。

真实化主要改变呈现方式：皮肤有克制的微纹理与肤色变化；毛发有松散边缘；衣料有织纹、重量与受力褶皱；金属有局部磨损和合理反光；手、脚、武器有接触和支撑关系。不要以加重皱纹、污垢或改变族裔年龄代替真实感。

表演从当前动机出发，选择少数有意义的呼吸、眨眼、视线转移、吞咽或重心变化。不能机械要求每秒眨眼或所有人都喘气。台词情绪与身体反应一致，避免通篇怒瞪、嘴动脸不动和长时间摆姿势。

人物与环境共享光向、色温、阴影和景深。画面真实感由人物、材质、空间和动作共同成立，不承诺靠 LUT 或一句“电影级写实”解决。

若原图过于插画化，可先设计一张视频用的真实化角色参考图；原立绘继续保留。这是后续任务的可选准备步骤，不能自动执行。审核要同时看原图与新图，检查“还是同一个人”和“真实感是否增加”。

## 工作流

1. **接收剧情与用途**：读取用户指定的剧情版本、当前视频、角色资产和实际游戏入口。列出该视频要传递的信息、进入和结束时的角色状态。未知处保持待定。
2. **建立视频清单**：用户要求重构全部时，先找代码中的真实视频引用与触发条件，核对独立片段、分支、复用与结尾循环。不能按文件夹里的视频数量声称覆盖全部。
3. **写导演方案**：每段给出情绪、空间、光线、动作中心和参考依据，明确如何适配当前剧情。
4. **写分镜与 Prompt**：按 [交付模板](references/delivery-template.md)。每镜说明入镜状态、动作变化、结束状态、切点与连续性。
5. **准备参考图**：区别角色身份、场景空间、材质光色、镜头构图。给每张图明确 ID 和用途；附真实文件或可访问链接，不能只写图片描述充当已交付参考图。
6. **校验**：剧情信息未改变；角色仍可辨；军营地形可读；动作与镜头能执行；相邻镜状态一致；Prompt 引用与实际附件顺序一致；生成参数与导演文字分开。

生成与接入是后续独立阶段。收到授权后按当时模型能力制作，并验证动态身份、接触、口型及游戏内播放；文档完成不等于素材效果已验证。

## 按场景选择拍法

| 场景 | 优先拍法 | 主要风险 |
| --- | --- | --- |
| 军帐议事 | 帐内关系全景 → 地图或手部 → 说话者与反应 | 地图字错误、眼线混乱、无来源面光 |
| 营门交涉 | 入口与守卫关系 → 双人中景 → 有动机的反打 | 每句切镜、身份漂移、道具瞬移 |
| 行军与战争 | 地形/目标 → 队列 → 负重与接触细节 → 行动结果 | 只堆人数、复制士兵、步伐滑动 |
| 临终、犹疑、隐瞒 | 稳定中近景，留出反应与停顿 | 过度煽情、机械泪光、慢推滥用 |
| 回忆与时间变化 | 在既有剧情允许范围内，通过状态、动作或光线变化组织 | 擅自增加玄幻事件、信息不可读 |

这些是建议拍法，不是替剧情预设的必拍镜头。采用时说明其在当前段落的作用。
