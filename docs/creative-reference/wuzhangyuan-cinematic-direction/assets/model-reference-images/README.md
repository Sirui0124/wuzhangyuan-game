## 怎么交给模型

文件夹本身不会自动成为模型可见的参考。每个镜头从图库挑选相关的单张 JPG，实际上传后按当次附件顺序标为“图片1、图片2……”；图库 H01、B01 是内部索引，不是附件编号。默认每镜头选 1–3 张风格图，避免同时混入所有场景。

身份优先使用游戏已有角色图。本目录没有游戏人物身份参考图。下列为附件说明模板，需在实际选图上传后填写：

> 图片1：本镜头游戏角色图，锁定脸型、年龄、发式、服装和标志物。保留身份辨识度，通过皮肤微小纹理、眼部湿润感、自然发丝、衣料厚度与可信光影加强实拍感，避免磨皮和塑料光泽。
>
> 图片2：H01 原片单帧，仅借鉴侧向光线塑造面部体积、发丝边缘和肩背前景构图。人物身份仍以图片1为准。
>
> 图片3：B01 原片单帧，仅借鉴军帐空间纵深、人物围桌关系及局部暖光。人物、服装、道具、季节和地点全部遵循当前剧情。

实际 Prompt 还需用普通视觉语言写明光源方向、景别、人物动作、摄影机运动及连续性，不依赖模型理解片名。字幕、水印、原片人物、神话装备与雪山环境不作为迁移目标。地图上的文字必须按剧情另制。先确定镜头是否需要身份、光照、材质或构图参考，再给每张附件一个明确职责。

静帧不能证明精确运镜、运动速度或表演节奏；这些需回到原片片段核验，或在 Prompt 中明确设计。需要精准起始帧时，应另用游戏人物与剧情场景制作专属参考图。
