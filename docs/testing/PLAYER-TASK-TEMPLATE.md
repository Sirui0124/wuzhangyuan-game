允许写入路径：{{此run独立报告目录}}
UI 控制权：每人专属 IAB tab 与独立 origin，最多5人并行。你只独占自己的 tab，不触碰其他人的 tab，不使用全局原生输入，不共享存档；新开窗口本身不构成 localStorage 隔离。结束时归还自己 tab 的控制权。

你只依据当前实际屏幕、可见对白、已获得线索和你亲自经历的结果决策。不得读源码、README、策划、攻略、开发者隐藏状态、存档内部内容、未来剧情或别人的报告；不得用协调者预知的解法。不要借用历史知识替游戏中未给出的事实作断言。不要向协调者索要答案。

从现有可见入口实际游玩。每次操作后观察结果，再决定下一步。可以按角色习惯探索、回看、尝试和停止；不要为达成预定通关结果编造行为，也不要机械地扮演低智力。不得修改游戏、重置用户数据、部署或新开服务订阅。仅使用提供的独立环境，发现隔离不明确立即停止。若出现真实付费、购买或新增服务需求，不执行并交协调者处理。

停止条件：可见章末证据确认第一关完成；有具体行为与耐心依据的角色主动退出；真实游戏阻塞或工具/模型/隔离失败。首次死亡或回溯不是通关，不能仅因此结束试玩，应按可见进展和角色耐心继续。若硬上限或协调者停止，明确记为预算或行政停止，不伪装成通关、角色退出或游戏阻塞。

逐步记录真实 UTC 时间、可见事实、实际操作、结果、证据，以及一句简短决策理由。不要输出或记录私有思维链。失败操作写失败；结果未知先重新观察，不盲目重做。工具等待与模型等待不能算玩家思考时间。所有时间必须真实记录；未记录的开始、结束、每步时间及未测耗时写 null，禁止估算或事后编造。截图/工具结果没有保存成功时不要编造证据路径。

结束交付 run.json、steps.jsonl 和 report.md。报告包括：
1. 真实开始结束、实际到达范围、终止原因、操作次数与验证限制。
2. 剧情、交互、画风、整体体验四项：每项写具体观察与证据、喜欢、困惑、建议；未测试明确不可评，可选分数为1–5或null。
3. 画风只有实际看图/视频才能评价，纯文本不算。没有听审能力则明确“音频未测试”。
4. 问题与复现路径，分清游戏、模型执行和基础设施原因；不把猜测写成已证实缺陷，不输出真人满意度结论。
5. 若阻塞，准确列动作、目标、原因、已完成部分、denied/pending/uncertain状态和最小恢复办法。
6. 最后声明自己的 IAB tab 控制权已归还；不要控制其他角色 tab。
