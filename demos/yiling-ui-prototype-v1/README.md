## 可体验的流程

1. 默认地图与操作区上下各半。点击地图军旗或下方的沙摩柯、冯习·张南、傅肜，选择联络对象；聊天区自动显示该队历史往来。
2. 输入问话，点击“传话”；人物标签上方直接展示推荐问话，点击只填入草稿，不需要展开。支持位置、伤兵、敌情、接应需要等预设主题，不支持的主题明确说明。
3. 回报自动进入聊天区，前线回报在左，自己的消息在右，输入框固定在底部。第一个筛选标签为当前对象往来，第二个“所有传令”可查看完整记录；重新选择队伍时默认回到该队往来。翻阅历史时，新报不会抢走滚动位置。
4. 点输入框上方靠右的“传令”铜牌切换传令，人物标签区只放联络对象。铜牌与“传话”按钮采用相近的凸起边框，带朱漆“令”印；选中后可点“返回传话”恢复前线聊天，切换保留各自草稿。底部输入框上方提供“派遣队伍 → 接应对象”下拉项，默认均为“自动识别”；可以手选任意一项或两项，也可直接输入“队伍2接应傅肜，急行军”。甲乙丙丁队与队伍1至4对应。已识别的队伍和方向会直接显示；右侧始终保留四队简报，不切换成配置表单。
5. 点击“请军侯复诵”，检查各队任务、行军方式和绕行安排；可修改或取消。未确认时不会改变队伍任务。
6. 确认传令后，自动收到接令、途中、会合及归营回报，不需要重复点击继续。
7. 派队直接接应旧营会出现预设受阻报告。点击“安排绕行”仅填入新草稿，复诵、确认后演示绕行及归营。新军令会替换该队尚未发生的旧演示回报。
8. 每次成功问话或确认传令后，共用10秒间隔。切换队伍、切换问话/传令或刷新均不能绕过。倒计时期间可以看历史、写草稿、修改配置或复诵；未确认、空输入和不能理解的军令不消耗间隔。

手选用于补足未写明的队伍或对象；与文字冲突时阻止复诵并提示修改，不静默替换。两项手选齐全后，可以留空正文，按接应任务复诵。两项均为自动时，缺队伍、目标不明或同句有多个接应方向均要求补全，不任意派出默认甲队。点击右侧队伍可在左侧选定本队；多队任务在左侧统一复诵，复诵前不会执行。

自然语言匹配覆盖本稿的既定任务、四支接应队、三路前线与常用称呼，支持队伍编号和完整中文人数。采用本地字段解析，不是已接入任意语义的AI。问询、条件军令、相互矛盾的安排与本稿不支持的内容不执行，保留草稿供修改。手选和自动识别仍共用原复诵、确认与10秒发送间隔。

右侧始终显示四队编制、状态和传令倒计时，点击部队会在左侧选择本队。出动人数在自然语言军令中填写，只接受1至该队编制人数的整数；人数会进入复诵和已发军令，状态区展示本次出动数，归营后清零。余员仍在原编制中，本稿没有加入战斗损耗计算。一条军令可以同时安排多队，共用一次发送间隔；这不代表多次连续发送。

可写“乙队原地休整”“丙队撤回接应营”“丁队留营待命”。同一任务可以点名多队；不同任务请用逗号分开。含糊、否定或粮草配置语句会提示本稿不支持，不会假装已经执行。此范围只用于交互稿，不代表正式自然语言 API 的能力。

## 伸缩与阅读

- “展开军报/恢复均分”切换两种高度；分界线可以拖动，也支持上下方向键、Home/End。
- 1280×720 下地图与操作区各 302px；1654×1278 下各 581px。展开军报时地图 180px。单列聊天记录独立滚动，输入固定底部；复诵与确认位于左侧输入区，右侧仅保留军情简报；倒计时固定在窗底，长内容可独立滚动。
- 地图使用原 v6 地形资源；缩小时裁切并围绕当前关注部队调整视窗，不纵向压扁图像。地图、路线和地点一起平移。路网采用低对比、半透明的弯曲土路，保留既有路口连接关系。
- 下方面板采用暗木托底、暗铜回纹压角和灰褐色纤维纸；聊天消息与输入使用厚纸笺，操作为朱漆印牌。右侧军情/调遣窗采用独立账册结构，配置项改为内凹书写栏。可见文字统一为正文18px、控件16px、辅助14px，页首标题单独24px。本调整只适用于本独立交互稿，不变更正式章节公共字号规范。
- 消息按内容自然收缩，短消息不占整行；长消息在上限内换行。桌面自己的纸笺上限620px／当前栏宽76%，前线正文上限720px／86%；小屏最大96%，不以缩小文字塞内容。输入框随内容增高，超出上限后内部滚动。
- 窄屏保留单列聊天和紧凑倒计时，传令铜牌随输入框放在底部；人物栏提供独立“军情调度”按钮查看四队简报和回合操作，窗内“收起”关闭。切换传令与复诵不会自动弹出侧窗，确认按钮在左侧复诵内容之后。允许页面纵向滚动。
- 三路前线以带人物简称的军旗和姓名标牌标识，使用不同旗色及选中高亮；已出营的接应队使用可点击兵筹，点击进入本队传令。
- 切换对象或工作页保留各自草稿；刷新恢复本稿的草稿、记录、布局和尚未到来的预设回报。
