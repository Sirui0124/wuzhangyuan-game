# 夷陵前线 · 夜间军帐美术版 v6

2026-11-17。独立试玩，待用户审阅。新版入口 http://127.0.0.1:8955/ ，v5保留在8954。未接入正式第4章。

本次只调整美术与交互呈现。战斗引擎、三路事实投影和AI军令/问话模块分别与v5的`src/engine.ts`、`src/frontline.ts`、`ai.mjs`逐字一致。不改变兵力、体力、救援时间、战斗倍率、问话判定或通关条件。模型返回的Prompt版本号因此仍标识v5语义模块，并非漏更新。

## 美术方向

将整体收成一张夜间指挥案：炭黑与深墨绿作背景，旧金色只用于地点、联络对象和有效操作，军令按钮采用收敛的赭红色。军报与问话在同一张案面上，以细线分隔；不用大片浅色卡片、圆角胶囊、网页式导航栏或装饰性假状态。

军报正文采用项目既定的楷体24px等级；地点、人物、辅助文字分别处理层级，不为深色风格把正文缩小。窄屏主要上下排列，保留地图、军报与输入操作。

## 地图

地点改为文字与定位菱钉，去掉白色按钮框；大地点分人物/地点两级，岔口等小地点降低权重。选中的联络路线稍亮，未接触敌军仍不提前显示。兵筹仍是上次回报位置，非实时GPS。底图为本作美术示意，不宣称真实地理测绘精度。

## 调遣入口

按用户本轮纠正，删除顶部“前线联络/出兵调遣”Tab。前线页的**往来军报右侧**设置“调遣接应队”入口；出兵页在相同位置设置“返回军报”。三位前线对象仍在下方联络区切换。

出兵页仍暂停，确认军令后回到前线持续执行；页面间草稿、刷新存档、API等待和军令复诵规则沿用v5。独立入口仍为`/#frontline`与`/#dispatch`，但不再以顶部Tab展示。

## 启动与验证

双击`启动军报指挥试玩.cmd`，或运行`node launch.mjs`。沿用工程现有TypeScript及模型配置，不新增收费服务或账号配置。

- `npm test`：继承的22项规则/语义检查。
- `node checks/browser.mjs`：真实API三路问话、军报附近调遣入口、军令复诵确认、完整救援、页面草稿与刷新恢复。
- `node checks/layout.mjs`：1440、1280、681、390宽度的两个页面。
- [发布检查记录](checks/release-verification.json)：实际验证与旧版保留校验。

自动检查和开发者看图不代替用户美术审核与实际体验认可。
