## 本版的主要操作

说派多少人、做什么即可，粮草默认自动按正常建议配给。军侯复诵列出正常建议口粮、本令预计用粮、当前拨粮、预计归营时间和本期状态变化。建议不是未来保证：只考虑已知任务，未知军情和随机减员可能改变工期与耗粮。

- “傅肜五百，旧营八百，沙摩柯七百，都接齐回来。”
- “旧营口粮多给些，原任务不变。”
- “沙摩柯少给两成口粮，先省着用。”
- “沙摩柯加紧赶路，不增兵。”
- “旧营现队休整一时段，下轮自动继续。”
- “别赶路了，恢复正常，口粮按建议给。”
- “再给旧营添三百人，粮按建议配。”
- “先别执行。多给、少给、赶路和休整各有什么代价？”

推荐项仅填入自然语言原话，仍需“说出”和确认。普通进展、状态变化与正常补给自动执行，不要求每期回复继续。顶部4×只加快时间流逝，三路与期限同步前进，不改变部队节奏；自然语言“赶路”才改变执行效率与疲劳。新增任务、真正总粮不足等冲突才暂停；询问不解除请示。

## 粮草自动，但有限

总量仍2500人、5000斤。新兵出发自带每人1斤，计入粮袋和总账；此后按每期所需从营粮自动接续补给，不另扣重复出发粮。不模拟日常运粮队操作和常规运输延迟，运输微操不转嫁给玩家。营中与回程口粮不另计此“前线调拨账”。

正常标准为每人每时段半斤，每队向上取整。总粮不足时，各路按实际缺口比例分配，不按路线顺序优先喂饱第一路。满足所选配给后才按该待遇影响状态；如果连所选配给都不足，当期推进减半并额外加25个百分点受挫风险，军报会说明。

推荐值通过同一引擎模拟已知任务计算。复诵同时提供常规配给的剩余口粮建议、所选配给/节奏下的预计口粮与用时；不是固定乘人头，更不把建议写成玩家主动指定的额外斤数。自动发粮按实际结算扣账，不在每次预览、询问或改写时重复扣粮。

本时段“预计拨粮”包含出发携粮、自动补足、明确额外备用粮及救济；任务“预计食用”包含本期，但不把未吃的备用粮视为已食用。备用粮及回程余粮始终纳入守恒，归营后下一次下令可再调。

## 选择的真实效果

以下均为本试玩参数，不是Radio Commander原作或历史数值。士气初始70，上限85；疲劳初始0，上限100。

| 安排 | 粮草与状态 | 执行后果 |
|---|---|---|
| 正常配给 | 按100%自动配发；正常吃饭本身不逐期加士气 | 正常推进每期疲劳+5 |
| 多给些/优待 | 默认120%；也接受“加两成”等明确幅度，范围60%—140% | 实际吃到120%以上后每期士气+4，最多85；140%更费粮但不额外叠加恢复，不消除疲劳 |
| 少给些/节用 | 默认80% | 按实际所吃的正常比例降低士气：80%每期约-6；60%约-12。状态下降后可能拖长工期，最终总耗粮未必按同一比例下降 |
| 赶路/加紧推进 | 保持当前配给；每期疲劳+22、士气-4 | 工作推进乘1.35，额外受挫风险+10个百分点；阶段门槛和先后关系仍保留，不保证快一整期 |
| 休整/重整 | 占用一时段，仍按当前配给吃粮；疲劳-35、士气+12，均有边界 | 本期接应工作暂停；若有该路新增任务，也用本期完成重整。下期自动恢复正常推进，无需再说继续 |

士气45—64时推进×0.9、风险+5；低于45推进×0.65、风险+15；达到80推进×1.05。疲劳60—79时推进×0.8、风险+10；80起推进×0.6。它们与赶路和任务冲突修正相乘，风险相加后封顶100%。休整时不应用主动推进的状态惩罚，但现有守备需求仍可能带来风险。

单纯多带备用粮不会提高士气；口粮优待也不能消灭敌情、治伤或替代新增任务需要的人手。若只是调整配给，不会自动算作对人手冲突的答复。休整后再改配给保留待执行休整；明确改为赶路或恢复正常则复诵提示取消原休整。

## 人手与状态会延续

“营中待命兵”就是未被当前任务占用的兵。增援优先使用营中疲劳较低的人，按人数把士气、疲劳与现队加权。归营者保留状态，在营中每时段疲劳-15、士气+4（上限85）；不会通过撤回再派遣洗成满状态。归营兵本次结算不能同时在别路工作。

三路的换防、迁旗清路、搜寻守口仍由部队自行分工。窗口继续为第6/7/8时段末。每局仍有一种主要新增任务，三种军情随种子变化；本版没有声称完成多事件战役。临场反应包括增援、适用的救济粮、休整重整或明确接受照旧后果。
