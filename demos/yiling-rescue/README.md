# 夷陵 · 归路：独立试玩

营救与军令玩法已接入完整游戏第四章，入口为 `http://127.0.0.1:8812/?chapter=yiling`，新玩家也可从舆图抢先体验。本目录同时保留8828独立试玩，两者使用不同存档。2026-11-02按用户要求删除黄权三队240人的旧故事，第四章及旧试玩链接统一使用本版多路营救；本机历史存档保留。正式版六轮结束后自动记录九条路线结果；主线通关街亭后可前往荆州，抢先体验结果继续有效。玩法与美术仍待用户试玩审核。

双击同目录的 `启动试玩.cmd`，或从工程根目录运行 `node demos/yiling-rescue/launch.mjs`，打开 http://127.0.0.1:8828/ 。需已有 Node.js 22+ 与工程依赖。启动器先编译，再隐藏启动本机服务；重复启动复用服务。

AI复用本机游戏服务保存的模型配置（含临时模型档案），凭据只在服务端读取，不传浏览器、不进入Git。当前模型状态可通过 `/api/health` 查看，不返回密钥。缺配置时在正式游戏设置中完成配置，再刷新试玩。本Demo不静默用预写对白冒充AI。

## 玩法

- 初始2500人，第2至第6轮开始时各增补500人，总供给5000人，100人为一档。未用兵力可结转。每轮统一发布一份可包含多路任务的军令，兵力直接扣减，不再返回可调池。派出不是阵亡。
- 十二时辰、六轮；第一时辰拟令，第二时辰看结果。阅读、提问、思绪整理、军令预览都不推进时间。发布前可改草稿；确认后写入本机存档。
- 刘备开场提及张南／冯习与马良，需通过军营选项确认路线后才出现地图标记。军营简化为刘备、点名处军吏、失散亲随、船工四个点位。军吏提供傅肜、沙摩柯、杜路／刘宁、程畿的消息；亲随提供黄权、王甫的消息。营中每人每轮只做一次选择：选中的路线立即出现，另一条在下一轮的同一阶段起可继续向该人物询问，选中后才出现。军吏按组依次交代，每轮最多确认一路；离开、刷新或进入本轮军报阶段都不恢复选择次数。晚发现不延长截止时间，末轮延迟赶不上接应。地图人物出现后可向各路报信人自由追问，每次最多补充一条新事实。
- 沙摩柯、黄权各有一次整理思绪与开放说服。选择两条相关依据形成思路，再自行发言；合理的未来行动安排允许通过，不要求固定句式。
- 孙夫人支线采用演义。船工在第4个时辰（第二轮军报送达）靠岸，此后一直可交谈；开场只提吴地误传死讯。选择给孙夫人报平安即可发现路线。结果阶段也可询问，不推进时间，不可下令。
- 各条路线截止轮次固定，不随发现时间重置。未发现路线也随战局变化，但不列入中途营救栏；结尾显示错过的对象。

## 数值与概率

每条军令由AI识别已知情报支持的三项行动，并返回原军令中的逐字引用。引用不存在、行动ID未开放时拒绝，不扣兵、不推进。任务系数为0.55 + 0.15 × 匹配项数，最多1。尚未说服的核心对象合作系数0.75，说服后1。

基础减危 = floor(100 × 投入兵力 / 基准兵力 × 任务系数 × 合作系数) + 首次有效行动数 × 6。重复提交不重复发放首次奖励；核心说服仍单次减危8点。

每轮根据后台范围抽取实际接应效果与战局恶化值：

| 轮次 | 基础减危的执行范围 | 基础恶化之外增加 |
| --- | --- | --- |
| 1 | 85%—108% | 0—2 |
| 2 | 82%—105% | 0—3 |
| 3 | 78%—102% | 1—4 |
| 4 | 76%—100% | 1—4 |
| 5 | 73%—98% | 2—5 |
| 6 | 70%—96% | 2—6 |

每匹配一项已知情报支持的安排，执行范围下限提高2个百分点，完整军令提高6个百分点。投入兵力决定基础减危，军令与合作决定效率，轮次决定战局压力。每条路线仍使用自己的基准兵力、基础恶化与固定截止时间。没有按玩家表现暗改结果，也不强制限制可救路线数。

实际减危在 `floor(基础减危 × 执行下限)` 至 `floor(基础减危 × 执行上限)` 的整数区间内取值。战局恶化在该路线基础恶化加本轮增量的整数区间内取值。两者按“开局／路线／轮次／判定类型”独立确定；同一战局增加兵力或完善军令不会让效果变差。刷新、重新预览、修改措辞、模型失败重试和军令顺序均不会重新抽取。新存档保存独立私有种子，旧存档从已有私有随机值取得稳定结果；已结算军报保持原值。

每轮危机 = clamp(旧危机 + 实际恶化 − 实际减危, 0, 100)。降至0立即脱险；到期仍大于0时，1—9生还率95%，10—49为0.9×(50−危机)/40，50—100无法营救。最终生还判定仍使用原有开局随机值，与接应波动分开。

玩家在发布前只看到“接应较有把握”“有望接回，仍有变数”“可缓解危机，仍需后续接应”等判断；接口不提前返回实际减危、未来危机、随机种子或内部范围。接应结果在确认发令后写入军报，显示实际危机变化及受阻／推进情况。

黄权失败为降魏，杜路／刘宁失败为降吴；其他角色按战死或演义支线结局写作，未把降敌等同死亡。

军营开场、选项、回应及回信均为固定文案，完全不调用模型；旧存档保留分支决定，界面直接显示当前固定文案。地图报信人的自由对话、每轮总军报和各路独立回报继续由AI生成。AI不决定数值、时间、扣兵或随机结果。模型只接收当前允许的事实与已结算结果。消息仍可能出现措辞不妥，需用户实审；本版没有逐句语义二次审计。

## 军营每轮一次交谈（2026-10-28）

军营只显示人物对白和当前选择，全部为预设文案，不调用模型。阅读不耗次数，确认选择后本轮结束交谈。再次进入只显示答复和离开／安排接应入口，不再逐条询问。

| 人物 | 一次交谈的选择 | 后续 |
| --- | --- | --- |
| 刘备 | 先接张南、冯习／先找马良 | 所选路线立即出现，另一路下一轮出现 |
| 点名处军吏 | 第一次：傅肜／沙摩柯 | 所选路线立即出现，另一路下一轮出现 |
| 点名处军吏 | 下一轮起第二次：杜路、刘宁／程畿 | 所选路线立即出现，另一路下一轮出现 |
| 失散亲随 | 黄权／王甫 | 所选路线立即出现，另一路下一轮出现 |
| 船工 | 给孙夫人报平安 | 第4时辰解锁，确认后出现路线 |

例如刘备说：“前军还没撤下来，马良也没有回来。你先接哪一路？”玩家选“先接张南、冯习”，地图立即出现前军，马良随下一轮消息出现。军营选择只决定情报先后，实际派兵仍在地图中安排。

两个时辰共用一次交谈机会：下令阶段选，另一路在下轮下令阶段出现；军报阶段选，另一路在下轮军报阶段出现。旧存档已发现的路线保留，本轮已有的军营选择计入次数。末轮延后的消息不再补发。
