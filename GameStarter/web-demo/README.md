## 当前玩法

点击地点、找人物、逐句读对白、调查并收集证据，再向人物当面出示、自由交涉、触发结局，最后回看本轮信息或重新调查。完整路线见[玩法说明](../../content/chapters/wuzhang/walkthrough.md)。

第一次是教学：取得禁令、向斥候出示并确认营门未失守，再向魏延依次出示禁令和军情。玩家承诺自己转呈急报即可暂候，不要求先取得姜维许可。固定短演出呈现主角说“军情我会转呈，将军放心”，魏延退走；主角将军情交给无权处置的甲，误以为灯亮就成功，没有确认有权者处理或取回军令。次日魏延问“昨夜军报，你交给谁了？谁回的令？”，主角答不上来。魏延说“虽未酿祸，也不堪此用。别让我再看见他。”，随后刀影黑场明确处死。report_status仍为none；新增tutorial_report_stage记录承诺、交给甲、无回令、受罚。结局唯一按钮“继续”进入复活调查。旧问罪视频保留但不播放，以对白演出呈现新因果，不生成新片；第一轮不增加成功传报任务。严重当面挑衅处斩和灯灭失败仍为独立分支。

2026-10-16：替代原“单因记恨抬走”的问罪因果；历史视频验收不代表新流程验收。第二轮v07规则不变。未新增军事损失或全剧穿越设定。

第二轮从告示前复活，先听甲说明责任与请示时机，再听乙指向姜维亲兵。两段完整确认后才开放姜维将军帐前；亲兵拒绝错误理由后可以重选。完整读完亲兵从中军帐外带回的许可，才取得 jiangwei_authorization，并开放中军帐门和营前传报处。营前核实斥候军情后魏延出现；先出示禁令，再逐项出示军情和姜维许可。重要沟通兼顾军情紧急、丞相禁令及擅闯风险、现在隔帘请有决策权的姜维接报担责。魏延同意后仍须完成实际接报、姜维下令、魏延回营的演出，才通关。没有第三次 AI；不合理办法导致灯灭，严重挑衅导致处斩。

每次只能选择并出示一项证据。第二次显示「选择你的第一个证据」「选择你的第二个证据」，两项实际提交后才开放输入；只持有、勾选、重复或错误出示均不推进。刷新保留本次已提交证据；离开魏延或切换地点会结束本次举证，返回时须先重新出示禁令。

## 对白与 AI

点击对白框继续，空格和 Enter 也可推进；选项、输入、菜单、弹窗、文字选择与拖动不会推进。Esc 关闭面板。旁白及主角独白提供「跳过」，逐句确认当前连续叙述及其效果，遇到人物台词或下一节点停止；开场跳过后正常解锁营前。人物与调查物件保留「结束交谈」，退出不自动确认未读对白、发放证据或选择分支；必须读完的既定结果仍锁定退出。按钮与正文同字号。已读线性对白可回看，不重复发卡。旧版提前关闭开场的同版本存档读取后会重新打开开场，可读完或跳过。

证据详情保存来源原话和「尚不能说明」。错误出示只回复“你给我看这个有何用？”，随后恢复原对白或选项。关键交涉点击「撰写回复」展开居中大弹窗，桌面采用最新收窄的居中版式，保留上方和左侧导航。可查看与修改实际出示证据、选择本轮已听对白作为记忆短语、展开 AI 润色的目的/语气/其他信息，并查看分阶段固定提示。工具区可滚动，输入框和确认按钮保持可见。

润色使用现有代理，25秒超时，仅把生成结果填入可编辑草稿；点击「确认回复」后才提交魏延判定。记忆短语属于玩家的写作参考，不计作实际证据，不加入魏延记忆。取消、关闭、离开或生成中修改原稿均不会被迟到结果覆盖；调用异常保留原稿。提示只展示建议，不替玩家填写。真实流程与截图见 `verification/reply-composer-browser.json`。

魏延只看本次原话与实际呈证，不加入 NPC 记忆。第一次须有禁令、斥候证词，并提出立即请帐内人接报或由帐门卫士隔帘转报的办法；第二次还须实际出示姜维本人许可、引擎中本轮许可已到账，并说明即时隔帘接报、姜维定夺担责的办法。仅说找人、请人不能由模型补成接报。严重本人辱骂、杀害威胁或主动投敌毁军报为处斩，引用和否认不算；一般不合理办法只是入帐。

先分类，程序核验实际证据与原话中的传报行动，再生成恰好两个中文字段的 JSON：决策分类（帐外等候／坚持入帐／震怒处斩中的单个值）、回应的话（贴合当前输入并保留预写结论）。错分类、多字段、丢失结论或越界措辞回退固定结论；不改变世界状态。两轮完整 Prompt 和正反例见 [v07说明](../../docs/魏延_两次交涉_v07_Prompt与JSON.md)。

分类最多45秒，措辞最多12秒。措辞异常回退固定结论；分类异常保留草稿供重试，不算剧情失败。取消、离开、读档或重开后，迟到回应不能写入新状态。

## 声音与设置

设置提供 API 服务网址、模型和 API 密钥（密码框预填）。默认 DeepSeek / deepseek-flash，关闭思考。点击「保存 API 配置」后立即用于自由交涉与润色；开发版写入 `server/.env`，独立应用写入用户目录的 `.env`，重启后保留。无效网址或空字段不会覆盖当前可用配置。

触点音效已接入：轻点击、对白推进、面板开合、翻页、证据选择/出示/取得，以及提交与回应。默认音效 45%，短音做了柔化处理；同一次操作不叠响，连续点击限频，输入文字和拖动滑块保持安静。设置提供独立的音乐与音效音量，范围 0–100%，最左为静音，自动记住并跨刷新、读档、重玩保留。地图也提供设置入口。

四段 BGM 已接入：首页《五声余韵》、第一轮《七星灯未灭》、第二轮《再查此夜》、魏延交谈及输入对白《帐前未决》。播放与停止有 2.5 秒渐入渐出，换曲交叉淡化；循环版首尾另做 4 秒交叉淡化，去掉近静音尾段，避免每轮循环停顿。首页曲保留原曲开头；视频页面立即暂停所有 BGM（包括正在渐出的旧曲），视频手动暂停仍保持 BGM 暂停，播放完或跳过后自动恢复场景曲目。首页的设置、读取存档与成就卡册不重启首页曲。资源与接入说明见 `../../source-art/发布排除归档_20261011/开发说明/声音接入_README.md`。浏览器验证见 `verification/audio-flow.json`、`verification/bgm-flow.json` 和 `verification/home-bgm-flow.json`（未进行人工听音），截图见 `audio-settings-desktop.png` 与 `audio-settings-mobile.png`。
