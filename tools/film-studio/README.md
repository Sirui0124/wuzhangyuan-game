# 逆转五丈原 · 片场工作台

工作台采用浅色简约界面：浅灰底、白色内容区、深色正文，用少量青色标识当前选择和主要操作。日常 HTML 工作工具默认沿用这一方向，约定见工程根目录的 README.md 与 AGENTS.md。（2026-10-30）

在工程根目录双击 `启动片场.cmd`，或运行 `node tools/film-studio/server.mjs`，访问 <http://127.0.0.1:8926/>。复用本机视频和现有军营几何，不需要上传素材。

2026-11-02 按用户要求简化首页：34段现用视频按目录顺序展示，每个视频旁有一个可编辑评论框。停止输入约0.7秒或离开输入框后自动保存到本机 `outputs/film-studio/review.json`，每段、每个视频版本独立存储。评论可以修改和清空；保存失败保留输入并提供重试，浏览器也暂存未保存输入。多页面编辑同一条评论时先核对差异，不覆盖另一页面的新内容。旧的时间点意见在对应视频的“之前的审片记录”中保留。

首页底部的“台本与场景参考”进入旧版 `/workbench.html`，保留台本、顺序预览、审片、版本对照及场景参考。以下为这些功能的说明。评论接口与重启保存验证：`node tools/film-studio/verify-comments.mjs`，测试使用独立临时目录。

## 第一章可编辑台本

2026-10-30阅读界面调整：正文按场景和人物连续排版，直接点击台词编辑；同一人物的连续台词只显示一次名字。受话人、表演要求、来源和技术编号放在每句右上角的详情中。正文随文字自动增高，去掉编辑区内层滚动。“现片台词”和“重拍稿”可在正文上方互相切换。开篇传令兵、魏延的显示名称来自PR01-B/C原制作稿，保留“按制作稿”标记，不将其当作实际听审结论；不覆盖已有说话人草稿。

来源为本轮实际读取的飞书逐句执行第271版，共113行；与程序118行比较后，将在线已无的5条P2反馈列为历史，不混入主线。4条文案差异均是AI回应意图与默认示例的表达差异，未擅改AI模块。

- 左侧“当前路线”提供四种组合：首轮询问营门／坚持禁令，第二轮先甲后乙／先乙后甲。每条有43个预览节点，其中32段为视频；另一首轮选择与另一版转呈不混播。
- “全部台本”可以编辑所有现用片、十三份准备台本及交互文案。R00的三句现代段心声单列为准备稿，没有覆盖现片VTT转录。R01—R12同时带分镜动作和原说话人台词，动作不朗读。
- 可以编辑说话人、台词原句、受话对象和表演要求；每段视频有独立拍摄备注。“保存台词草稿”写入本机`outputs/film-studio/chapter-draft.json`，修订和变更历史保留，拒绝旧修订覆盖并发编辑。未保存输入也在当前浏览器暂存，并在离开时提示。
- “预览”播放现片原声，显示当前编辑稿供对照。片尾自动接下一段；遇到文字、玩家选项、推理或AI对话即暂停。下一段是审片导航，不执行游戏判定，不增加或消耗玩家线索。
- 程序会用真实NPC回应替换A-40B和W07，因此它们归动态回应，不误列成需要固定补拍的缺片。画布、结算、告示、导演说明与台词分开。
- “导出台本”将全章现用片清单、台词、十三份重拍准备台本、互动文案和8项整体review导出为Markdown；“导出JSON”保留结构与来源，可迁移继续编辑。文件仍保存到`outputs/film-studio/exports/`。

本轮编辑只维护工作台草稿。保存不会自动改飞书策划表、游戏正文、现片声音或字幕；后续收到同步要求后再比较来源并定点同步。

接口与分支验证：`node tools/film-studio/verify.mjs`。测试使用独立目录，不写正式审片意见或台词草稿。在线源快照保存在`data/chapter-source.json`；`snapshot-chapter.mjs`从本轮CLI原始读取文件归一化，不会自行联网或监控表格。

- 审片：自动读取启动时第一章实际 `cinematics.json` 绑定，提供播放、0.04秒定位、抽帧、A/B对照、带时间点和版本标记的意见、本地人工结论。外部新片临时对照，评论仍归左侧现用片，页面明确提示。
- 片场：复用 `source-art/visuals/spatial/camp-v1`，十个原机位加两个空景机位，可调眼点、目标、视野角及八个人物代理的坐标和朝向，保存机位、导出配置、导出1920×1080干净参考图。单位米；Y向上，Z向南。鼠标环绕/缩放，WASD平移，Q/E升降。
- 参考：已有场景图、平面与外部资源链接。外部仅作选型研究，未购买下载。没有把网站预览图下载充作自有图。
- 重拍：R00—R12本地准备稿及其真实参考图。文件保留原文，不推断飞书审批状态，不自动调用生成。

意见与人工结论保存到 `outputs/film-studio/review.json`，按视频路径、大小和修改时间形成版本标记（不是内容哈希）；导出JSON可留档。图片、审片记录与片场配置直接保存到 `outputs/film-studio/exports/`，顶部出现可打开刚导出文件的链接。自定义机位保存在当前浏览器 `localStorage`，可另行导出片场配置。刷新服务器后再扫描资产；原文件变更后的版本不会继承旧审片结论。意见不能直接改写正式飞书台账或游戏选片。
