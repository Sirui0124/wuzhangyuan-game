# 第一章独立对话审阅 v3.3 AI

2026-11-17，本版对白与阅读体验待用户审阅。页面从小甲开始，保留两项选择、守卫自由问话、四种结局和死亡后的新问法；魏延最终问答已接实际模型。

双击同目录的 `启动第一章审阅.cmd`，或在项目根目录执行：

```powershell
node tools/chapter-one-review/server.mjs
```

打开 http://127.0.0.1:8941/ 。依赖当前工程已有的 Node.js 与 TypeScript，无需另装前端依赖。服务只监听本机。

页面直接请求 `/story.json`，服务读取 `docs/design/chapter-one-branches-20261117/v3/chapter-one.design.v3.json`。全部对白、选项、效果和跳转由该文件提供；HTML 不复制剧情。改稿后刷新，点击“从头读”体验。v1、v2 保留。

- “上一步”恢复上一段对白及当时的状态，便于比较选择。“从头读”清空本轮线索，从告示开始。
- “回看对白”只显示走过的内容。没有线索列表；问出伯约可代为把关后，才在最终输入处出现对应提示。
- 进度只保存在本页独立 localStorage 键 `wuzhang:isolated-dialogue-review:v3`，不读写正式游戏存档。
- 小甲的自由输入仍为本地有限问法识别。支持询问其他接报、处置、作主或担责的人；单报名字、自称负责或已获授权不授予提示。不能据此评价真实 AI 理解能力。
- 魏延的两条说服路线进入实际 AI 输入。军情明确写作“魏军的骑兵已经到了营外，还没攻营。前营等着回话，我得见丞相。”输入提示为“我了解今晚军情是＿＿＿＿，军令我可以＿＿＿＿”，允许自己的说法和分轮补充。
- 每次最多三轮，读取最近两轮玩家与 NPC 的完整问答。三轮仍未说清可重新组织；连接或判断格式错误保留输入，不作剧情失败。取消、修改、返回和重开会使迟到回应失效，刷新保留进度及草稿。
- 模型先理解军情、接报方案及是否冒认授权，程序按实际路径决定结果；随后单独生成魏延回应并核对行动归属及事实。生成或核对未通过时使用该结果的预写回应，页面明确提示。没有把关键词匹配冒充最终 AI 判断。
- 知道伯约不等于获得应允：请他出面或把报送去仍需经过后续本人同意与实际传令。自行转呈进入原教学死亡；主动放行进入灯灭。“怕将军为此获罪”在下一次选择后固定闯帐灯灭，不开放 AI。
- JSON 中 `title` 为策划节点名，`displayTitle` 为阅读时的场景标题，防止内部判断词提前透露结果。
- 每屏呈现一个节点的完整对白，再显示选择。选择中的 `say`、`response` 单独呈现；点击继续后进入目标节点。提示在小甲或姜维回答实际呈现后取得。
- 第二章只有阅读边界，不会进入正式游戏。服务端只读现有模型配置，复用纯模型传输函数，不启动或修改正式游戏服务器。密钥不传给浏览器。输入及必要剧情上下文会发往已配置的模型服务。
- 服务端按操作记录重建实际路径，并核验之前 AI 回应的签名；客户端自称获得线索不会直接生效。签名密钥保存在忽略提交的 `.local/receipt-key`。

校验命令：

```powershell
python docs/design/chapter-one-branches-20261117/v3/validate_and_render.py
npm --prefix tools/chapter-one-review test
# 单独调用真实模型验证，会产生已配置服务的正常调用费用：
node tools/chapter-one-review/live.test.mjs
# 启动审阅服务后，通过浏览器提交真实发言并走至结局：
node tools/chapter-one-review/live-browser.test.mjs
```

静态校验同时生成可按节点跳转的 Markdown 阅读稿。浏览器检查使用独立 Chrome 上下文，结果和截图在 `outputs/chapter-review/`。`review.test.mjs` 检查规则、状态和签名；`browser.test.mjs` 使用受控模型检查交互与异常；`live.test.mjs` 使用实际模型验证六组发言。真实调用结果单独记录回应来自模型还是预写后备句，不把受控测试当作模型能力验证。有限样例不能保证任意输入的稳定性，测试通过不代表用户已认可对白。

本轮验证：静态检查 40 节点、134 状态、12 条路径；12 项规则检查通过；受控浏览器的四条路线及取消、改写、返回、刷新、连接失败和窄屏检查通过。实际模型六组发言的分支均符合预期，其中三组采用预写后备回应；实际浏览器走完请伯约看报至灯火未灭结局，该次回应也采用后备句。模型生成的角色行动归属尚有不稳，保留此限制供对白审阅，不标为用户通过。
