# 对战与动作

吸收《关羽对吕布》的角色与兵器锁定、统一战场、攻防反应、阶段变化及蓄势到结果的组织方法。以下写实适配是制作建议，未据此验证某一生成模型的成功率；不把该文当成历史、真实武术教材或已生成样片。

## 选择战斗模式

默认写实历史模式：重量、惯性、步法、呼吸、衣甲阻力和真实接触建立力量感。以踏步扬尘、武器被拨偏、握持调整、身体受力与退步表现强弱；刀气、雷电、幻象和超尺度地裂不进入默认Prompt。

只有当前任务明确要求神话或超自然力量，才使用幻想分支。先规定能力来自谁、起效位置、影响范围及结果，再加特效；仍需真人皮肤、衣甲材质和可辨的攻防。不能用满屏能量替代所有兵器交锋；战斗模式不能中途无说明切换。关羽、吕布的特定配色、衣甲和能力只属于源稿，不覆盖本作角色资产。

## 锁定可连续拍摄的空间

交锋前写明双方起始左右位置、面向、距离、脚下地形、各自兵器及握持方式，必要时用近景地物和远处营门维持方向。首帧应能完成设计的攻击范围，长兵器不要贴身穿进对方身体才开始动作。

一个连续交锋单元留在同一片空间。追击、退出营门或跨地形可以换空间，但须交代路线和到达，不能一剪就变成另一处战场。背景兵器、倒地物与破损状态延续，受损物不能下一镜完整复原。

## 按攻防关系写动作

每个主要交锋写清四件事：

1. 发起：谁向何处踏步，兵器从什么方向朝哪个目标移动。
2. 应对：另一人如何格挡、侧闪、退步或改变握距；有看见攻击和调整的时间。
3. 接触与受力：哪一段兵器接触，力向哪里卸开，手臂、躯干与脚如何承受；闪避成功则不凭空响金属撞击。
4. 结果：谁被逼退、谁得到空当、双方新的距离和兵器位置；下一招从这个状态继续。

用行为区分人物：沉稳者控制距离、压住对方兵器后反击；急攻者用连续进步迫使对手后撤。不要只堆“霸气、狂暴、绝世”。结果服从剧情，不因动作示例擅自让一人受伤、死亡或败走。

握持要求要可执行：锁定初始握法和必要换手过程，不写“双手始终握持”后又要求松手、抛接或单手变招。被拨偏的兵器须先回收才能下一次挥击；长兵器不瞬间缩成短刀，手不能沿杆瞬移。

## 节奏与机位

“一个主要变化”可是一组紧密相连的攻击、格挡和反击，并非每镜只能动一下。复杂招式先拆成观众能读懂的动作单元，按所需时长安排，不照抄原稿1.5秒三连击。紧凑来自动作目的清楚和停顿取舍，避免全片匀速挥舞、无限慢动作或后期整体倍速掩盖失真。

- 中景或全身双人镜头交代距离、步法和攻防；近景只强调关键接触和表情，再接回空间关系。
- 固定、侧向跟移或短距离推进择其所需。低机位可体现重量，但不能只剩仰拍脸部、看不见碰撞。
- 快速跟拍保留主体与攻击方向；运动模糊落在快速边缘，不把关键接触整段糊掉。
- 原稿高速180度环绕、俯冲、升高与拉远是可选拍法，不必全部使用。跨轴前用连续运动或重新建立空间解释位置改变；不得无说明镜像翻转双方。
- 切点由接触后的反应、闪避结果或方向改变触发。不要每次将刀刃真正接触的瞬间都剪掉，也不要反复回放同一击充当更多回合。

## 不同规模的处理

| 场景 | 必须看见 | 重点限制 |
| --- | --- | --- |
| 双人步战 | 身体与兵器距离、重心、格挡方向、结果 | 不能站桩挥空、兵器互穿、凭空受击 |
| 骑战与追击 | 马的行进方向、骑手平衡、缰绳与兵器职责、交错后位置 | 不把马当无惯性的滑台；不默认一手同时拉缰又双手握兵器 |
| 断后与小队交锋 | 敌人从哪里逼近、出口在哪里、谁被保护 | 不用来回切无关拼杀替代包围形成过程 |
| 群战 | 近处可辨的行动小组、中景队伍、远处地形 | 防止复制兵阵、人人同步挥刀、无序涌入挡住主要动作 |
| 溃退与中箭 | 威胁方向、人物反应、身体失衡和落点 | 死亡方式必须已确认；不因源稿自动加入爆炸或夸张飞退 |
| 明确授权的神话战 | 蓄势、释放、对手应对、碰撞、可持续的结果 | 特效不能吞没脸手和兵器；破坏范围不得无因扩张 |

## 写实动作示例

以下仅示范调度写法，不是本项目新增剧情，也不是可直接提交的完整生成文档；正式稿需换成实际角色、参考图和已确认结果。

> 同一营道内，两名武将保持既定身份与长兵器形制。甲在画面左侧面向右，乙在右侧面向左，双方有完整挥动空间。侧面中全景，摄影机与两人同高，保持在轴线同一侧。甲前踏半步斜向下劈；乙退半步并抬起兵器迎挡，接触点清楚，两人的肩臂与握持随受力短暂收紧。乙顺着来力将甲的兵器拨向外侧，甲随即收步、回收兵器，不让刃口穿入身体。双方重新形成戒备距离，衣甲与脚下细土只随真实动作变化。全段围绕一次攻防，不增加第三人、刀气或地裂。金属接触声对应实际接触，衣甲与脚步声跟随动作，无BGM，无新增对白。

正式镜头长度按动作与平台能力确定。先验证一次攻防是否连贯，再视需要增加回合；不能宣称多加“物理正确”即可解决穿模。

## 审阅重点

顺序查看起手、接触、卸力、回收、结束姿势，必要时逐帧定位。核对兵器全程数量、结构、手掌接触、步法与地面、受力方向、轴线、背景连续性和音效同步。大量火星、烟尘、震屏只能是有根据的结果，不能作为隐藏穿模的补丁。源稿的0.1秒定格不作为默认要求；冻结、变速或倒放须有具体设计依据，不用来伪造真实动作完成。
