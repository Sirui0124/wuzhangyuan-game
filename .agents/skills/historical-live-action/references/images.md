# 图片与统一质感

## 先确定图片用途

| 图片用途 | 必须表达 | 避免 |
| --- | --- | --- |
| 人物身份 | 当前时期的脸、年龄、须发、冠帽、衣甲；自然闭口表情，必要时补侧面 | 用怒脸迫使每镜怒瞪；用参考作品人物换脸 |
| 兵器与道具 | 完整轮廓、比例、材质、握持区、正反面；与手或身体的尺度关系 | 只拍刃尖却要求模型还原整柄武器；过度装饰改变形制 |
| 场景空间 | 道路、门、台阶、出入口、可行动区域，近中远层与光源 | 无因新增城池、悬崖、军队；背景漂亮但无路可走 |
| 当前首帧 | 本镜开始时的确切站位、持物与接触关系、动作准备状态 | 用已经落地的兵器作“落刀前”首帧；用动作结束图要求重新完成同一动作 |
| 风格参考 | 只负责指定的材质、光色、景深或空间组织 | 默认当作首帧；带入外部角色、文字、UI或服饰 |

单张图选择一个时间点，不同时描绘起手、碰撞、退步和结束。联系人物身份与构图参考发生矛盾时，先修构图或明确两图职责；不能要求模型自行猜测。原尺寸单帧适合构图参考，联系表用于研究，不默认当作生成首帧。

## 构图与可读性

先定观看位置：玩家眼高、旁观侧面、营门内或远处山坡。近景遮挡提供位置感，中景承载行动，远景交代地形；不要求每张特写都出现完整三层。对战首帧需留出武器摆动和后退空间；刀柄、戟杆、手和身体不能先天穿插。近战构图避免两柄长兵器重合成一条，双方脸、手和攻击方向至少有必要的信息可读。

人物大小由叙事决定：环境建立可让人占较小面积；对白和交接要看清表情及手。需要身体全幅和完整兵器时不强行用人脸大特写；需要印钮与掌纹时不强行把整个营地纳入焦内。

## 光色与材质

- 明确主光来自哪侧天光、帐口、灯火或火场；阴影和接触阴影跟随光向。夜景不为“5500K”改成白天，室内可有局部冷暖光，但不整体蓝橙染色。
- 脸保留细微纹理与自然色差，人物年龄和美术身份不变。不要靠加深皱纹、煤灰脸或油亮汗珠把所有人做得苦旧。
- 粗麻、丝织物、皮革、木材和金属的反光不同；布纹不应像浮雕，铁甲不应有塑料描边。磨损集中在折叠、摩擦、握持或热损位置。
- 地面按干湿与光线呈现；干土不用镜面反光，雨地也不是整片镜子。薄雾主要影响远处对比，不把清楚的前景统一洗白。
- 细节与景深服务信息。f/1.8、胶片、相机型号、IMAX、8K是可选视觉沟通词，不作为实际设备、输出分辨率或成功质量证明。

## 图片Prompt的拼装顺序

画幅与真人摄影目标 → 本镜时间地点 → 参考图各自职责 → 人物/道具和空间位置 → 确定瞬间及接触 → 光向与物体本色 → 景别与景深 → 必须保持的状态 → 针对当前失败风险的限制。

可复用的共同质感段：

> 横向16:9满幅，真人历史电影剧照观感。沿用已确认人物的脸、年龄、发型和衣着，肤色自然，皮肤与须发保留细微纹理；织物有重量和受力褶皱，木、皮革、铜铁各自呈现合理磨损与反光。光源位置明确，中性自然色温，无整体黄偏，实际火源照到的局部保留暖色。空间尺度可信，关键脸、手和道具可读，阴影有必要细节，高光自然过渡。无游戏CG、磨皮蜡像、均匀金属亮边、过强HDR、文字和水印。

此段只是共同质感，不能替代人物、动作和构图说明。按当前图删去不相关材料，不把全部排除词重复堆入每张请求。

## 静帧核对

核对身份、左右手、兵器数量和形制、握持接触、腿脚支撑、空间通路、光向、画幅及真实像素尺寸。区分“静帧可用”与“运动可行”：图片正确不能证明后续兵器碰撞、马蹄、叩首或口型稳定。图中若带人而需要空景，先准备合适首帧，不靠一句“不要人物”假定会干净移除。
