# 场景分类

选择当前叙事对应的类别，可组合，但不要把不同类别的天气、道具和节奏一并叠加。对战另读 [对战与动作](combat.md)。

| 场景 | 图片先建立什么 | 视频的主要变化 | 光色与常见错误 |
| --- | --- | --- | --- |
| 山河、城池、营地远景 | 近处地形或人物、中段道路/营地、远山；观看方向与可达路线 | 旗、衣角、烟或远处人流的有限运动，必要时单一慢推 | 远层对比递减；不把前景一起雾化，不自动新增城池和背影骑者 |
| 营门、仪式、军令与问责 | 门框、轴线、守卫与受令人的位置，谁有权进出 | 停步、让路、递令或转向实际目标 | 结构和尺度建立压力，不自动移植宫殿红毯；对称不遮挡脸手 |
| 帐内对白、倾听与交涉 | 人物眼线、灯与帐口位置、彼此距离 | 由上一句话引发的视线、呼吸或动作变化；只让说话人开口 | 自然肤色，灯侧暖、帐口冷可共存；避免机械点头和每句切镜 |
| 铜印、文书等交接 | 同一物件尺度、托持面、接收手、手指与桌面关系 | 取出—递近—接触—承重转移—松手，按剧情保留必要阶段 | 手与关键物件同时可读；不靠浅景深糊掉交接，不凭空复制物件 |
| 拉人、救援与坠落 | 支撑点、落差、伸手范围、退路与承重关系 | 抓稳后受力，再移动身体；成功或失败由既定剧情决定 | 避免先把人拉起再补抓手、悬空无支撑；不自动添加悬崖和雨 |
| 骑行赶赴、追逐与撤退 | 路线、马头方向、地面坡度与远处目标，按已定视角构图 | 真实步态、骑手平衡、进路变化和到达；动势由剧情定 | 不套山河固定骑者；不为了动感失去马腿、路面接触与空间方向 |
| 火场与营寨燃烧 | 燃烧物、遮挡、烟的去向、可行走空间 | 火势/结构/人员动作只按当前阶段变化 | 火焰不沿所有边缘描线，布不是熔岩；暗烟与局部高光有层次 |
| 雨灭火、灾后与余烬 | 烧损物状态、地面坡向、残火位置和雨前雨后关系 | 雨压低暴露火、流水顺坡、受保护处残火或灾后停顿 | 湿木不是规则篝火堆，不把所有木材做成发光黑塑料；无因复燃与雨晴跳变 |
| 回忆、梦境、托付 | 保留人物、道具和动作现实质感，明确回忆所处时间 | 用切点、声音衔接与必要停顿区分时空 | 边缘柔化仅为可选方案，中心脸手清楚；不默认泛黄去色、透明鬼魂和法阵 |
| 告别、失败与结尾 | 人物关系或物件结果，空位与距离 | 一个有动机且完成的动作，再留结果；如凝望后低头 | 不强制流泪、跪地、灭灯或山河空镜；不把已落地的物件再落一次 |

## 从《江山北望》转化的方法

- A宫殿：吸收轴线、重复排列和人物尺度体现秩序；军营使用自身帐门、军案与守卫，不凭空变宫殿。
- B街巷：吸收近处门框、中景人物、远处屋顶和明暗层次；营帐可用帘口组织进出。框景不挡眼睛、手和关键证物。
- C山河：吸收前景提供尺度、中景展开地域、远山递减对比；可用于火营或灾后全景，但不把静止骑者模板强加给正在奔马的人。环境镜头服务剧情，不能用风景拖长紧凑动作段。
- D人物：吸收自然肤色、服装色相、背景局部灯火和轻微表演；不移植拥抱人物、服饰或关系。参考抽帧只支持可见质感，不能据此推定对白、配乐或精确摄影机轨迹。

## 时空与状态衔接

火场切雨后可以有时间省略，须在设计中说明事件阶段并用合适切点、声音或必要黑场表达；不强求用一个生成镜头同时实现火势、暴雨和全部灾后变化。具体黑场长度沿当前成片决定，不把某版剪辑数值固化为所有PV规则。

回忆与当下的区别不应遮住交印等剧情行为。回忆边缘柔焦、暗角或微光晕须全画面平滑过渡，幅度与范围由当前审阅决定；不能变成可见矩形模糊框，也不用于掩盖伪字或坏手。颜色来自光与物体，默认不全片降低饱和度。

交互镜头维持玩家既定视点，NPC的正面不表示他代玩家说话。PV可按既定导演方案使用外部视角，但不能擅自把互动段改成玩家露脸第三人称。
