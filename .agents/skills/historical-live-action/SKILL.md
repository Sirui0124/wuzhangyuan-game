# 历史实拍影像

本项目本地技能，2026-11-17整理。把已确认剧情转成可拍摄、可生成、可检查的图片和视频要求。“实拍”指追求的视觉效果，不声称生成素材由真实演员或摄影设备拍摄。

## 使用入口

先核对当前用户要求、项目 [AGENTS.md](../../../AGENTS.md)、当前制作索引实际指向的正文和用户意见；不要按文件日期猜最新版本。保留人物、事件结果、台词、第一视角及已确认素材。参考文档的角色、特效、时长不自动成为本作设定。

按当前任务只读需要的部分：

| 任务 | 读取 |
| --- | --- |
| 生成或修订图片、视频首帧、人物与空间参考 | [图片与统一质感](references/images.md) |
| 兵器近战、追击、骑战、群战、超自然战斗 | [对战与动作](references/combat.md)，制作图片时同时读图片规范 |
| 对白、交印、救援、山河与营地、火雨灾后、回忆和告别 | [场景分类](references/scenes.md) |
| 编写生成请求、剪辑或检查成片 | [视频与交付](references/video.md) |
| 查找来源、判断哪些是原文设定或未验证建议 | [来源与适用边界](references/sources.md) |

详细人物与场景特例留在项目原规范中，本技能不建立第二套素材台账。基础依据为 [写实电影影像风格](../../../docs/visual-direction/写实电影影像风格.md) 与 [制片风格规范](../../../docs/visual-direction/制片风格规范.md)；若本技能摘要与后续明确修订不一致，先核对修订内容再更新摘要。

## 共同要求

- 横向16:9满幅；真实演员观感、自然肤色、织物重量、道具接触和有原因的磨损。中性自然色温，无整体黄偏；火光暖色保留在实际照到的位置。不要用CG、游戏引擎、塑料高光或全片灰化实现“电影感”。
- 先写空间与行为：谁在哪里、看向谁、想做什么、起始状态、接触点、受力与结束状态。用前中远景体现尺度，景深保证脸、手、武器接触和关键物件可读。50mm正常透视是常用基准，远景与动作可按需要调整，不硬套焦距或浅景深。
- 人物身份、服装、持物手、兵器形制、地形方向和天气跨镜保持连续。雨、雾、湿衣、羽扇、马匹、悬崖不是风格必备元素。第一视角不等于手和长矛常驻前景。
- 环境镜头可以固定机位与微动作；战斗需要主动交锋和力量反馈。每镜围绕一个主要变化，可含必要的连续攻防，不能把所有场景都改为慢推、站桩或机械眨眼。
- 默认写实历史模式。《关羽对吕布》的神龙、魔影、刀气和地裂只有用户明确要求相应幻想设定时才启用；“更燃、大片感、激烈”不等于增加法术。
- 生成画面保持干净，无制作说明、编号、字幕列表、水印或遮伪字的方框。默认无BGM；台词与控制说明分开，口型只属于实际发声的人。具体声音与字幕按视频规范处理。

## 工作方法

1. 确定是图片、分镜、Prompt、成片审阅还是制作；若仅整理设计，不顺势调用生成API。既有授权继续有效，读取当前审核边界，不重复索取已给出的许可。
2. 明确场景类别和本镜叙事作用，读取对应参考。用简短连续性清单记录身份、位置、光向、天气、持物手、动作前后状态及必须保留的用户意见。
3. 分开参考图职责：人物身份、兵器/道具结构、场景空间、当前构图、光照质感。外部电影画面只参考已注明的拍法，不换成本作演员或剧情。核对真实附件、顺序和绝对路径。
4. 图片先选一个确定瞬间；视频按“空间—动作因果—机位/切点—连续性—声音”展开。对战写出双方动作关系，不能只有气氛词和攻击者动作。
5. 分别检查文稿、静帧、动态画面、实际声音与游戏内显示。未执行的检查明确标注；不将自动检查、ASR或文件生成成功写成用户通过。

- 马谡刑场：先读 [素材与轴线锁定](../../../docs/visual-direction/PV-马谡刑场站位与素材锁定.md)，原E07、凝望后叩首、无对白及反打方向只适用于该段，不推广成所有告别镜头。
- 诸葛亮分期、脸型与羽扇：读 [人物素材标准](../../../docs/visual-direction/诸葛亮人物素材标准.md)，不跨时期混用身份图。
- 庞统铜印：读 [史料与道具设计](../../../docs/visual-direction/庞统私印-史料与道具设计.md)，以当前用户确认版本为准，不从旧说明恢复已替代尺寸。
- Seedance：使用项目现有规则与模板；H3等其他平台使用当前指定流程，不自动套Seedance模型名，也不从历史记录推断当前API可用。

交付本地正文及可点击绝对路径，不额外打包。Prompt状态、视频状态和用户审核分别记录。技能可按项目任务选用，不要求固定口令。
